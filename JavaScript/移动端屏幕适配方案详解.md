## 一、移动端适配背景与挑战

### 1.1 移动端开发面临的挑战

| 挑战 | 说明 |
|------|------|
| **屏幕尺寸碎片化** | 从 320px (iPhone SE) 到 428px (iPhone 14 Pro Max)，Android 设备宽度范围更广 |
| **不同像素密度** | 高 DPI 屏幕（Retina）下 1px CSS 像素 = 2px 或 3px 物理像素 |
| **横竖屏切换** | 用户可能旋转设备，需要适配屏幕方向变化 |
| **安全区域适配** | iPhone X+ 的刘海屏、底部 Home Indicator 区域 |
| **浏览器兼容性** | 不同浏览器对 CSS 特性的支持程度不同 |
| **字体大小自适应** | 用户可能在系统设置中调整字体大小 |

### 1.2 移动端适配的目标

1. **响应式布局**：页面在不同屏幕尺寸下都能正确显示
2. **等比缩放**：元素尺寸随屏幕大小等比缩放
3. **清晰显示**：在高 DPI 屏幕上文字和图片保持清晰
4. **交互体验**：触摸区域足够大（至少 44px），手势流畅

### 1.3 适配方案分类

```
┌─────────────────────────────────────────────────────────┐
```

## 二、方案一：rem 适配方案

### 2.1 核心原理

**rem (Root Em)** 是 CSS 的一个相对单位，基于根元素（`<html>`）的字体大小计算。`1rem` 等于根元素的 `font-size` 值。

```css
/* 假设根元素 font-size 为 16px */
html { font-size: 16px; }

/* 则以下样式等于： */
.box { width: 1rem; }  /* 16px */
.box { width: 2rem; }  /* 32px */
.box { width: 0.5rem; } /* 8px */
```

**适配思路**：动态设置根元素的 `font-size`，使其与屏幕宽度挂钩，从而实现等比缩放。

### 2.2 实现步骤

**步骤 1**：设置设计稿宽度和基准字号

- 设计稿宽度：通常为 750px（iPhone 6/7/8 的两倍屏）
- 基准字号：在 750px 宽度下，`1rem = 100px`

**步骤 2**：计算当前屏幕宽度下的根字号

```
当前根字号 = (当前屏幕宽度 / 设计稿宽度) * 基准字号
```

**步骤 3**：动态设置根元素的 font-size

### 2.3 代码实现

#### 2.3.1 基础 rem 适配脚本

```javascript
/**
 * rem 适配方案基础实现
 * 设计稿宽度：750px
 * 基准字号：1rem = 100px
 */
(function () {
  const designWidth = 750;      // 设计稿宽度
  const baseFontSize = 100;     // 基准字号（750px 屏幕下 1rem = 100px）
  
  /**
   * 设置根元素字号
   */
  function setRootFontSize() {
    // 获取当前屏幕宽度
    const screenWidth = document.documentElement.clientWidth || document.body.clientWidth;
    
    // 限制最大宽度（PC 端预览时防止过大）
    const maxWidth = 750;
    const actualWidth = Math.min(screenWidth, maxWidth);
    
    // 计算根字号
    const fontSize = (actualWidth / designWidth) * baseFontSize;
    
    // 设置根元素字号
    document.documentElement.style.fontSize = fontSize + 'px';
    
    // 同时设置 body 的 font-size，便于子元素继承
    document.body.style.fontSize = '14px'; // 正文字号
  }
  
  // 初始化
  setRootFontSize();
  
  // 监听窗口变化
  window.addEventListener('resize', setRootFontSize);
  window.addEventListener('orientationchange', setRootFontSize);
  
  // 监听页面加载完成（防止初始化时尺寸为 0）
  window.addEventListener('load', setRootFontSize);
  
  // 可选：使用 MutationObserver 监听 DOM 变化
  // 以确保首次加载时的字体大小正确
  const observer = new MutationObserver(setRootFontSize);
  observer.observe(document.documentElement, {
    attributes: true,
    childList: true,
    subtree: true
  });
})();
```

#### 2.3.2 高级 rem 适配（含 DPR 处理）

```javascript
/**
 * 高级 rem 适配方案
 * - 处理 DPR（设备像素比）
 * - 支持横竖屏切换
 * - 性能优化（节流）
 * - 兼容微信/支付宝 WebView
 */
(function (window, document) {
  const designWidth = 750;     // 设计稿宽度
  const baseFontSize = 100;     // 基准字号
  const maxWidth = 750;         // 最大适配宽度
  
  let lastFontSize = 0;
  let timer = null;
  
  /**
   * 获取 DPR（设备像素比）
   */
  function getDPR() {
    return window.devicePixelRatio || 1;
  }
  
  /**
   * 设置根元素字号
   */
  function setRootFontSize() {
    // 获取屏幕宽度（兼容不同浏览器）
    const screenWidth = document.documentElement.clientWidth 
      || document.body.clientWidth
      || window.innerWidth;
    
    // 限制最大宽度
    const actualWidth = Math.min(screenWidth, maxWidth);
    
    // 计算根字号
    const fontSize = (actualWidth / designWidth) * baseFontSize;
    
    // 只在字号变化时更新（性能优化）
    if (fontSize !== lastFontSize) {
      lastFontSize = fontSize;
      document.documentElement.style.fontSize = fontSize + 'px';
      
      // 可选：设置 data-dpr 属性，便于 CSS 查询
      document.documentElement.setAttribute('data-dpr', getDPR());
    }
  }
  
  /**
   * 节流函数
   */
  function throttle(fn, delay) {
    let lastTime = 0;
    return function (...args) {
      const now = Date.now();
      if (now - lastTime >= delay) {
        lastTime = now;
        fn.apply(this, args);
      }
    };
  }
  
  // 节流处理（100ms）
  const throttledSet = throttle(setRootFontSize, 100);
  
  // 初始化
  setRootFontSize();
  
  // 事件监听
  window.addEventListener('resize', throttledSet);
  window.addEventListener('orientationchange', throttledSet);
  window.addEventListener('pageshow', throttledSet);
  
  // DOM 就绪后设置
  if (document.readyState === 'complete') {
    setRootFontSize();
  } else {
    window.addEventListener('DOMContentLoaded', setRootFontSize);
  }
  
  // 暴露到全局（调试用）
  window.__REM_ADAPTER__ = {
    refresh: setRootFontSize,
    getState: () => ({
      fontSize: lastFontSize,
      screenWidth: document.documentElement.clientWidth,
      dpr: getDPR()
    })
  };
  
})(window, document);
```

#### 2.3.3 CSS 使用示例

```css
/* 基于 rem 的样式 */

/* 容器宽度：设计稿 750px → 100% */
.container {
  width: 100%;
  max-width: 7.5rem; /* 750px */
  margin: 0 auto;
}

/* 按钮：设计稿 200px × 80px */
.button {
  width: 2rem;      /* 200px */
  height: 0.8rem;   /* 80px */
  font-size: 0.32rem; /* 32px */
  border-radius: 0.1rem; /* 10px */
}

/* 间距：设计稿 30px */
.margin {
  margin: 0.3rem;   /* 30px */
  padding: 0.2rem 0.4rem; /* 20px 40px */
}

/* 文字大小 */
.title {
  font-size: 0.48rem; /* 48px */
  line-height: 1.4;    /* 行高用倍数，不随字号缩放 */
}

/* 响应式断点（rem 结合 Media Query） */
@media (min-width: 3.75rem) {
  /* 屏幕宽度 >= 375px 时 */
  .container {
    max-width: 5rem; /* 500px */
  }
}
```

### 2.4 优缺点分析

#### 优点

| 优点 | 说明 |
|------|------|
| ✅ **成熟稳定** | 方案简单，社区实践丰富 |
| ✅ **跨平台兼容** | 几乎所有浏览器都支持 rem |
| ✅ **灵活控制** | 可精确控制每个元素的尺寸 |
| ✅ **等比缩放** | 随屏幕宽度等比缩放，保证视觉比例 |
| ✅ **支持嵌套** | rem 可嵌套使用，计算方便 |

#### 缺点

| 缺点 | 说明 |
|------|------|
| ❌ **需额外脚本** | 需要动态设置根字号的 JS 代码 |
| ❌ **布局抖动** | 页面加载时可能出现短暂的布局变化（FOUC） |
| ❌ **字体大小影响** | 用户修改系统字体大小可能影响布局 |
| ❌ **响应式断点** | 需要结合 Media Query 处理不同屏幕 |

## 三、方案二：vw/vh 适配方案

### 3.1 核心原理

**vw (Viewport Width)** 和 **vh (Viewport Height)** 是 CSS3 引入的视口单位。

- `1vw` = 视口宽度的 1%
- `1vh` = 视口高度的 1%
- `1vmin` = vw 和 vh 中较小的那个
- `1vmax` = vw 和 vh 中较大的那个

```
视口单位示意：
┌────────────────────────────────────┐
│  视口 (Viewport)                    │
│  ┌────────────────────────────────┐ │
│  │                                │ │
│  │        1vw = 视口宽度的 1%      │ │
│  │        1vh = 视口高度的 1%      │ │
│  │                                │ │
│  └────────────────────────────────┘ │
│                                      │
└────────────────────────────────────┘
```

### 3.2 实现步骤

**步骤 1**：计算 vw 与设计稿 px 的换算关系

```
设计稿 750px 对应 100vw
1px = (100 / 750)vw = 0.1333vw
100px = 13.33vw
```

**步骤 2**：使用 PostCSS 自动转换 px 为 vw

**步骤 3**：处理 vh 在移动端的兼容性问题（动态视口）

### 3.3 代码实现

#### 3.3.1 PostCSS 配置（vue.config.js 或 postcss.config.js）

```javascript
// postcss.config.js
module.exports = {
  plugins: {
    // 自动将 px 转换为 vw
    'postcss-px-to-viewport': {
      unitToConvert: 'px',      // 要转换的单位
      viewportWidth: 750,       // 视口宽度（设计稿宽度）
      unitPrecision: 5,         // 转换后小数位数
      propList: ['*'],          // 所有属性都转换
      viewportUnit: 'vw',       // 目标单位
      fontViewportUnit: 'vw',   // 字体目标单位
      selectorBlackList: [],    // 要忽略的选择器
      minPixelValue: 1,         // 最小转换值
      mediaQuery: false,        // 是否在媒体查询中转换
      replace: true,            // 是否直接替换
      exclude: [/node_modules/],// 排除的文件
      landscape: false,         // 是否处理横屏
      landscapeUnit: 'vw',      // 横屏单位
      landscapeWidth: 568      // 横屏宽度
    }
  }
};
```

#### 3.3.2 动态 viewport 高度处理（解决 vh 问题）

移动端浏览器地址栏会影响视口高度，导致 `100vh` 不准确。解决方案：

```javascript
/**
 * 动态设置视口高度（解决移动端 100vh 问题）
 * iOS Safari 地址栏收起/展开会改变视口高度
 */
(function () {
  // 设置 CSS 变量 --vh 为实际视口高度
  function setVh() {
    const vh = window.innerHeight * 0.01;
    document.documentElement.style.setProperty('--vh', `${vh}px`);
  }
  
  // 初始化
  setVh();
  
  // 监听视口变化
  window.addEventListener('resize', setVh);
  window.addEventListener('orientationchange', setVh);
})();
```

#### 3.3.3 CSS 使用示例

```css
/* 基于 vw 的样式（PostCSS 自动转换） */

/* 原始 CSS */
.container {
  width: 750px;
  height: 200px;
  font-size: 32px;
  padding: 20px 30px;
}

/* PostCSS 转换后 */
.container {
  width: 100vw;
  height: 26.6667vw;
  font-size: 4.2667vw;
  padding: 2.6667vw 4vw;
}

/* 使用 --vh 变量解决 100vh 问题 */
.full-screen {
  height: 100vh; /* 有问题 */
  height: calc(var(--vh, 1vh) * 100); /* 正确方式 */
}

/* 结合 px 限制最小宽度 */
.min-width-container {
  min-width: 320px; /* 保持 320px 最小宽度 */
  width: 100vw;
  max-width: 750px;
}
```

### 3.4 优缺点分析

#### 优点

| 优点 | 说明 |
|------|------|
| ✅ **原生支持** | CSS3 标准单位，无需 JS 脚本动态设置 |
| ✅ **零延迟** | 无 rem 的 FOUC（Flash of Unstyled Content）问题 |
| ✅ **等比缩放** | 100vw = 视口宽度，天然等比缩放 |
| ✅ **简单直接** | 理解和使用成本低 |
| ✅ **性能好** | 浏览器原生渲染，无额外计算开销 |

#### 缺点

| 缺点 | 说明 |
|------|------|
| ❌ **移动端 vh 问题** | iOS Safari 地址栏影响 100vh 准确性 |
| ❌ **单位转换复杂** | 需要 PostCSS 工具链支持 |
| ❌ **边界不精确** | 元素可能超出屏幕（需 max-width 限制） |
| ❌ **字体缩放** | 小屏下字体过小，大屏下字体过大 |
| ❌ **兼容性** | 部分老浏览器不支持 vw/vh |

## 四、方案三：Flexbox/Grid 弹性布局

### 4.1 核心原理

**Flexbox** 和 **CSS Grid** 是 CSS3 引入的弹性布局系统，通过分配剩余空间实现响应式布局，而非依赖绝对单位换算。

```
Flexbox 布局模式：
┌──────────────────────────────────────┐
│  Flex Container (display: flex)       │
│  ┌────────┬────────┬────────┐        │
│  │  Flex  │  Flex  │  Flex  │ ...    │
│  │  Item  │  Item  │  Item  │        │
│  └────────┴────────┴────────┘        │
│  自动分配空间，无需关心具体像素值      │
└──────────────────────────────────────┘
```

### 4.2 实现步骤

1. 使用 `display: flex` 或 `display: grid` 启用弹性布局
2. 通过 `flex: 1` 或 `grid-template-columns` 分配空间
3. 使用 `flex-wrap` 实现自动换行
4. 配合 Media Query 调整布局

### 4.3 代码实现

#### 4.3.1 Flexbox 基础适配

```css
/* 导航栏布局 */
.nav-bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  width: 100%;
  height: 44px; /* 固定高度 */
}

.nav-bar .logo {
  flex: 0 0 auto; /* 不伸缩 */
  width: 80px;
  height: 32px;
}

.nav-bar .menu {
  flex: 1; /* 占据剩余空间 */
  display: flex;
  justify-content: center;
  gap: 16px;
}

.nav-bar .menu-item {
  flex: 1; /* 菜单均分空间 */
  text-align: center;
}

/* 三列布局 */
.three-column-layout {
  display: flex;
  gap: 12px;
  padding: 16px;
}

.three-column-layout .col {
  flex: 1; /* 三等分 */
  min-height: 100px;
}

/* 列表自适应（固定宽度 + 弹性） */
.card-list {
  display: flex;
  flex-wrap: wrap; /* 自动换行 */
  gap: 12px;
  justify-content: space-between;
}

.card-list .card {
  flex: 0 0 calc(50% - 6px); /* 两列，考虑间距 */
  min-height: 120px;
  box-sizing: border-box;
}

/* 响应式：屏幕大于 600px 时显示三列 */
@media (min-width: 600px) {
  .card-list .card {
    flex: 0 0 calc(33.333% - 8px); /* 三列 */
  }
}
```

#### 4.3.2 Grid 布局适配

```css
/* 商品网格布局 */
.product-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));

.product-grid .item {
  min-height: 200px;
  display: flex;
  flex-direction: column;
}

.product-grid .item img {
  width: 100%;
  height: auto;
  aspect-ratio: 1; /* 保持正方形比例 */
  object-fit: cover;
}

/* 复杂布局：头部 + 侧边 + 主内容 */
.dashboard {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

.dashboard .header { grid-area: header; }
.dashboard .sidebar { grid-area: sidebar; }
.dashboard .main { grid-area: main; }
.dashboard .footer { grid-area: footer; }

/* 响应式：移动端侧边栏折叠 */
@media (max-width: 768px) {
  .dashboard {
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
    grid-template-columns: 1fr;
    grid-template-rows: auto auto auto auto;
  }
```

### 4.4 优缺点分析

#### 优点

| 优点 | 说明 |

## 五、方案对比与选型

### 5.1 核心对比

| 对比维度 | rem 方案 | vw/vh 方案 | Flexbox/Grid |
|---------|---------|-----------|--------------|
| **核心思路** | 动态根字号换算 | 视口百分比单位 | 弹性分配空间 |
| **单位类型** | rem（相对根字号） | vw/vh（相对视口） | px/auto/percentage |
| **设计稿支持** | ✅ 完美支持 | ✅ 需 PostCSS 转换 | ❌ 需手动调整 |
| **性能开销** | 中（JS 计算 + CSS 重绘） | 低（CSS 原生） | 低（CSS 原生） |
| **实现复杂度** | 中 | 中 | 低 |
| **响应式能力** | 中（需配合 Media Query） | 高（天然响应式） | 高（配合 Media Query） |
| **兼容性** | 所有浏览器 | 现代浏览器 | 现代浏览器 |
| **字体大小** | 等比缩放（可控制） | 等比缩放（难控制） | 固定或相对 |

### 5.2 选型建议

#### 场景一：电商/App 类项目（固定设计稿）

**推荐方案**：rem + PostCSS px-to-rem

**原因**：
- 设计稿转换简单（750px 设计稿直接写 px）
- 元素等比缩放，保持视觉一致性
- 生态成熟，组件库（Vant、NutUI）都支持

#### 场景二：内容展示类项目（响应式布局）

**推荐方案**：vw/vh + Flexbox

**原因**：
- 内容自适应宽度，无需精确像素
- Flexbox 处理复杂布局，vw 处理宽度适配
- 响应式断点处理不同屏幕

#### 场景三：复杂后台管理系统（PC + 移动）

**推荐方案**：Flexbox/Grid 为主 + rem 辅助

**原因**：
- Grid 实现复杂的二维布局
- Flexbox 处理组件内部布局
- rem 控制字体、间距等细节
- Media Query 处理 PC/平板/手机切换

#### 场景四：混合方案（最推荐）

**最佳实践**：**vw/vh + Flexbox + rem 字体** 组合使用

```css
/* 宽度用 vw（自动适配） */
.container {
  width: 100vw;
  max-width: 750px;
  margin: 0 auto;
}

/* 布局用 Flexbox（弹性分配） */
.flex-layout {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

/* 字体用 rem（精确控制） */
.title {
  font-size: 0.48rem; /* 基于 rem 的字号 */
  line-height: 1.5;
}

/* 间距用 vw 或 rem */
.card {
  padding: 2vw; /* 视口百分比 */
  margin-bottom: 0.3rem; /* 或 rem */
}
```

### 6.3 核心适配脚本

```javascript
// src/utils/adapter.js
/**
 * 移动端适配方案
 * - rem 动态适配
 * - DPR 处理
 * - 横竖屏切换
 * - 安全区域适配
 */

const DESIGN_WIDTH = 750;     // 设计稿宽度
const BASE_FONT_SIZE = 100;   // 基准字号
const MAX_WIDTH = 750;        // 最大适配宽度

/**
 * rem 适配
 */
class RemAdapter {
  constructor() {
    this.lastFontSize = 0;
    this.dpr = this.getDPR();
    this.init();
  }
  
  getDPR() {
    return window.devicePixelRatio || 1;
  }
  
  getScreenWidth() {
    return document.documentElement.clientWidth 
      || document.body.clientWidth
      || window.innerWidth;
  }
  
  setFontSize() {
    const width = Math.min(this.getScreenWidth(), MAX_WIDTH);
    const fontSize = (width / DESIGN_WIDTH) * BASE_FONT_SIZE;
    
    if (fontSize !== this.lastFontSize) {
      this.lastFontSize = fontSize;
      document.documentElement.style.fontSize = fontSize + 'px';
      document.documentElement.setAttribute('data-dpr', this.dpr);
    }
  }
  
  // 解决移动端 100vh 问题
  setVh() {
    const vh = window.innerHeight * 0.01;
    document.documentElement.style.setProperty('--vh', `${vh}px`);
  }
  
  // 安全区域适配（iPhone X+）
  setSafeArea() {
    const env = `
      padding-top: constant(safe-area-inset-top);
      padding-top: env(safe-area-inset-top);
      padding-bottom: constant(safe-area-inset-bottom);
      padding-bottom: env(safe-area-inset-bottom);
    `;
    document.documentElement.style.setProperty('--safe-area', env);
  }
  
  init() {
    this.setFontSize();
    this.setVh();
    this.setSafeArea();
    
    // 事件监听
    window.addEventListener('resize', () => {
      this.throttle(this.setFontSize, 100);
      this.throttle(this.setVh, 100);
    });
    
    window.addEventListener('orientationchange', () => {
      this.setFontSize();
      this.setVh();
    });
    
    window.addEventListener('pageshow', (e) => {
      if (e.persisted) {
        this.setFontSize();
        this.setVh();
      }
    });
    
    console.log('[Adapter] 初始化完成:', {
      fontSize: this.lastFontSize,
      screenWidth: this.getScreenWidth(),
      dpr: this.dpr
    });
  }
  
  throttle(fn, delay) {
    let timer = null;
    return () => {
      if (timer) return;
      timer = setTimeout(() => {
        fn();
        timer = null;
      }, delay);
    };
  }
  
  getState() {
    return {
      fontSize: this.lastFontSize,
      screenWidth: this.getScreenWidth(),
      screenHeight: window.innerHeight,
      dpr: this.dpr,
      userAgent: navigator.userAgent
    };
  }
}

// 导出单例
export const adapter = new RemAdapter();

// 调试用
window.__ADAPTER__ = adapter;
```

### 7.2 优化建议

#### 7.2.1 性能优化

1. **减少 JS 计算**：
   - 使用 `requestAnimationFrame` 替代 `setTimeout`
   - 防抖函数确保只在必要时计算
   - 缓存计算结果，避免重复计算

2. **避免 FOUC（Flash of Unstyled Content）**：
   - 在 `<head>` 中同步执行适配脚本
   - 使用 `window.__WEBFONT__` 或 `font-display: swap`

3. **优化图片加载**：
   - 使用 `loading="lazy"` 懒加载
   - 使用响应式图片（`srcset`、`sizes`）
   - 使用 WebP 格式减少体积

4. **减少重绘重排**：
   - 避免频繁修改 `font-size`
   - 使用 `transform` 替代 `top/left`
   - 合理使用 `will-change` 提示浏览器

#### 7.2.2 体验优化

1. **字体大小保护**：
   - 设置最小字号（`min-font-size: 12px`）
   - 设置最大字号（`max-font-size: 72px`）
   - 防止小屏设备字体过小

2. **触控区域优化**：
   - 可点击元素最小尺寸：`44px × 44px`
   - 输入框最小高度：`32px`
   - 避免在移动端使用 hover 交互

3. **安全区域适配**：

   ```css
   .safe-bottom {
   ```

## 八、常见问题 FAQ

### Q1: rem 方案和 vw 方案哪个更好？

**A**: 各有优势，推荐组合使用：
- **rem**：适合字体、间距等需要精确控制的场景
- **vw**：适合容器宽度、块级元素等需要自动适配的场景
- **最佳实践**：**宽度用 vw，字体用 rem，布局用 Flexbox**

### Q2: 为什么 rem 方案需要设置最大宽度？

**A**: 在 PC 浏览器中预览时，如果不限制最大宽度，rem 根字号会过大，导致元素超出预期大小。设置最大宽度（如 750px）可保证在宽屏下也能正确显示。

### Q3: 如何处理用户手动调整的字体大小？

**A**: 可以监听 `resize` 事件或使用 `Media Query` 检测字体设置变化：

```css
@media (min-width: 750px) {
  html { font-size: 100px; } /* 固定值，防止 PC 端过大 */
}
```

### Q4: vh 方案在 iOS Safari 中表现不佳，如何解决？

**A**: 使用 CSS 变量动态计算视口高度：

```javascript
function setVh() {
  const vh = window.innerHeight * 0.01;
  document.documentElement.style.setProperty('--vh', `${vh}px`);
}

// CSS 中使用
.full-page {
  height: 100vh; /* 旧方式 */
  height: calc(var(--vh, 1vh) * 100); /* 新方式 */
}
```

### Q5: Flexbox 布局在小屏设备上换行过多怎么办？

**A**: 可以使用 `flex-shrink: 0` 防止换行，或使用 `overflow-x: auto` 实现横向滚动：

```css
.calendar {
  display: flex;
  overflow-x: auto;
  -webkit-overflow-scrolling: touch; /* iOS 平滑滚动 */
}

.calendar .day {
  flex: 0 0 calc(100% / 7); /* 不收缩，均分 7 天 */
}
```

### Q6: 如何测试适配方案在不同设备上的表现？

**A**: 使用以下工具和方法：
1. **Chrome DevTools**：设备模拟模式（Ctrl+Shift+M）
2. **Safari Web Inspector**：连接 iOS 设备调试
3. **BrowserStack**：在线多设备测试
4. **真机调试**：使用 USB 连接 + Chrome remote debugging
5. **Lighthouse**：性能测试和诊断

### Q7: 如何在 Vue3 中优雅地集成适配方案？

**A**: 推荐封装一个 `useAdapter` 组合式函数：

```javascript
// src/composables/useAdapter.js
import { ref, onMounted, onUnmounted } from 'vue';

export function useAdapter() {
  const screenWidth = ref(window.innerWidth);
  const screenHeight = ref(window.innerHeight);
  const dpr = ref(window.devicePixelRatio || 1);
  
  const update = () => {
    screenWidth.value = window.innerWidth;
    screenHeight.value = window.innerHeight;
  };
  
  onMounted(() => {
    window.addEventListener('resize', update);
    window.addEventListener('orientationchange', update);
  });
  
  onUnmounted(() => {
    window.removeEventListener('resize', update);
    window.removeEventListener('orientationchange', update);
  });
  
  return {
    screenWidth,
    screenHeight,
    dpr,
    isMobile: computed(() => screenWidth.value < 768),
    isTablet: computed(() => screenWidth.value >= 768 && screenWidth.value < 1024),
    isDesktop: computed(() => screenWidth.value >= 1024)
  };
}

// 使用
import { useAdapter } from '@/composables/useAdapter';

const { screenWidth, isMobile } = useAdapter();
</script>
```
