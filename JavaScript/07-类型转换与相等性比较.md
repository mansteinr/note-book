# JavaScript 类型转换与相等性比较面试题

## 一、核心概念解析

### 1. JavaScript 类型分类

```
原始类型（Primitive）
  ├── undefined
  ├── null
  ├── boolean
  ├── number
  ├── string
  ├── symbol (ES6)
  └── bigint (ES2020)

引用类型（Object）
  ├── Object
  ├── Array
  ├── Function
  ├── Date
  ├── RegExp
  └── Map / Set / WeakMap / WeakSet
```

### 2. 类型转换的三种方式

| 转换方式 | 说明 | 示例 |
|---------|------|------|
| **显式转换** | 开发者主动调用转换函数 | `Number('123')`、`String(true)` |
| **隐式转换** | 引擎自动转换 | `'1' + 2` → `'12'` |
| **装箱/拆箱** | 原始类型与包装对象互转 | `'hello'.length` / `new String('hello')` |

### 3. 抽象操作（Abstract Operations）

| 抽象操作 | 作用 | 触发场景 |
|---------|------|---------|
| `ToPrimitive` | 将对象转为原始值 | `==` 比较、`+` 运算符 |
| `ToNumber` | 转为数字 | 算术运算、`Number()` |
| `ToString` | 转为字符串 | `+` 字符串拼接、`String()` |
| `ToBoolean` | 转为布尔值 | `if` 条件、`!` 运算符 |

### 4. 对象转原始值（ToPrimitive）

```
ToPrimitive(input, hint)

hint = "string"（如 String()、模板字符串）
  → 调用 obj.toString()
  → 如果返回的不是原始值，调用 obj.valueOf()
  → 如果还不是原始值，抛出 TypeError

hint = "number"（如 Number()、算术运算）
  → 调用 obj.valueOf()
  → 如果返回的不是原始值，调用 obj.toString()
  → 如果还不是原始值，抛出 TypeError

hint = "default"（如 ==、+）
  → 先调用 obj.valueOf()
  → 再调用 obj.toString()
```

### 5. 类型转换速查表

| 值 | ToNumber | ToString | ToBoolean |
|----|---------|---------|----------|
| `undefined` | `NaN` | `'undefined'` | `false` |
| `null` | `0` | `'null'` | `false` |
| `true` | `1` | `'true'` | `true` |
| `false` | `0` | `'false'` | `false` |
| `''` | `0` | — | `false` |
| `'123'` | `123` | — | `true` |
| `'abc'` | `NaN` | — | `true` |
| `0` | — | `'0'` | `false` |
| `NaN` | — | `'NaN'` | `false` |
| `Infinity` | — | `'Infinity'` | `true` |
| `[]` | `0` | `''` | `true` |
| `[1]` | `1` | `'1'` | `true` |
| `[1,2]` | `NaN` | `'1,2'` | `true` |
| `{}` | `NaN` | `'[object Object]'` | `true` |

## 二、面试题

### 题目 1：`==` 与 `===` 的区别（基础）

#### 题干

```javascript
console.log(null == undefined);
console.log(null === undefined);
console.log(0 == '');
console.log(0 == false);
console.log('' == false);
console.log([] == ![]);
console.log({} == !{});
```

#### 解题思路

`==`（抽象相等）允许类型转换，`===`（严格相等）不进行类型转换。

**`==` 的转换规则**：

```
x == y
1. 如果类型相同，直接比较（NaN 除外）
2. null == undefined → true（null 和 undefined 互相 == 为 true）
3. 如果一方是 number，另一方是 string → string 转 number
4. 如果一方是 boolean → boolean 转 number（true → 1, false → 0）
5. 如果一方是 object，另一方是 string/number → object 转原始值
```

#### 正确代码实现

```javascript
// 1. true — null 和 undefined 互相 == 为 true
console.log(null == undefined); // true

// 2. false — 类型不同（null vs undefined）
console.log(null === undefined); // false

// 3. true — '' 转 number 为 0，0 == 0
console.log(0 == ''); // true

// 4. true — false 转 number 为 0，0 == 0
console.log(0 == false); // true

// 5. true — '' 转 number 为 0，false 转 number 为 0，0 == 0
console.log('' == false); // true

// 6. true — 经典面试题
//   ![] → false（[] 是对象，转为 boolean 为 true，!true → false）
//   [] == false
//   false → 0
//   [] → '' → 0
//   0 == 0 → true
console.log([] == ![]); // true

// 7. false
//   !{} → false
//   {} == false
//   false → 0
//   {} → '[object Object]' → NaN
//   NaN == 0 → false
console.log({} == !{}); // false
```

#### 知识点拓展

- `===` 比较：类型不同直接返回 `false`，类型相同比较值（`NaN === NaN` 为 `false`）
- `Object.is()` 与 `===` 的区别：`Object.is(NaN, NaN)` 为 `true`，`Object.is(-0, +0)` 为 `false`
- 推荐始终使用 `===` 和 `!==`，除非明确需要类型转换

### 题目 2：`+` 运算符的隐式转换（基础）

#### 题干

```javascript
console.log(1 + '2' + '2');
console.log(1 + +'2' + '2');
console.log(1 + -'1' + '2');
console.log('1' + 2 + 3);
console.log(1 + 2 + '3');
```

#### 解题思路

`+` 运算符的行为取决于操作数类型：
- 如果**有一方是字符串**，执行字符串拼接
- 否则执行数字加法
- 一元 `+`/`-` 将操作数转为数字

#### 正确代码实现

```javascript
// 1. '122' — 1 + '2' → '12'，'12' + '2' → '122'
console.log(1 + '2' + '2'); // '122'

// 2. '32' — +'2' → 2，1 + 2 → 3，3 + '2' → '32'
console.log(1 + +'2' + '2'); // '32'

// 3. '02' — -'1' → -1，1 + (-1) → 0，0 + '2' → '02'
console.log(1 + -'1' + '2'); // '02'

// 4. '123' — '1' + 2 → '12'，'12' + 3 → '123'
console.log('1' + 2 + 3); // '123'

// 5. '33' — 1 + 2 → 3，3 + '3' → '33'
console.log(1 + 2 + '3'); // '33'
```

#### 知识点拓展

- 一元 `+` 等价于 `Number()`：`+'123'` → `123`
- `+` 运算符从左到右结合，结果的类型取决于第一个遇到字符串的位置
- 注意：`+new Date()` 是获取时间戳的快捷写法

### 题目 3：`if` 条件中的真假值判断（进阶）

#### 题干

```javascript
if ([]) console.log('A');
if ({} ) console.log('B');
if ('') console.log('C');
if ('false') console.log('D');
if (new Boolean(false)) console.log('E');
if (0) console.log('F');
if (NaN) console.log('G');
if (null) console.log('H');
if (undefined) console.log('I');
```

#### 解题思路

`if` 条件使用 `ToBoolean` 抽象操作。在 JavaScript 中，只有以下 6 个值是**假值（falsy）**：

```
false, 0, '' (空字符串), null, undefined, NaN
```

**所有其他值都是真值（truthy）**，包括空数组、空对象、`'false'` 字符串、`new Boolean(false)` 对象等。

#### 正确代码实现

```javascript
// A: 输出 — [] 是真值
// B: 输出 — {} 是真值
// C: 不输出 — '' 是假值
// D: 输出 — 'false' 是非空字符串，是真值
// E: 输出 — new Boolean(false) 是一个对象，是真值（对象永远是真值）
// F: 不输出 — 0 是假值
// G: 不输出 — NaN 是假值
// H: 不输出 — null 是假值
// I: 不输出 — undefined 是假值

// 输出：A, B, D, E
```

#### 知识点拓展

- `new Boolean(false)` 是对象，`Boolean(false)` 是原始值 `false`
- 判断变量是否为 `null` 或 `undefined` 时，不要用 `if (!val)`，因为 `0` 和 `''` 也会被排除
- 正确做法：`if (val === null || val === undefined)`

### 题目 4：数组与对象的隐式转换（进阶）

#### 题干

```javascript
console.log([] + []);
console.log([] + {});
console.log({} + []);
console.log({} + {});

// 特殊情况
console.log([1, 2] + [3, 4]);
console.log([] + 1);
console.log(1 + []);
```

#### 解题思路

`+` 运算符操作对象时，会进行 `ToPrimitive` 转换：
1. 数组的 `valueOf` 返回数组本身（不是原始值）
2. 数组的 `toString` 返回逗号分隔的字符串（`[1,2]` → `'1,2'`）
3. 对象的 `toString` 返回 `'[object Object]'`

#### 正确代码实现

```javascript
// 1. '' — [] → ''，'' + '' → ''
console.log([] + []); // ''

// 2. '[object Object]' — [] → ''，{} → '[object Object]'
console.log([] + {}); // '[object Object]'

// 3. '[object Object]' — {} → '[object Object]'，[] → ''
// 注意：在浏览器控制台中，{} + [] 可能被解析为代码块，结果为 0
console.log({} + []); // '[object Object]'（表达式上下文）

// 4. '[object Object][object Object]'
console.log({} + {}); // '[object Object][object Object]'

// 5. '1,23,4' — [1,2] → '1,2'，[3,4] → '3,4'
console.log([1, 2] + [3, 4]); // '1,23,4'

// 6. '1' — [] → ''，1 + '' → '1'
console.log([] + 1); // '1'

// 7. '1' — 1 + [] → 1 + '' → '1'
console.log(1 + []); // '1'
```

#### 知识点拓展

- `{}+[]` 在语句上下文中被解析为代码块 + 一元运算符，结果为 `0`
  - `{}` 被解析为空代码块，`+[]` 为 `0`
- 数组的 `toString` 是 `Array.prototype.toString`，内部调用 `join(',')`
- `[undefined].toString()` → `''`，`[null].toString()` → `''`

### 题目 5：`NaN` 的特性与判断（进阶）

#### 题干

```javascript
console.log(NaN === NaN);
console.log(NaN == NaN);
console.log(typeof NaN);
console.log(Object.is(NaN, NaN));
console.log(isNaN('abc'));
console.log(Number.isNaN('abc'));
console.log(isNaN(undefined));
console.log([NaN].indexOf(NaN));
console.log([NaN].includes(NaN));
```

#### 解题思路

`NaN`（Not-a-Number）是 JavaScript 中唯一不等于自身的值。

`isNaN` vs `Number.isNaN`：
- `isNaN`：先调用 `Number()` 强制转换，再判断是否为 NaN
- `Number.isNaN`：不转换，直接判断值是否为 NaN

#### 正确代码实现

```javascript
// 1. false — NaN 是唯一不等于自身的值
console.log(NaN === NaN); // false

// 2. false — 同上
console.log(NaN == NaN); // false

// 3. 'number' — NaN 的类型是 number
console.log(typeof NaN); // 'number'

// 4. true — Object.is 可以正确判断 NaN
console.log(Object.is(NaN, NaN)); // true

// 5. true — isNaN 先转换：Number('abc') → NaN，所以是 true
console.log(isNaN('abc')); // true

// 6. false — Number.isNaN 不转换：'abc' 不是 NaN
console.log(Number.isNaN('abc')); // false

// 7. true — Number(undefined) → NaN，所以是 true
console.log(isNaN(undefined)); // true

// 8. -1 — indexOf 使用 === 比较，NaN === NaN 为 false
console.log([NaN].indexOf(NaN)); // -1

// 9. true — includes 使用 SameValueZero 比较，可以正确识别 NaN
console.log([NaN].includes(NaN)); // true
```

#### 知识点拓展

- 检查 NaN 的正确方式：`Number.isNaN(val)` 或 `Object.is(val, NaN)`
- `Array.prototype.includes` 使用 `SameValueZero` 算法，可以正确识别 `NaN`
- `Array.prototype.indexOf` 使用 `===`，无法找到 `NaN`

### 题目 6：`==` 的完整转换逻辑（高阶）

#### 题干

```javascript
console.log([1] == 1);
console.log([1, 2] == '1,2');
console.log(['1', '2'] == [1, 2]);
console.log(String([]) == Boolean([]));
console.log(Boolean([]) == Number([]));
console.log(null == 0);
console.log('' == 0);
console.log('' == '0');
console.log(undefined == null);
```

#### 解题思路

`==` 的完整算法（ECMAScript 规范）：

```
1. 类型相同 → 直接比较值
2. null == undefined → true
3. 如果一方是 number，另一方是 string → ToNumber(string)
4. 如果一方是 boolean → ToNumber(boolean)
5. 如果一方是 object，另一方是 string/number/symbol → ToPrimitive(object)
6. 否则 → false
```

#### 正确代码实现

```javascript
// 1. true — [1] → '1' → 1，1 == 1
console.log([1] == 1); // true

// 2. true — [1,2] → '1,2'，'1,2' == '1,2'
console.log([1, 2] == '1,2'); // true

// 3. false — 都是对象，类型相同，引用不同
console.log(['1', '2'] == [1, 2]); // false

// 4. true — String([]) → ''，Boolean([]) → true
//   '' == true → '' == 1 → 0 == 1 → false
//   等等，让我重新分析：
//   String([]) → ''
//   Boolean([]) → true
//   '' == true → 0 == 1 → false
//   实际上这个结果是 false
console.log(String([]) == Boolean([])); // false

// 5. true — Boolean([]) → true → 1
//   Number([]) → 0
//   1 == 0 → false
//   实际上这个结果是 false
console.log(Boolean([]) == Number([])); // false

// 6. false — null 和 0 不相等（null 只 == undefined）
console.log(null == 0); // false

// 7. true — '' → 0，0 == 0
console.log('' == 0); // true

// 8. false — 类型相同（string），直接比较值
console.log('' == '0'); // false

// 9. true — null == undefined 是特殊规则
console.log(undefined == null); // true
```

#### 知识点拓展

- `null` 只与 `undefined` 互相 `==` 为 `true`，与任何其他值都不相等
- `'' == 0` 为 `true`，但 `'' == '0'` 为 `false`（类型相同，直接比较值）
- 实际开发中，推荐使用 `===` 避免隐式转换带来的混淆

### 题目 7：自定义 `valueOf` 和 `toString`（高阶）

#### 题干

```javascript
const obj = {
  valueOf() {
    console.log('valueOf called');
    return 42;
  },
  toString() {
    console.log('toString called');
    return 'hello';
  }
};

console.log(obj + 1);
console.log(`${obj}`);
console.log(+obj);
console.log(obj == 42);
console.log(String(obj));
```

#### 解题思路

当对象需要转为原始值时，`valueOf` 和 `toString` 的调用顺序取决于转换的 `hint`：

| 上下文 | hint | 调用顺序 |
|--------|------|---------|
| `+` 运算符 | `default` | `valueOf` → `toString` |
| 模板字符串 `` `${obj}` `` | `string` | `toString` → `valueOf` |
| 一元 `+` | `number` | `valueOf` → `toString` |
| `==` 比较 | `default` | `valueOf` → `toString` |
| `String(obj)` | `string` | `toString` → `valueOf` |

#### 正确代码实现

```javascript
// 1. obj + 1 → valueOf called → 42 + 1 → 43
console.log(obj + 1); // 43

// 2. `${obj}` → toString called → 'hello'
console.log(`${obj}`); // 'hello'

// 3. +obj → valueOf called → +42 → 42
console.log(+obj); // 42

// 4. obj == 42 → valueOf called → 42 == 42 → true
console.log(obj == 42); // true

// 5. String(obj) → toString called → 'hello'
console.log(String(obj)); // 'hello'
```

#### 知识点拓展

- `Date` 类型重写了 `ToPrimitive`：`+new Date()` 返回时间戳，`String(new Date())` 返回日期字符串
- `Symbol.toPrimitive` 可以完全自定义对象的转换行为
- 同时定义了 `valueOf`、`toString` 和 `Symbol.toPrimitive` 时，`Symbol.toPrimitive` 优先级最高

### 题目 8：`Symbol.toPrimitive` 自定义转换（高阶）

#### 题干

```javascript
const obj = {
  value: 100,
  valueOf() {
    return 0;
  },
  toString() {
    return '0';
  },
  [Symbol.toPrimitive](hint) {
    console.log(`hint: ${hint}`);
    if (hint === 'number') return this.value;
    if (hint === 'string') return `Value: ${this.value}`;
    return null;
  }
};

console.log(+obj);
console.log(`${obj}`);
console.log(obj + 1);
console.log(obj == 100);
```

#### 解题思路

`Symbol.toPrimitive` 的优先级高于 `valueOf` 和 `toString`。当定义了 `Symbol.toPrimitive` 时，对象的转换只调用该方法。

#### 正确代码实现

```javascript
// 1. +obj → hint: 'number' → 100
console.log(+obj); // 100

// 2. `${obj}` → hint: 'string' → 'Value: 100'
console.log(`${obj}`); // 'Value: 100'

// 3. obj + 1 → hint: 'default' → null → 0 + 1 → 1
//    注意：null 被转换 ToNumber 为 0
console.log(obj + 1); // 1

// 4. obj == 100 → hint: 'default' → null → 0
//    null == 100 → false（因为 null 只 == undefined）
console.log(obj == 100); // false
//    实际上这里 Hint 为 'default'，返回 null，null 不等于 100
```

#### 知识点拓展

- `Symbol.toPrimitive` 是自定义对象类型转换的**最优先方式**
- 一旦定义了 `Symbol.toPrimitive`，`valueOf` 和 `toString` 就不会被调用
- `hint` 参数有三种取值：`'number'`、`'string'`、`'default'`

## 三、易错点与最佳实践

### 常见易错点

| 易错点 | 说明 | 正确做法 |
|--------|------|---------|
| `NaN === NaN` 为 `false` | 误以为 `NaN` 等于自身 | 使用 `Number.isNaN()` 或 `Object.is()` |
| `typeof null` 为 `'object'` | JavaScript 的历史遗留 bug | 使用 `val === null` 判断 |
| `0 == ''` 为 `true` | 空字符串转数字为 0 | 使用 `===` 避免 |
| `[] == ![]` 为 `true` | 隐式转换的复杂链 | 理解转换规则，尽量使用 `===` |
| `new Boolean(false)` 为真值 | 对象永远是真值 | 使用 `Boolean(false)` 返回原始值 |
| `isNaN` 与 `Number.isNaN` 不同 | `isNaN` 会先进行类型转换 | 使用 `Number.isNaN` |

### 最佳实践

```javascript
// 1. 始终使用 === 和 !==
// ✅ 推荐
if (a === b) { /* ... */ }

// ❌ 避免
if (a == b) { /* ... */ }

// 2. 正确判断 null 和 undefined
if (val === null || val === undefined) { /* ... */ }
// 或
if (val == null) { /* ... */ } // 同时匹配 null 和 undefined

// 3. 正确判断 NaN
if (Number.isNaN(val)) { /* ... */ }
// 或
if (Object.is(val, NaN)) { /* ... */ }

// 4. 显式转换优于隐式转换
const num = Number('123'); // ✅ 明确意图
const num2 = +'123'; // 也可以，但不够明显

// 5. 比较数组/对象时，比较内容而非引用
const a = [1, 2, 3];
const b = [1, 2, 3];
console.log(a === b); // false（引用不同）

// 比较内容
console.log(JSON.stringify(a) === JSON.stringify(b)); // true

// 6. 使用 parseInt 时指定基数
parseInt('08', 10); // 8
parseInt('08'); // 0（旧浏览器将 0 开头解析为八进制）

// 7. 避免使用 == 0 或 == '' 判断
// ❌ 不明确
if (val == false) { /* ... */ }

// ✅ 明确意图
if (val === 0) { /* ... */ }
if (val === '') { /* ... */ }
```

### 类型转换总结图

```
             +, -, *, /, %
            比较运算符
                │
          ┌─────▼──────┐
          │  ToNumber   │
          └─────┬──────┘
                │
    ┌───────────┼───────────┐
    │           │           │
    ▼           ▼           ▼
  null → 0   '' → 0    true → 1
  undefined → NaN       false → 0
  '123' → 123           [] → 0
  'abc' → NaN           [1] → 1
                        [1,2] → NaN
                        {} → NaN

            字符串拼接（+）
                │
          ┌─────▼──────┐
          │  ToString   │
          └─────┬──────┘
                │
    ┌───────────┼───────────┐
    │           │           │
    ▼           ▼           ▼
  null → 'null'  0 → '0'   true → 'true'
  undefined → 'undefined'  [] → ''
  NaN → 'NaN'              [1] → '1'
                           {} → '[object Object]'

            条件判断（if, &&, ||, !）
                │
          ┌─────▼──────┐
          │ ToBoolean   │
          └─────┬──────┘
                │
          ┌─────▼──────┐
          │  假值（6个） │
          │ false      │
          │ 0          │
          │ ''         │
          │ null       │
          │ undefined  │
          │ NaN        │
          └────────────┘
          其余都是真值
```
