我一般从网络、资源、JavaScript 执行、渲染和接口几个方面优化。

首先是资源层面，通过 Gzip/Brotli、图片 WebP/AVIF、CDN、HTTP 缓存减少网络传输成本；然后通过 Tree Shaking、代码分割、路由懒加载和组件按需加载减少首屏 JS。

其次是执行层面，避免大量 JS 在首屏同步执行，非核心任务延迟到空闲时间，复杂计算可以放到 Web Worker。

渲染层面主要减少首屏 DOM，避免一次性渲染大量数据，可以使用虚拟列表、分页以及分片渲染。

接口层面则尽量并行请求核心接口，非核心接口延迟请求，同时可以使用 SSR、SSG 或骨架屏改善首屏体验。

最后通过 Chrome Performance 和 Lighthouse 观察 FCP、LCP、TTFB、TBT、CLS 等指标，定位到底是网络、JS 执行还是渲染阶段造成的瓶颈。
在 Vue 3 项目中，我会重点使用路由懒加载、异步组件、shallowRef、虚拟列表、组件按需引入，以及对 ECharts、地图 SDK 等重型依赖进行异步加载，避免它们阻塞首屏。
