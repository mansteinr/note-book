# JavaScript 异步编程模式面试题

## 一、核心概念解析

### 1. 异步编程发展历程

```
回调函数 (Callback) ──→ Promise ──→ Generator ──→ async/await
    ES5               ES6          ES6               ES2017
```

### 2. 各阶段对比

| 模式 | 优点 | 缺点 |
|------|------|------|
| 回调函数 | 简单、通用 | 回调地狱、错误处理困难、不能 return |
| Promise | 链式调用、统一错误处理 | 学习成本、不能取消 |
| Generator | 可暂停/恢复、惰性求值 | 需要手动调用 next() |
| async/await | 代码同步化、可读性强 | 需要 try/catch、不能并行 |

### 3. 异步编程的核心难题

- **控制反转**：将控制权交给异步 API，信任问题
- **错误处理**：回调中的错误无法通过 try/catch 捕获
- **代码可读性**：深层嵌套的回调难以维护
- **并发与顺序**：多个异步任务的组合与编排

## 二、面试题

### 题目 1：回调地狱与解决方案（基础）

#### 题干

有一段回调地狱代码，请分别用 Promise 和 async/await 重构：

```javascript
getUser(1, function (user) {
  getPosts(user.id, function (posts) {
    getComments(posts[0].id, function (comments) {
      console.log(comments);
    });
  });
});
```

#### 解题思路

1. 将每个回调函数包装成 Promise
2. 使用 Promise 链式调用消除嵌套
3. 使用 async/await 进一步简化

#### 正确代码实现

```javascript
// 1. 将回调函数 Promise 化
function getUser(id) {
  return new Promise((resolve, reject) => {
    // 模拟异步操作
    setTimeout(() => resolve({ id, name: 'Tom' }), 100);
  });
}

function getPosts(userId) {
  return new Promise((resolve, reject) => {
    setTimeout(() => resolve([{ id: 1, title: 'Post 1' }]), 100);
  });
}

function getComments(postId) {
  return new Promise((resolve, reject) => {
    setTimeout(() => resolve([{ id: 1, text: 'Comment 1' }]), 100);
  });
}

// 2. Promise 链式调用
getUser(1)
  .then(user => getPosts(user.id))
  .then(posts => getComments(posts[0].id))
  .then(comments => console.log(comments))
  .catch(err => console.error(err));

// 3. async/await（推荐）
async function getCommentsByUser(userId) {
  try {
    const user = await getUser(userId);
    const posts = await getPosts(user.id);
    const comments = await getComments(posts[0].id);
    console.log(comments);
    return comments;
  } catch (err) {
    console.error(err);
  }
}

getCommentsByUser(1);
```

#### 知识点拓展

- **Promise 化（Promisification）**：将回调风格转为 Promise 风格的通用模式
- Node.js 内置 `util.promisify` 工具函数
- 回调地狱的根本问题是嵌套的**控制流**，而非简单的缩进

### 题目 2：Generator 实现异步流程控制（进阶）

#### 题干

使用 Generator 函数实现一个异步流程控制函数 `runGenerator`，使其能够自动执行 Generator 函数，支持 yield 返回 Promise。

#### 解题思路

Generator 函数本身不处理异步，需要手动调用 `next()`。实现一个自动执行器：

1. 调用 `gen.next()` 获取 `{ value, done }`
2. 如果 `value` 是 Promise，则 `.then` 后传入 `next()`
3. 如果 `value` 是普通值，直接传入 `next()`
4. 递归执行直到 `done === true`

#### 正确代码实现

```javascript
// 自动执行器（类似 co 库的核心实现）
function runGenerator(genFunc) {
  return function (...args) {
    const gen = genFunc(...args);

    function step(resolve, reject) {
      const { value, done } = gen.next(resolve);

      if (done) {
        return resolve(value);
      }

      // 如果 value 是 Promise，等待其完成
      Promise.resolve(value).then(
        val => step(val, reject),
        err => gen.throw(err)
      );
    }

    return new Promise((resolve, reject) => {
      step(resolve, reject);
    });
  };
}

// 使用 Generator 写异步代码
const fetchData = runGenerator(function* (userId) {
  const user = yield new Promise(r =>
    setTimeout(() => r({ id: userId, name: 'Tom' }), 100)
  );
  console.log('User:', user);

  const posts = yield new Promise(r =>
    setTimeout(() => r([{ id: 1, title: 'Post' }]), 100)
  );
  console.log('Posts:', posts);

  return { user, posts };
});

fetchData(1).then(result => {
  console.log('Done:', result);
});

// 简易版 co 实现
function co(gen) {
  const iterator = gen();

  function handle(result) {
    if (result.done) return Promise.resolve(result.value);

    return Promise.resolve(result.value).then(
      res => handle(iterator.next(res)),
      err => handle(iterator.throw(err))
    );
  }

  return handle(iterator.next());
}
```

#### 知识点拓展

- `co` 库是 TJ 大神开发的 Generator 自动执行器，是 async/await 的前身
- Generator 的 `yield` 可以暂停函数执行，`next()` 恢复执行
- Generator 的实现依赖于**迭代器协议（Iterator Protocol）**
- async/await 本质上是 Generator + Promise + 自动执行器的语法糖

### 题目 3：async/await 错误处理模式（进阶）

#### 题干

请实现一个 `safeAsync` 高阶函数，包装异步函数使其不会抛出未捕获的异常，而是返回 `[error, result]` 的解构形式（类似 Go 语言的错误处理模式）。

#### 解题思路

将 async 函数调用包装在 try/catch 中，统一返回 `[error, data]` 元组。

#### 正确代码实现

```javascript
// 通用错误处理包装器
function safeAsync(asyncFn) {
  return async function (...args) {
    try {
      const result = await asyncFn.apply(this, args);
      return [null, result];
    } catch (error) {
      return [error, null];
    }
  };
}

// 使用示例
const safeFetch = safeAsync(async (url) => {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
});

// 使用方式类似 Go 的错误处理
const [err, data] = await safeFetch('/api/data');
if (err) {
  console.error('Failed:', err.message);
  return;
}
console.log('Data:', data);

// 多个异步操作
const safeGetUser = safeAsync(async (id) => {
  // 模拟异步
  if (id < 0) throw new Error('Invalid ID');
  return { id, name: 'Tom' };
});

const [err1, user] = await safeGetUser(1);
const [err2, posts] = await safeGetUser(2);
// 每个错误都独立处理，不会互相影响

// 批量包装
function wrapAll(asyncFns) {
  return asyncFns.map(safeAsync);
}
```

#### 知识点拓展

- Go 语言错误处理模式的优点：**错误显式**，不会被忽略
- 与 `try/catch` 相比，`[err, data]` 模式强制调用方处理错误
- 避免 `try/catch` 嵌套过深的问题
- 适合多个独立异步操作需要各自处理错误的场景

### 题目 4：异步任务的取消（进阶）

#### 题干

实现一个可取消的异步任务。假设有一个耗时操作（如延迟 5 秒），要求在 2 秒内如果执行了取消操作，则任务提前终止。

#### 解题思路

1. 使用 `AbortController` 是标准方案
2. 也可以使用 Promise 的竞速机制，将取消信号作为一个 Promise

#### 正确代码实现

```javascript
// 方案一：使用 AbortController（推荐）
function createCancellableTask() {
  const controller = new AbortController();
  const { signal } = controller;

  const task = new Promise((resolve, reject) => {
    // 监听取消信号
    signal.addEventListener('abort', () => {
      reject(new DOMException('Task cancelled', 'AbortError'));
    });

    // 模拟耗时操作
    setTimeout(() => {
      if (!signal.aborted) {
        resolve('Task completed');
      }
    }, 5000);
  });

  return {
    task,
    cancel: () => controller.abort()
  };
}

// 使用
const { task, cancel } = createCancellableTask();
task.then(console.log).catch(err => console.log(err.message));

setTimeout(() => {
  cancel(); // 2 秒后取消
  console.log('Cancelled!');
}, 2000);

// 方案二：手动实现取消 Promise
function cancellablePromise(executor) {
  let cancelFn = null;

  const promise = new Promise((resolve, reject) => {
    cancelFn = () => {
      reject(new Error('Cancelled'));
    };

    executor(resolve, reject, cancelFn);
  });

  return { promise, cancel: cancelFn };
}

// 使用
const { promise, cancel } = cancellablePromise((resolve, reject, onCancel) => {
  const timer = setTimeout(() => resolve('Done'), 5000);

  // 注册取消时的清理逻辑
  onCancel(() => {
    clearTimeout(timer);
    console.log('Cleanup done');
  });
});

promise.catch(err => console.log(err.message));
setTimeout(() => cancel(), 2000); // 2 秒后取消
```

#### 知识点拓展

- `AbortController` 是浏览器标准 API，可用于取消 `fetch` 请求
- 取消的 Promise 会进入 `rejected` 状态，需要 `.catch` 处理
- 取消时注意清理资源（定时器、事件监听器等）
- 并非所有异步操作都能被取消（如 `setTimeout` 本身不支持取消，需要用 `clearTimeout`）

### 题目 5：实现异步队列（高阶）

#### 题干

实现一个 `AsyncQueue` 类，支持：
1. 添加异步任务（入队）
2. 按顺序执行任务（串行）
3. 支持限制并发数
4. 支持任务完成后的回调

#### 解题思路

使用队列数据结构管理任务，维护 `running` 计数控制并发。

#### 正确代码实现

```javascript
class AsyncQueue {
  constructor(concurrency = 1) {
    this.concurrency = concurrency;
    this.queue = [];
    this.running = 0;
    this.completed = 0;
    this.total = 0;
    this.onComplete = null;
  }

  addTask(task) {
    this.queue.push(task);
    this.total++;
    this._process();
    return this;
  }

  addTasks(tasks) {
    tasks.forEach(task => this.addTask(task));
    return this;
  }

  onAllCompleted(callback) {
    this.onComplete = callback;
    return this;
  }

  _process() {
    while (this.running < this.concurrency && this.queue.length > 0) {
      const task = this.queue.shift();
      this.running++;

      Promise.resolve()
        .then(() => task())
        .then(result => {
          this._onTaskComplete(result);
        })
        .catch(error => {
          this._onTaskComplete(null, error);
        });
    }
  }

  _onTaskComplete(result, error) {
    this.running--;
    this.completed++;

    if (error) {
      console.error('Task failed:', error);
    }

    this._process();

    // 所有任务完成
    if (this.completed === this.total && this.onComplete) {
      this.onComplete();
    }
  }

  get progress() {
    return `${this.completed}/${this.total}`;
  }

  get isBusy() {
    return this.running >= this.concurrency;
  }
}

// 使用示例
const queue = new AsyncQueue(2); // 并发 2

const tasks = [
  () => new Promise(r => setTimeout(() => { console.log('Task 1'); r(); }, 1000)),
  () => new Promise(r => setTimeout(() => { console.log('Task 2'); r(); }, 500)),
  () => new Promise(r => setTimeout(() => { console.log('Task 3'); r(); }, 800)),
  () => new Promise(r => setTimeout(() => { console.log('Task 4'); r(); }, 300)),
];

queue
  .addTasks(tasks)
  .onAllCompleted(() => {
    console.log('All tasks completed!');
  });

// 控制台输出：
// （同时开始 Task 1 和 Task 2）
// Task 2 完成（500ms）→ 开始 Task 3
// Task 4 完成（300ms）→ Task 4 入队
// Task 1 完成（1000ms）→ 开始 Task 4
// Task 3 完成（800ms）
// Task 4 完成
// All tasks completed!
```

#### 知识点拓展

- 异步队列是**生产者-消费者模式**的典型应用
- 并发控制的核心是维护 `running` 计数和 `queue` 队列
- 实际项目中可使用 `p-limit`、`async.queue` 等成熟库
- 队列的优先级、超时、重试等扩展功能是可考察的点

### 题目 6：Promise 化异步边界操作（高阶）

#### 题干

实现一个 `promisify` 工具函数，将 Node.js 风格的**回调函数**（最后一个参数为 callback，签名为 `(err, result) => void`）转换为 Promise 风格的函数。

#### 解题思路

核心思路：返回一个包装函数，该函数调用原始函数，但将 callback 替换为 Promise 的 resolve/reject 逻辑。

#### 正确代码实现

```javascript
function promisify(fn) {
  return function (...args) {
    return new Promise((resolve, reject) => {
      fn.call(this, ...args, (err, result) => {
        if (err) {
          reject(err);
        } else {
          resolve(result);
        }
      });
    });
  };
}

// 使用示例
const fs = require('fs');

// 传统回调方式
fs.readFile('test.txt', 'utf-8', (err, data) => {
  if (err) return console.error(err);
  console.log(data);
});

// Promise 化
const readFileAsync = promisify(fs.readFile);
readFileAsync('test.txt', 'utf-8')
  .then(data => console.log(data))
  .catch(err => console.error(err));

// 支持多参数结果的 promisify（如 fs.exists 的 callback 有多个参数）
function promisifyAll(fn) {
  return function (...args) {
    return new Promise((resolve, reject) => {
      fn.call(this, ...args, (err, ...results) => {
        if (err) {
          reject(err);
        } else {
          resolve(results.length === 1 ? results[0] : results);
        }
      });
    });
  };
}

// 批量 promisify 对象上的所有方法
function promisifyMethods(obj, methodNames) {
  return methodNames.reduce((result, methodName) => {
    if (typeof obj[methodName] === 'function') {
      result[methodName] = promisify(obj[methodName].bind(obj));
    }
    return result;
  }, {});
}

// Node.js 内置的 util.promisify
const { promisify: nodePromisify } = require('util');
const readFile = nodePromisify(fs.readFile);
```

#### 知识点拓展

- Node.js 内置 `util.promisify` 已经实现了此功能
- 回调函数约定：**error-first**（第一个参数是错误对象，第二个是结果）
- 注意 `this` 绑定问题：`promisify` 后的函数需要保持 `this` 指向
- `promisify` 是"适配器模式"的典型应用

### 题目 7：实现 Pipeline 异步流程编排（高阶）

#### 题干

实现一个 `asyncPipeline` 函数，将多个异步函数按顺序组合成一个管道（Pipeline），前一个函数的输出作为后一个函数的输入。

#### 解题思路

类似函数组合（Compose），但处理的是异步函数。使用 `reduce` 或 `for...of` 串行执行。

#### 正确代码实现

```javascript
// 从左到右执行（Pipe）
function asyncPipeline(...fns) {
  return async function (input) {
    let result = input;
    for (const fn of fns) {
      result = await fn(result);
    }
    return result;
  };
}

// 从右到左执行（Compose）
function asyncCompose(...fns) {
  return async function (input) {
    let result = input;
    for (let i = fns.length - 1; i >= 0; i--) {
      result = await fns[i](result);
    }
    return result;
  };
}

// 使用示例
const validateInput = async (input) => {
  if (!input || !input.id) throw new Error('Invalid input');
  return input;
};

const fetchUser = async (input) => {
  // 模拟异步请求
  const user = { id: input.id, name: 'Tom', score: 85 };
  return { ...input, user };
};

const calculateLevel = async (data) => {
  const level = data.user.score >= 80 ? 'A' : 'B';
  return { ...data, level };
};

const formatResponse = async (data) => {
  return {
    userId: data.user.id,
    name: data.user.name,
    level: data.level,
    timestamp: Date.now()
  };
};

// 组合管道
const processUser = asyncPipeline(
  validateInput,
  fetchUser,
  calculateLevel,
  formatResponse
);

// 执行
processUser({ id: 1 })
  .then(result => console.log(result))
  .catch(err => console.error(err));
// 输出: { userId: 1, name: 'Tom', level: 'A', timestamp: ... }

// 条件分支管道
function asyncPipelineWithCondition(condition, truePipe, falsePipe) {
  return async function (input) {
    const result = condition(input);
    if (result) {
      return await truePipe(input);
    } else {
      return await falsePipe(input);
    }
  };
}
```

#### 知识点拓展

- **Pipeline 模式**源于 Unix 管道思想，广泛应用于函数式编程
- 与 `Promise 链` 相比，Pipeline 更强调函数的**组合性**和**可复用性**
- 实际框架中的应用：Express/Koa 的中间件、Webpack 的 loader
- 错误处理需要在 Pipeline 中逐层传递

## 三、易错点与最佳实践

### 常见易错点

| 易错点 | 说明 | 正确做法 |
|--------|------|---------|
| 忘记 await | 漏写 `await` 导致获取到 Promise 对象 | 始终使用 `await` 或 `.then` |
| 串行执行并行任务 | 用 `await` 在循环中逐个执行独立任务 | 使用 `Promise.all` 并行执行 |
| 忽略 try/catch | async 函数中抛出的异常未被捕获 | 使用 `try/catch` 包裹 await 表达式 |
| 在 forEach 中使用 async | `forEach` 不等待 async 回调完成 | 使用 `for...of` 或 `Promise.all` |
| 回调中调用同步 return | 错误地以为回调中可以 return 结果 | 使用 Promise 或 callback 传递结果 |

### 最佳实践

```javascript
// 1. 优先使用 async/await
// ✅ 推荐
async function fetchData() {
  const data = await fetch('/api');
  return data.json();
}

// ❌ 避免
function fetchData() {
  return fetch('/api').then(res => res.json());
}

// 2. 并行任务使用 Promise.all
const [users, posts] = await Promise.all([
  fetch('/api/users').then(r => r.json()),
  fetch('/api/posts').then(r => r.json())
]);

// 3. 循环中的异步操作
// ❌ forEach 不等待
items.forEach(async item => {
  await process(item);
});

// ✅ 串行 for...of
for (const item of items) {
  await process(item);
}

// ✅ 并行 Promise.all
await Promise.all(items.map(item => process(item)));

// 4. 错误处理统一化
function handleErrors(fn) {
  return async function (...args) {
    try {
      return await fn.apply(this, args);
    } catch (err) {
      console.error(`Error in ${fn.name}:`, err);
      throw err;
    }
  };
}

// 5. 异步函数的超时保护
async function withTimeout(promise, ms) {
  const timeout = new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Timeout')), ms)
  );
  return Promise.race([promise, timeout]);
}
```

### 异步模式选择指南

```
需要简单的异步操作？
  → 使用 async/await

需要处理多个并发的异步操作？
  → 使用 Promise.all / Promise.allSettled

需要顺序执行但避免嵌套？
  → 使用 async/await + for 循环

需要控制并发数量？
  → 使用 asyncPool 或 AsyncQueue

需要取消异步操作？
  → 使用 AbortController

需要暂存 Generator 的执行状态？
  → 使用 Generator + co 自动执行器

需要组合多个异步函数？
  → 使用 asyncPipeline 模式
```
