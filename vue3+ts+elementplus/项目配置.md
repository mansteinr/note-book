### eslint 

  安装
  ```
  npm install eslint --save-dev
  ```

  检查安装版本号

  ```
  npx eslint --version
  ```

  自动生成配置文件
  ```
  npm init @eslint/config
  ```

  运行命令行后 会生成.eslintrc.cjs文件 如果需要配置规则 可以在里面添加rules
