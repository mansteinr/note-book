## 一、基础概念题（6题）

### Q1：什么是意图识别？其在 NLP 中的定位是什么？

**难度级别**：初级
**考察维度**：概念理解

**问题描述**：
请阐述意图识别的定义，并说明它在对话系统、智能客服等 NLP 应用中的定位与核心价值。

**参考答案**：

```
定义:
  意图识别是从用户输入的自然语言文本中，识别出用户真实意图或目的的任务。
  本质上是一个文本分类问题：输入用户话语，输出预定义的意图类别。

  示例:
    "我想订一张明天去北京的机票" → 意图: 订机票（BookTicket）
    "今天天气怎么样"           → 意图: 查天气（CheckWeather）

NLP 应用定位:
  用户输入 → [意图识别] → [槽位填充] → [对话管理] → [响应生成]
  
  • 意图识别: 判断"用户想做什么"（What）
  • 槽位填充: 提取"关键参数"（如时间、地点）

核心价值:
  1. 路由分发: 根据意图将请求路由到对应处理模块
  2. 任务触发: 确定执行哪个业务流程
  3. 体验优化: 理解意图后才能给出准确响应
  4. 降本增效: 自动化处理高频咨询，减少人工
```

**评分标准**：
- 3分：能准确说出意图识别的定义
- 4分：能说明其在 NLP 流水线中的定位
- 5分：能列举多种应用场景并说明核心价值

### Q2：意图识别与文本分类的关系？有何异同？

**难度级别**：初级
**考察维度**：概念辨析

**问题描述**：
意图识别常被视为文本分类的子任务。请说明两者的关系，并指出意图识别的特殊性。

**参考答案**：

```
关系: 意图识别是文本分类的特定应用场景，本质相同（分类问题）。

不同点（意图识别的特殊性）:
  1. 输入长度: 意图识别通常短（5~20字），文本分类可能很长
  2. 类别特性: 意图间可能重叠（"订机票" vs "订酒店"）
  3. 数据分布: 意图识别长尾分布明显（少数意图占多数流量）
  4. 实时性: 意图识别通常需实时响应（<100ms）
  5. 多意图: 用户一句话可能含多个意图
     "帮我订机票，顺便查下天气" → [订机票, 查天气]
  6. 意图演进: 业务发展需频繁新增意图
  7. OOV 问题: 用户口语化、错别字、省略多
```

**评分标准**：
- 3分：能说明两者本质相同
- 4分：能指出 3 个以上差异点
- 5分：能分析多意图、长尾分布、实时性等深层差异

### Q3：意图识别的常见评估指标有哪些？

**难度级别**：初级
**考察维度**：评估方法

**问题描述**：
请列举意图识别任务中常用的评估指标，并说明类别不平衡场景下如何选择指标。

**参考答案**：

```
常用指标:
  1. 准确率（Accuracy）: 正确/总数（不平衡时虚高）
  2. 精确率（Precision）: TP/(TP+FP)
  3. 召回率（Recall）: TP/(TP+FN)
  4. F1-Score: P和R的调和平均
  5. Macro-F1: 各类别F1的算术平均（适合不平衡）
  6. Micro-F1: 全局计算（受大类影响）
  7. 混淆矩阵: 可视化意图间混淆

类别不平衡处理:
  评估: ❌ Accuracy → ✅ Macro-F1 + 每类别P/R/F1
  数据: 过采样、欠采样、SMOTE、数据增强
  算法: 类权重、Focal Loss、阈值调整
  方法: 分层抽样、分类别评估、长尾分析
```

**评分标准**：
- 3分：能说出 Accuracy、Precision、Recall、F1
- 4分：能区分 Macro-F1 和 Micro-F1
- 5分：能给出类别不平衡的三层处理方案

### Q5：意图识别中的多标签问题如何处理？

**难度级别**：中级
**考察维度**：问题分析

**问题描述**：
用户一句话可能含多个意图。请给出解决方案。

**参考答案**：

```
方案 1: Multi-label 分类
  • 输出层用 Sigmoid（非 Softmax），每意图独立二分类
  • 损失: Binary Cross Entropy

方案 2: 序列标注
  • 分段标注意图: "订机票 | 顺便 | 查天气"
     BookTicket  O    CheckWeather

方案 3: 先分割后分类
  • 分句 → 每句独立分类 → 合并结果

方案 4: 生成式（LLM）
  • Prompt: "识别以下文本的所有意图: {text}"

评估: Exact Match / Hamming Loss / Micro-Macro F1
```

**评分标准**：
- 3分：能区分单/多意图问题
- 4分：能给出 Multi-label 和分割方案
- 5分：能对比四种方案并给出评估指标

### Q6：意图识别中的 OOV 问题如何解决？

**难度级别**：中级
**考察维度**：问题分析

**问题描述**：
用户输入常有口语化、新词、错别字。请说明解决方案。

**参考答案**：

```
OOV 来源: 网络用语、口语、错别字、品牌新词

解决方案:
  1. 子词分词: BPE/WordPiece，"绝绝子"→["绝","绝","子"]
  2. 字符级特征: 中文天然适合字符级
  3. 数据增强: 同义替换、回译、随机噪声
  4. 文本归一化: 繁简转换、错别字纠正
  5. 预训练模型: BERT/GPT 预训练见过大量词汇
  6. 持续学习: 定期挖掘新词，更新词表
```

**评分标准**：
- 3分：能说出子词分词、数据增强
- 4分：能提及文本归一化和预训练模型
- 5分：能给出持续学习方案和分层防御策略

### Q7：请设计一个基于 BERT 的意图识别系统

**难度级别**：中级

```
模型结构:
  [CLS] 用户文本 [SEP] → BERT(12层) → [CLS]向量(768维) 
  → Linear(768,20)+Dropout → Softmax → 意图

代码示意:
  from transformers import BertForSequenceClassification, Trainer
  
  model = BertForSequenceClassification.from_pretrained(
      'bert-base-chinese', num_labels=20)

  trainer.train()

推理优化:
  1. 量化: FP32→FP16/INT8，延迟降2~4倍
  2. 蒸馏: BERT-base→6层Student
  3. ONNX/TensorRT加速
  4. 批处理+缓存

预期: 准确率90%+ | 延迟<50ms(GPU) | QPS 100+
```

### Q8：如何处理意图识别中的冷启动问题？

**难度级别**：中级
**考察维度**：系统设计

**问题描述**：
新业务上线时没有标注数据。请设计冷启动方案。

**参考答案**：

```
分阶段冷启动:

阶段 1: 规则+零样本（0数据）
  • 梳理核心意图（5~10个）
  • 关键词/正则规则匹配
  • LLM零样本: "判断文本属于哪个意图: {候选列表}"

阶段 2: 少样本学习（<100条/意图）
  • 数据增强: LLM生成同义表达、回译
  • Few-shot: Prototypical Networks（原型向量最近邻）
  • Prompt Tuning: 冻结BERT，只训练Prompt向量

阶段 3: 主动学习（数据积累）
  • 不确定性采样: 选模型最不确定的样本
  • 人工审核闭环: 低置信度→人工标注→扩充训练集

阶段 4: 全量监督（>1000条/意图）
  • BERT微调 + 评估体系 + A/B测试

架构: 规则匹配(高置信→输出) → ML模型(高置信→输出) → 兜底(转人工)
     所有记录 → 筛选高价值样本 → 人工标注 → 扩充训练集
```

**评分标准**：
- 3分：能提出规则启动和数据增强
- 4分：能设计少样本学习和主动学习
- 5分：能给出分阶段方案和架构图

### Q9：设计一个支持新意图动态扩展的系统

**难度级别**：高级
**考察维度**：系统设计

**问题描述**：
业务需频繁新增意图。请设计动态扩展系统，避免全量重训。

**参考答案**：

```
架构: 基座模型(冻结) + 意图向量库

  用户输入 → BERT编码(冻结) → 意图向量库 → 最近邻匹配 → 置信度判断

核心思想:
  • 基座模型只负责"文本→向量"
  • 意图识别 = 向量最近邻
  • 新增意图 = 加几条样本向量，无需重训

实现:
  1. 基座模型训练: 对比学习，同类文本映射到相近向量
  2. 原型向量: 每意图5~20条样本编码取平均
     intent_vec = mean([bert(text) for text in samples])
  3. 推理: cosine相似度最近邻
  4. 新增意图: 收集样本→计算原型→加入向量库

混合架构:
  层1: 高频意图用BERT分类器（快、准）
  层2: 长尾/新意图用向量检索（灵活）
  层3: 低置信度转人工

技术选型: BERT/Sentence-BERT + Faiss/Milvus
优势: 新意图小时级上线 | 不影响现有意图 | 无需重训
```

**评分标准**：
- 3分：能提出"基座模型+向量检索"思路
- 4分：能说明原型向量和增量更新
- 5分：能设计混合架构并分析优势

### Q10：如何设计多轮对话中的意图识别系统？

**难度级别**：高级
**考察维度**：系统设计

**问题描述**：
多轮对话中意图可能随对话演进。请设计考虑上下文的系统。

**参考答案**：

```
挑战:
  轮次1: "订去北京的机票" → BookTicket
  轮次2: "明天下午的"     → 补充时间（不是新意图）
  轮次3: "算了，改订高铁"  → 意图切换 BookTrain
  轮次4: "同样明天下午"    → 复用上下文

方案 1: 上下文拼接
  input = "[轮次1]订机票 [轮次2]明天下午 [当前]改订高铁"
  → BERT分类（缺点: 长对话超窗口）

方案 2: 注意力机制
  query = encode(current)
  context = encode(history)
  fused = cross_attention(query, context)
  intent = classifier(fused)

方案 3: 意图状态追踪
  intent_dist[t] = α×classify(current) + (1-α)×intent_dist[t-1]
  α大: 更信当前（可能切换） | α小: 更信历史（补充）

方案 4: 分层决策
  Step1: 判断是否切换（"算了"、"改"→切换）
  Step2: 切换→重新分类 | 补充→保持当前意图

决策器:
  conf>high → 新意图
  is_supplemental → 继续当前
  else → 澄清
```

**评分标准**：
- 3分：能说明多轮对话挑战
- 4分：能给出上下文融合方案
- 5分：能设计意图状态追踪和分层决策

### Q11：设计一个意图识别的 A/B 测试方案

**难度级别**：中级
**考察维度**：工程实践

**问题描述**：
优化了模型v2，想替换线上v1。请设计A/B测试方案。

**参考答案**：

```
实验设计:
  1. 流量: 控制组(v1) 50% / 实验组(v2) 50%，按user_id hash
  2. 周期: 1~2周，每组>10000样本
  3. 指标:
     • 主指标: 准确率（人工标注抽样）
     • 辅助: 任务完成率、满意度、转人工率、延迟
     • 护栏: 延迟不增加、错误率不上升
  4. 分层: 按意图/用户/时段/输入长度分析

统计检验: Z检验，p<0.05，95%CI
  示例: v1 85% vs v2 88%, p=0.002 → 显著

决策:
  上线: 主指标显著提升 + 分层无下降 + 护栏无恶化 + 延迟增<20ms
  下线: 主指标下降 / 护栏恶化 / 严重Bad Case

流程: 离线评估→影子模式→小流量(5%→10%→50%)→全量→监控
注意: 避免新奇效应、Simpson悖论、确保分流均匀(SRM检验)
```

**评分标准**：
- 3分：能设计基本A/B流程
- 4分：能定义主指标和护栏指标
- 5分：能给出统计检验和决策标准

### Q13：智能客服如何区分"闲聊"与"业务意图"？

**难度级别**：中级
**考察维度**：场景应用

**问题描述**：
用户既问业务（如"如何退款"）也闲聊（如"你是机器人吗"）。请设计方案。

**参考答案**：

```
两层架构:
  用户输入 → 层1:闲聊检测(二分类)
           → 闲聊: 闲聊应答
           → 业务: 层2:意图识别

层1闲聊检测:
  • 规则: 关键词"你好"、"你是谁"、"笑话"
  • 模型: BERT/FastText 二分类
  • LLM: "判断输入是业务还是闲聊"

混合输入处理: "退款怎么办，对了你叫什么"
  • 分句: ["退款怎么办","你叫什么"] → [业务,闲聊]
  • 多标签: 同时识别 [Refund, Chitchat]
  • 优先级: 业务优先，闲聊延后

闲聊应答:
  • 简单: 模板回复
  • 复杂: LLM生成
  • 拒绝: "我们还是聊聊您的订单吧"

评估: 闲聊识别率 / 业务误杀率（重要！） / 整体准确率
```

**评分标准**：
- 3分：能提出两层架构
- 4分：能处理混合输入
- 5分：能给出工程实现和评估指标

**难度级别**：高级

**参考答案**：

```python
import re
from typing import List, Dict, Tuple

class RuleBasedIntentRecognizer:
    """基于规则的意图识别器"""
    
    def __init__(self):
        self.keyword_rules: Dict[str, List[str]] = {
            "BookTicket": ["订机票", "买机票", "预订航班"],
            "CheckWeather": ["天气", "温度", "下雨"],
            "CancelOrder": ["取消订单", "退订"],
        }
        self.regex_rules: Dict[str, List[str]] = {
            "BookTicket": [r"订.*机票", r"买.*机票"],
            "CheckWeather": [r"(今天|明天).*(天气|温度)"],
            "CancelOrder": [r"取消.*(订单|预订)"],
        }
    
    def recognize(self, text: str) -> List[Tuple[str, float]]:
        """识别意图，返回 [(intent, confidence), ...]"""
        scores = {}
        
        # 关键词匹配（权重0.6）
        for intent, keywords in self.keyword_rules.items():
            for kw in keywords:
                if kw in text:
                    scores[intent] = scores.get(intent, 0) + 0.6
        
        # 正则匹配（权重0.4）
        for intent, patterns in self.regex_rules.items():
            for pattern in patterns:
                if re.search(pattern, text):
                    scores[intent] = scores.get(intent, 0) + 0.4
        
        # 归一化
        total = sum(scores.values())
        if total == 0:
            return [("Unknown", 0.0)]
        
        results = [(k, v/total) for k, v in scores.items()]
        results.sort(key=lambda x: -x[1])
        return results
    
    def add_intent(self, intent: str, keywords: List[str], 
                   patterns: List[str] = None):
        """动态添加意图"""
        self.keyword_rules[intent] = keywords
        if patterns:
            self.regex_rules[intent] = patterns
```

### Q20：实现 TF-IDF + SVM 意图分类器

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report
import jieba
import numpy as np
from typing import List, Tuple
import pickle


def tokenize(text: str) -> List[str]:
    """中文分词"""
    return list(jieba.cut(text))


class TfidfSvmIntentClassifier:
    """TF-IDF + SVM 意图分类器"""
    
    def __init__(self):
        self.pipeline = Pipeline([
            ('tfidf', TfidfVectorizer(
                tokenizer=tokenize, token_pattern=None,
                ngram_range=(1, 2), max_features=10000, min_df=2,
            )),
            ('clf', LinearSVC(C=1.0, class_weight='balanced'))
        ])
        self.intents = []
    
    def train(self, texts: List[str], labels: List[str]):
        """训练模型"""
        X_train, X_test, y_train, y_test = train_test_split(
            texts, labels, test_size=0.2, random_state=42, stratify=labels
        )
        self.pipeline.fit(X_train, y_train)
        self.intents = sorted(set(labels))
        
        y_pred = self.pipeline.predict(X_test)
        print(classification_report(y_test, y_pred))
    
    def predict(self, text: str) -> Tuple[str, float]:
        """预测意图"""
        scores = self.pipeline.decision_function([text])[0]
        exp_scores = np.exp(scores - np.max(scores))
        probs = exp_scores / exp_scores.sum()
        
        best_idx = np.argmax(probs)
        return self.intents[best_idx], probs[best_idx]
    
    def predict_topk(self, text: str, k: int = 3) -> List[Tuple[str, float]]:
        """Top-K 意图"""
        scores = self.pipeline.decision_function([text])[0]
        exp_scores = np.exp(scores - np.max(scores))
        probs = exp_scores / exp_scores.sum()
        topk_idx = np.argsort(probs)[::-1][:k]
        return [(self.intents[i], probs[i]) for i in topk_idx]
    
    def save(self, path: str):
        with open(path, 'wb') as f:
            pickle.dump({'pipeline': self.pipeline, 
                        'intents': self.intents}, f)
    
    def load(self, path: str):
        with open(path, 'rb') as f:
            data = pickle.load(f)
            self.pipeline = data['pipeline']
            self.intents = data['intents']
```

**参考答案**：

```python
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
from transformers import BertTokenizer, BertModel, AdamW
from transformers import get_linear_schedule_with_warmup
from sklearn.metrics import f1_score
from typing import List, Tuple, Dict


class IntentDataset(Dataset):
    def __init__(self, texts, labels, tokenizer, max_len=64):
        self.texts, self.labels = texts, labels
        self.tokenizer, self.max_len = tokenizer, max_len
    
    def __len__(self):
        return len(self.texts)
    
    def __getitem__(self, idx):
        encoding = self.tokenizer.encode_plus(
            self.texts[idx], max_length=self.max_len,
            padding='max_length', truncation=True,
            return_attention_mask=True, return_tensors='pt'
        )
        return {
            'input_ids': encoding['input_ids'].flatten(),
            'attention_mask': encoding['attention_mask'].flatten(),
            'label': torch.tensor(self.labels[idx], dtype=torch.long)
        }


class BertIntentClassifier(nn.Module):
    def __init__(self, model_name, num_intents, dropout=0.1):
        super().__init__()
        self.bert = BertModel.from_pretrained(model_name)
        self.dropout = nn.Dropout(dropout)
        self.classifier = nn.Linear(self.bert.config.hidden_size, num_intents)
    
    def forward(self, input_ids, attention_mask):
        outputs = self.bert(input_ids=input_ids, 
                           attention_mask=attention_mask)
        cls_output = outputs.pooler_output
        return self.classifier(self.dropout(cls_output))


class IntentTrainer:
    def __init__(self, model, tokenizer, device='cuda', lr=2e-5):
        self.model = model.to(device)
        self.tokenizer = tokenizer
        self.device = device
        self.optimizer = AdamW(model.parameters(), lr=lr, weight_decay=0.01)
        self.criterion = nn.CrossEntropyLoss()
    
    def train(self, train_loader, val_loader, epochs=3):
        total_steps = len(train_loader) * epochs
        scheduler = get_linear_schedule_with_warmup(
            self.optimizer, num_warmup_steps=total_steps // 10,
            num_training_steps=total_steps
        )
        
        best_f1 = 0
        for epoch in range(epochs):
            self.model.train()
            total_loss = 0
            for batch in train_loader:
                ids = batch['input_ids'].to(self.device)
                mask = batch['attention_mask'].to(self.device)
                labels = batch['label'].to(self.device)
                
                self.optimizer.zero_grad()
                logits = self.model(ids, mask)
                loss = self.criterion(logits, labels)
                loss.backward()
                torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
                self.optimizer.step()
                scheduler.step()
                total_loss += loss.item()
            
            val_f1 = self.evaluate(val_loader)
            print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f}, "
                  f"val_f1={val_f1:.4f}")
            
            if val_f1 > best_f1:
                best_f1 = val_f1
                torch.save(self.model.state_dict(), 'best_model.pt')
        return best_f1
    
    def evaluate(self, val_loader):
        self.model.eval()
        preds, truths = [], []
        with torch.no_grad():
            for batch in val_loader:
                ids = batch['input_ids'].to(self.device)
                mask = batch['attention_mask'].to(self.device)
                labels = batch['label']
                logits = self.model(ids, mask)
                preds.extend(torch.argmax(logits, dim=1).cpu().numpy())
                truths.extend(labels.numpy())
        return f1_score(truths, preds, average='macro')
    
    def predict(self, text, intent2id):
        self.model.eval()
        encoding = self.tokenizer.encode_plus(
            text, max_length=64, padding='max_length',
            truncation=True, return_tensors='pt'
        )
        with torch.no_grad():
            logits = self.model(
                encoding['input_ids'].to(self.device),
                encoding['attention_mask'].to(self.device)
            )
            probs = torch.softmax(logits, dim=1)
            conf, pred = torch.max(probs, dim=1)
        
        id2intent = {v: k for k, v in intent2id.items()}
        return id2intent[pred.item()], conf.item()


# 使用
```

### Q22：实现基于原型网络的 Few-shot 意图识别器

**难度级别**：高级
**考察维度**：Few-shot 学习

**问题描述**：
实现 Prototypical Networks 的 Few-shot 意图识别器，支持动态注册新意图。

**参考答案**：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from transformers import BertModel, BertTokenizer
from typing import List, Dict, Tuple


class PrototypicalIntentRecognizer:
    """基于原型网络的 Few-shot 意图识别器"""
    
    def __init__(self, model_name='bert-base-chinese'):
        self.encoder = BertModel.from_pretrained(model_name)
        self.encoder.eval()
        self.tokenizer = BertTokenizer.from_pretrained(model_name)
        self.intent_samples: Dict[str, List[str]] = {}
        self.prototypes: Dict[str, torch.Tensor] = {}
    
    def register_intent(self, intent: str, samples: List[str]):
        """注册新意图（少样本，5~20条）"""
        self.intent_samples[intent] = samples
        self._update_prototype(intent)
    
    def _encode(self, text: str) -> torch.Tensor:
        """编码文本为向量"""
        encoding = self.tokenizer.encode_plus(
            text, max_length=64, padding='max_length',
            truncation=True, return_tensors='pt'
        )
        with torch.no_grad():
            output = self.encoder(
                input_ids=encoding['input_ids'],
                attention_mask=encoding['attention_mask']
            )
        return output.pooler_output.squeeze()  # [hidden]
    
    def _update_prototype(self, intent: str):
        """更新意图原型向量（样本均值）"""
        samples = self.intent_samples[intent]
        embeddings = [self._encode(s) for s in samples]
        self.prototypes[intent] = torch.mean(
            torch.stack(embeddings), dim=0)
    
    def predict(self, text: str, threshold: float = 0.5) -> Tuple[str, float]:
        """预测意图"""
        query_emb = self._encode(text)
        
        # 计算与每个原型的余弦相似度
        similarities = {}
        for intent, proto in self.prototypes.items():
            sim = F.cosine_similarity(query_emb, proto, dim=0)
            similarities[intent] = sim.item()
        
        best_intent = max(similarities, key=similarities.get)
        confidence = similarities[best_intent]
        
        if confidence < threshold:
            return "Unknown", confidence
        return best_intent, confidence
    
    def predict_topk(self, text: str, k: int = 3) -> List[Tuple[str, float]]:
        """Top-K 意图"""
        query_emb = self._encode(text)
        sims = [(intent, F.cosine_similarity(
            query_emb, proto, dim=0).item())
                for intent, proto in self.prototypes.items()]
        sims.sort(key=lambda x: -x[1])
        return sims[:k]
```

### Q23：实现意图识别的置信度校准（温度缩放）

**难度级别**：高级
**考察维度**：工程实践

**问题描述**：
模型置信度往往偏高。请实现温度缩放校准方法。

**参考答案**：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from typing import Tuple


class TemperatureScaling:
    """温度缩放置信度校准"""
    
    def __init__(self):
        self.temperature = nn.Parameter(torch.ones(1) * 1.5)
    
    def fit(self, logits: torch.Tensor, labels: torch.Tensor,
            max_iter: int = 100, lr: float = 0.01):
        """在验证集上学习最佳温度"""
        optimizer = torch.optim.LBFGS(
            [self.temperature], lr=lr, max_iter=max_iter)
        
        def closure():
            optimizer.zero_grad()
            loss = F.cross_entropy(logits / self.temperature, labels)
            loss.backward()
            return loss
        
        optimizer.step(closure)
        print(f"校准温度: {self.temperature.item():.4f}")
    
    def calibrate(self, logits: torch.Tensor) -> torch.Tensor:
        """校准置信度"""
        return F.softmax(logits / self.temperature, dim=-1)


def compute_ece(confidences, predictions, labels, n_bins=10):
    """计算期望校准误差（ECE）"""
    accuracies = (predictions == labels).astype(float)
    bin_boundaries = np.linspace(0, 1, n_bins + 1)
    ece = 0.0
    
    for i in range(n_bins):
        mask = ((confidences > bin_boundaries[i]) & 
                (confidences <= bin_boundaries[i + 1]))
        if mask.sum() > 0:
            bin_conf = confidences[mask].mean()
            bin_acc = accuracies[mask].mean()
            ece += (mask.sum() / len(confidences)) * abs(bin_conf - bin_acc)
    return ece


class CalibratedPredictor:
    """带校准的意图预测器"""
    
    def __init__(self, model, tokenizer, intent2id):
        self.model = model
        self.tokenizer = tokenizer
        self.intent2id = intent2id
        self.id2intent = {v: k for k, v in intent2id.items()}
        self.calibrator = None
    
    def get_logits(self, text):
        encoding = self.tokenizer.encode_plus(
            text, max_length=64, padding='max_length',
            truncation=True, return_tensors='pt')
        with torch.no_grad():
            return self.model(
                encoding['input_ids'], encoding['attention_mask']).squeeze()
    
    def predict(self, text, threshold=0.5):
        logits = self.get_logits(text)
        if self.calibrator:
            probs = self.calibrator.calibrate(logits.unsqueeze(0)).squeeze()
        else:
            probs = F.softmax(logits, dim=-1)
        
        conf, pred_id = torch.max(probs, dim=-1)
        if conf.item() < threshold:
            return "Unknown", conf.item()
        return self.id2intent[pred_id.item()], conf.item()
    
    def calibrate_on_validation(self, texts, labels):
        """在验证集上校准"""
        if self.calibrator is None:
            self.calibrator = TemperatureScaling()
        
        all_logits = []
        all_labels = []
        for text, label in zip(texts, labels):
            all_logits.append(self.get_logits(text))
            all_labels.append(self.intent2id[label])
        
        self.calibrator.fit(
            torch.stack(all_logits), torch.tensor(all_labels))


# 测试
```

### Q24：实现级联意图识别系统

**难度级别**：高级
**考察维度**：系统设计

**问题描述**：

**参考答案**：

```python
import re
import hashlib
import time
from typing import Tuple, Optional, Dict
from collections import OrderedDict


# ========== 缓存层 ==========
class LRUCache:
    """LRU 缓存"""
    
    def __init__(self, capacity=10000):
        self.cache = OrderedDict()
        self.capacity = capacity
    
    def get(self, key: str) -> Optional[Tuple[str, float]]:
        if key in self.cache:
            self.cache.move_to_end(key)
            return self.cache[key]
        return None
    
    def set(self, key: str, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)


# ========== 层 1: 规则匹配 ==========
class RuleMatcher:
    def __init__(self):
        self.rules = {
            "BookTicket": [r"订.*机票", r"买.*机票", r"预订.*航班"],
            "CheckWeather": [r"天气", r"温度", r"下雨"],
            "CancelOrder": [r"取消.*订单", r"退订"],
        }
    
    def match(self, text: str) -> Tuple[Optional[str], float]:
        for intent, patterns in self.rules.items():
            for pattern in patterns:
                if re.search(pattern, text):
                    return intent, 0.95
        return None, 0.0


# ========== 层 2: 快速模型 ==========
class FastTextClassifier:
    def __init__(self, threshold=0.85):
        self.threshold = threshold
    
    def predict(self, text: str) -> Tuple[Optional[str], float]:
        # 模拟（实际加载 FastText 模型）
        if "机票" in text: return "BookTicket", 0.90
        if "天气" in text: return "CheckWeather", 0.88
        if "取消" in text: return "CancelOrder", 0.87
        return None, 0.0


# ========== 层 3: BERT 模型 ==========
class BertClassifier:
    def __init__(self):
        self.threshold = 0.6
        # 实际加载 BERT 模型
    
    def predict(self, text: str) -> Tuple[str, float]:
        # 模拟（实际用 BERT 推理）
        if "票" in text or "航班" in text:
            return "BookTicket", 0.92
        if "天" in text:
            return "CheckWeather", 0.85
        return "Unknown", 0.3


# ========== 级联系统 ==========
class CascadeIntentSystem:
    """级联意图识别系统"""
    
    def __init__(self):
        self.cache = LRUCache(10000)
        self.rule_matcher = RuleMatcher()
        self.fast_classifier = FastTextClassifier()
        self.bert_classifier = BertClassifier()
        
        # 统计
        self.stats = {'cache_hit': 0, 'rule_hit': 0,
                      'fast_hit': 0, 'bert_hit': 0, 'total': 0}
    
    def predict(self, text: str) -> Tuple[str, float]:
        """级联预测"""
        self.stats['total'] += 1
        start_time = time.time()
        
        # 层 0: 缓存
        cache_key = hashlib.md5(text.encode()).hexdigest()
        cached = self.cache.get(cache_key)
        if cached:
            self.stats['cache_hit'] += 1
            return cached
        
        # 层 1: 规则匹配（~0.1ms）
        intent, conf = self.rule_matcher.match(text)
        if intent and conf > 0.9:
            result = (intent, conf)
            self.cache.set(cache_key, result)
            self.stats['rule_hit'] += 1
            return result
        
        # 层 2: FastText（~1ms）
        intent, conf = self.fast_classifier.predict(text)
        if intent and conf > self.fast_classifier.threshold:
            result = (intent, conf)
            self.cache.set(cache_key, result)
            self.stats['fast_hit'] += 1
            return result
        
        # 层 3: BERT（~50ms）
        intent, conf = self.bert_classifier.predict(text)
        if conf < self.bert_classifier.threshold:
            result = ("Unknown", conf)  # 转人工
        else:
            result = (intent, conf)
        
        self.cache.set(cache_key, result)
        self.stats['bert_hit'] += 1
        
        elapsed = (time.time() - start_time) * 1000
        return result
    
    def get_stats(self):
        """获取统计信息"""
        total = self.stats['total']
        if total == 0:
            return self.stats
        return {
            **self.stats,
            'cache_rate': f"{self.stats['cache_hit']/total:.1%}",
            'rule_rate': f"{self.stats['rule_hit']/total:.1%}",
            'fast_rate': f"{self.stats['fast_hit']/total:.1%}",
            'bert_rate': f"{self.stats['bert_hit']/total:.1%}",
        }
```
