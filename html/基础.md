## 一、HTML 基础概念与语法规范

### 1.1 什么是 HTML

HTML（HyperText Markup Language，超文本标记语言）是构建网页的标准标记语言，用于描述网页的结构和内容。它通过标签（Tag）来标记内容的类型，浏览器根据标签来渲染显示页面。

### 1.2 HTML 文档基本结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="页面描述">
    <title>页面标题</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>
```

**各标签说明：**

| 标签 | 作用 |
|------|------|
| `<!DOCTYPE html>` | 声明文档类型，告诉浏览器使用 HTML5 标准模式渲染 |
| `<html>` | 根元素，`lang` 属性指定语言 |
| `<head>` | 包含文档元数据（标题、编码、样式、脚本等） |
| `<meta charset="UTF-8">` | 指定字符编码为 UTF-8 |
| `<meta name="viewport">` | 控制移动端视口，适配响应式布局 |
| `<title>` | 页面标题（显示在浏览器标签页） |
| `<body>` | 页面可见内容 |

### 1.3 块级元素与行内元素

| 对比维度 | 块级元素（Block） | 行内元素（Inline） |
|----------|-------------------|---------------------|
| 独占一行 | 是 | 否，与其他行内元素同行 |
| 宽高设置 | 可设置 `width`/`height` | 不可设置（由内容撑开） |
| 内外边距 | 四个方向均可设置 | 仅水平方向有效（`padding`/`margin` 垂直方向不生效） |
| 可包含元素 | 可包含块级和行内元素 | 通常只能包含文本或行内元素 |
| 常见标签 | `div`、`p`、`h1`-`h6`、`ul`、`li`、`section` | `span`、`a`、`strong`、`em`、`img`、`input` |

**行内块元素（Inline-Block）：** 结合了两者特性 —— 不独占一行，但可设置宽高。常见元素：`img`、`input`、`button`、`select`。

### 1.4 元素嵌套规则

- **块级元素**可以嵌套块级元素和行内元素
- **行内元素**不能嵌套块级元素（如 `<span>` 内不能放 `<div>`）
- **特殊规则：**
  - `<p>` 标签内不能嵌套块级元素（如 `<div>`、`<ul>`）
  - `<a>` 标签内不能嵌套 `<a>` 标签
  - `<ul>` / `<ol>` 的直接子元素只能是 `<li>`
  - `<table>` 的直接子元素是 `<thead>`、`<tbody>`、`<tfoot>`、`<tr>` 等

## 二、HTML 元素分类

### 2.1 按显示方式分类

```
HTML 元素
├── 块级元素（Block）
│   ├── div, p, h1~h6, ul, ol, li, dl, dt, dd
│   ├── header, footer, section, article, nav, aside
│   ├── form, table, hr, blockquote, pre
│   └── fieldset, figure, figcaption, address
│
├── 行内元素（Inline）
│   ├── span, a, strong, em, i, b, u, s, del, ins
│   ├── code, kbd, sub, sup, cite, q, abbr
│   └── label, small, mark, time, br
│
└── 行内块元素（Inline-Block）
    ├── img, input, textarea, select, button
    ├── video, audio, canvas, iframe
    └── progress, meter
```

### 2.2 按是否可替换分类

| 分类 | 说明 | 常见元素 |
|------|------|----------|
| **替换元素** | 内容由外部资源决定，不直接受当前文档 CSS 影响 | `img`、`input`、`video`、`audio`、`iframe`、`canvas` |
| **非替换元素** | 内容直接写在 HTML 中，由 CSS 控制样式 | `div`、`p`、`span`、`a` 等大多数元素 |

### 2.3 空元素（自闭合标签）

空元素没有内容和子节点，不能包含其他元素：

```html
<br>    <!-- 换行 -->
<hr>    <!-- 水平线 -->
<img>   <!-- 图片 -->
<input> <!-- 输入框 -->
<link>  <!-- 外部资源链接 -->
<meta>  <!-- 元数据 -->
<source> <!-- 媒体资源源 -->
```

## 三、HTML 语义化标签

### 3.1 什么是语义化

语义化是指根据内容的结构和含义选择合适的 HTML 标签，而非全部使用 `<div>` 和 `<span>`。

**语义化的优势：**

| 优势 | 说明 |
|------|------|
| **SEO 友好** | 搜索引擎能更好地理解页面结构，提升排名 |
| **可访问性** | 屏幕阅读器能正确解读页面内容，帮助视障用户 |
| **代码可读性** | 开发者一眼就能理解页面结构，便于维护 |
| **样式一致** | 浏览器对语义化标签有默认样式，减少 CSS 重置 |

### 3.2 常见语义化标签

```html
<h1>一级标题（页面只能有一个）</h1>
<h2>二级标题</h2>
<header>页头 / 文章头部</header>
<nav>导航链接区域</nav>
<main>页面主要内容（每个页面唯一）</main>
<article>独立的文章内容</article>
<section>文档中的节 / 区块</section>
<aside>侧边栏 / 附加内容</aside>
<footer>页脚 / 文章尾部</footer>
<time datetime="2026-07-19">2026年7月19日</time>
<address>联系信息</address>
<figure>
    <img src="image.jpg" alt="描述">
    <figcaption>图片说明文字</figcaption>
</figure>
```

## 四、HTML 表单处理

### 4.1 表单基础结构

```html
<form action="/submit" method="POST" enctype="multipart/form-data">
    <!-- 表单控件 -->
    <button type="submit">提交</button>
</form>
```

**核心属性：**

| 属性 | 可选值 | 说明 |
|------|--------|------|
| `action` | URL | 表单提交的目标地址 |
| `method` | `GET` / `POST` | 提交方式：GET 将数据拼接在 URL 中，POST 放在请求体中 |
| `enctype` | `application/x-www-form-urlencoded`（默认）<br>`multipart/form-data`（上传文件）<br>`text/plain` | 数据编码方式 |
| `target` | `_self` / `_blank` / `_parent` / `_top` | 提交后页面的打开位置 |
| `autocomplete` | `on` / `off` | 是否启用自动填充 |
| `novalidate` | 布尔属性 | 禁用浏览器原生表单验证 |

### 4.2 GET 与 POST 的区别

| 维度 | GET | POST |
|------|-----|------|
| 数据位置 | URL 查询字符串中 | 请求体中 |
| 数据大小限制 | 受 URL 长度限制（约 2KB-8KB） | 理论上无限制 |
| 安全性 | 数据暴露在 URL 中，不安全 | 相对安全（但仍需 HTTPS） |
| 缓存 | 可被缓存 | 不会被缓存 |
| 书签 | 可收藏 | 不可收藏 |
| 幂等性 | 幂等（多次请求结果相同） | 非幂等 |
| 使用场景 | 查询、搜索、筛选 | 登录、注册、提交数据 |

### 4.3 表单控件

```html
<!-- 文本输入 -->
<input type="text" name="username" placeholder="请输入用户名" required>

<!-- 密码 -->
<input type="password" name="password" minlength="6" maxlength="20">

<!-- 单选框 -->
<input type="radio" name="gender" value="male" checked> 男
<input type="radio" name="gender" value="female"> 女

<!-- 复选框 -->
<input type="checkbox" name="hobby" value="reading" checked> 阅读
<input type="checkbox" name="hobby" value="sports"> 运动

<!-- 下拉选择 -->
<select name="city" multiple>
    <option value="">请选择城市</option>
    <optgroup label="华北">
        <option value="beijing">北京</option>
    </optgroup>
</select>

<!-- 文本域 -->
<textarea name="desc" rows="5" cols="30" maxlength="500"></textarea>

<!-- 文件上传 -->
<input type="file" name="avatar" accept="image/*" multiple>

<!-- 按钮 -->
<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button">普通按钮</button>
```

### 4.4 `<label>` 标签

`<label>` 为表单控件提供标签说明，提升可访问性和用户体验：

```html
<!-- 方式一：显式关联（for 属性指向控件 id） -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 方式二：隐式关联（将控件放在 label 内） -->
<label>
    <input type="checkbox" name="agree"> 我已阅读并同意
</label>
```

**优势：** 点击 label 文字时，焦点自动转移到关联的控件上，增大了点击区域。

## 五、HTML5 新增特性总览

HTML5 于 2014 年正式定稿，新增了大量强大特性：

| 类别 | 新增特性 |
|------|----------|
| **语义化标签** | `header`、`nav`、`main`、`section`、`article`、`aside`、`footer`、`figure`、`figcaption`、`time`、`mark`、`details`、`summary` |
| **表单增强** | 新输入类型（`email`、`url`、`number`、`date` 等）、新属性（`placeholder`、`required`、`pattern`、`autofocus`、`autocomplete`）、新元素（`datalist`、`output`、`progress`、`meter`） |
| **多媒体** | `<audio>`、`<video>` 标签，原生支持音视频播放 |
| **图形绘制** | `<canvas>` 元素 + Canvas API、`<svg>` 内联矢量图形 |
| **本地存储** | `localStorage`、`sessionStorage`、IndexedDB |
| **通信** | WebSocket、Server-Sent Events (SSE) |
| **离线应用** | Application Cache（已废弃）、Service Worker |
| **设备访问** | Geolocation API、拖放 API、File API、Camera API |
| **性能** | Web Workers、requestAnimationFrame |
| **历史管理** | History API（`pushState`、`replaceState`） |

## 六、HTML5 语义化标签详解

### 6.1 页面结构标签

```html
<body>
    <header>
        <h1>网站标题</h1>
        <nav>
            <ul>
                <li><a href="/">首页</a></li>
                <li><a href="/about">关于</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <header>
                <h2>文章标题</h2>
                <time datetime="2026-07-19">2026年7月19日</time>
            </header>
            <section>
                <h3>第一节</h3>
                <p>文章内容...</p>
            </section>
            <section>
                <h3>第二节</h3>
                <p>更多内容...</p>
            </section>
            <footer>
                <p>作者：张三</p>
            </footer>
        </article>

        <aside>
            <h3>相关文章</h3>
            <ul>
                <li><a href="#">文章一</a></li>
            </ul>
        </aside>
    </main>

    <footer>
        <p>&copy; 2026 版权所有</p>
        <address>联系邮箱：contact@example.com</address>
    </footer>
</body>
```

### 6.2 标签语义对照表

| 标签 | 语义 | 使用场景 |
|------|------|----------|
| `<header>` | 头部区域 | 页面头部、文章头部（可多次使用） |
| `<nav>` | 导航链接 | 主导航、面包屑、分页 |
| `<main>` | 主要内容 | 每个页面唯一，放置核心内容 |
| `<article>` | 独立内容 | 博客文章、新闻、评论、帖子 |
| `<section>` | 文档分区 | 章节、标签页、功能区 |
| `<aside>` | 侧边内容 | 侧边栏、广告、相关链接 |
| `<footer>` | 底部区域 | 版权信息、联系方式、相关链接 |
| `<figure>` / `<figcaption>` | 图文组合 | 插图、图表、代码片段 |
| `<time>` | 时间/日期 | 发布日期、活动时间 |
| `<mark>` | 高亮标记 | 搜索结果高亮、重点标注 |
| `<details>` / `<summary>` | 折叠内容 | FAQ、展开/收起面板 |

### 6.3 语义化标签对 SEO 的影响

- 搜索引擎优先抓取 `<main>`、`<article>` 中的内容
- `<h1>` ~ `<h6>` 层级结构影响关键词权重
- `<nav>` 帮助搜索引擎理解站点导航结构
- `<time>` 帮助搜索引擎提取时间信息
- `<img>` 的 `alt` 属性提升图片搜索排名

## 七、Canvas 绘图

### 7.1 Canvas 基础

`<canvas>` 是 HTML5 提供的位图绘制区域，通过 JavaScript 操作其 2D 或 3D（WebGL）上下文进行绘制。

```html
<canvas id="myCanvas" width="400" height="300">
    您的浏览器不支持 Canvas，请升级浏览器。
</canvas>

<script>
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// 绘制矩形
ctx.fillStyle = '#1890ff';
ctx.fillRect(50, 50, 200, 100);

// 绘制边框矩形
ctx.strokeStyle = '#ff4d4f';
ctx.lineWidth = 3;
ctx.strokeRect(50, 50, 200, 100);

// 清除区域
ctx.clearRect(60, 60, 50, 50);
</script>
```

### 7.2 Canvas 常用 API

```javascript
const ctx = canvas.getContext('2d');

// ===== 路径绘制 =====
ctx.beginPath();              // 开始新路径
ctx.moveTo(100, 100);         // 移动起点
ctx.lineTo(200, 200);         // 画线
ctx.arc(150, 150, 50, 0, Math.PI * 2);  // 画圆
ctx.rect(10, 10, 80, 80);     // 画矩形路径
ctx.closePath();              // 闭合路径
ctx.fill();                   // 填充
ctx.stroke();                 // 描边

// ===== 样式设置 =====
ctx.fillStyle = '#ff0000';          // 填充颜色
ctx.strokeStyle = '#0000ff';        // 描边颜色
ctx.lineWidth = 2;                  // 线宽
ctx.lineCap = 'round';              // 线端样式：butt | round | square
ctx.lineJoin = 'round';             // 连接处样式：round | bevel | miter
ctx.globalAlpha = 0.5;              // 全局透明度

// ===== 文字绘制 =====
ctx.font = '20px Arial';            // 字体样式
ctx.textAlign = 'center';           // 水平对齐
ctx.textBaseline = 'middle';        // 垂直对齐
ctx.fillText('Hello Canvas', 200, 150);
ctx.strokeText('Hello Canvas', 200, 180);

// ===== 图片绘制 =====
const img = new Image();
img.onload = () => {
    ctx.drawImage(img, 0, 0, 200, 150);  // 绘制图片
    // drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)  // 裁剪绘制
};
img.src = 'image.jpg';

// ===== 变换 =====
ctx.save();                     // 保存当前状态
ctx.translate(100, 100);        // 平移
ctx.rotate(Math.PI / 4);        // 旋转
ctx.scale(0.5, 0.5);            // 缩放
ctx.transform(1, 0, 0, 1, 0, 0);// 矩阵变换
ctx.restore();                  // 恢复保存的状态

// ===== 像素操作 =====
const imageData = ctx.getImageData(0, 0, 100, 100);
const data = imageData.data;    // Uint8ClampedArray [R,G,B,A, R,G,B,A, ...]
// 修改像素数据...
ctx.putImageData(imageData, 0, 0);
```

### 7.3 Canvas 动画实现

```javascript
let x = 0;
let y = 150;
let vx = 2;
let vy = 0;
const radius = 20;

function animate() {
    // 清除画布
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    // 更新位置
    x += vx;
    y += vy;

    // 边界检测
    if (x + radius > canvas.width || x - radius < 0) {
        vx = -vx;
    }

    // 绘制
    ctx.beginPath();
    ctx.arc(x, y, radius, 0, Math.PI * 2);
    ctx.fillStyle = '#1890ff';
    ctx.fill();

    // 请求下一帧
    requestAnimationFrame(animate);
}

animate();
```

### 7.4 Canvas 与 SVG 对比

| 维度 | Canvas | SVG |
|------|--------|-----|
| 图形类型 | 位图（像素） | 矢量图（XML） |
| 缩放 | 会失真 | 不失真 |
| 事件处理 | 需要手动计算坐标 | 每个元素可绑定事件 |
| 性能 | 大量对象时性能好 | 大量对象时性能下降 |
| DOM 操作 | 无法通过 DOM 操作 | 可通过 DOM 操作 |
| 修改方式 | 重绘整个画布 | 修改单个元素属性 |
| 适用场景 | 游戏、图形编辑器、大数据可视化 | 图标、地图、数据图表 |

## 八、SVG 矢量图形

### 8.1 SVG 基础

SVG（Scalable Vector Graphics）是一种基于 XML 的矢量图形格式，可直接嵌入 HTML 中。

```html
<svg width="200" height="200" viewBox="0 0 200 200" xmlns="http://www.w3.org/2000/svg">
    <!-- 矩形 -->
    <rect x="10" y="10" width="80" height="80" rx="8"
          fill="#1890ff" stroke="#0050b3" stroke-width="2" />

    <!-- 圆形 -->
    <circle cx="140" cy="50" r="40"
            fill="#52c41a" stroke="#237804" stroke-width="2" />

    <!-- 椭圆 -->
    <ellipse cx="100" cy="150" rx="60" ry="25"
             fill="#faad14" />

    <!-- 线条 -->
    <line x1="20" y1="180" x2="180" y2="180"
          stroke="#ff4d4f" stroke-width="2" />

    <!-- 折线 -->
    <polyline points="10,10 50,30 90,10 130,40"
              fill="none" stroke="#722ed1" stroke-width="2" />

    <!-- 多边形 -->
    <polygon points="100,10 140,80 110,120 90,120 60,80"
             fill="#13c2c2" />

    <!-- 路径 -->
    <path d="M 10 80 Q 50 10, 100 80 T 190 80"
          fill="none" stroke="#eb2f96" stroke-width="2" />

    <!-- 文字 -->
    <text x="100" y="195" text-anchor="middle" font-size="14" fill="#333">
        SVG 文字
    </text>
</svg>
```

### 8.2 SVG 路径命令

| 命令 | 含义 | 示例 |
|------|------|------|
| `M x y` | 移动到 (x, y) | `M 10 10` |
| `L x y` | 画线到 (x, y) | `L 50 50` |
| `H x` | 水平线到 x | `H 100` |
| `V y` | 垂直线到 y | `V 100` |
| `C x1 y1, x2 y2, x y` | 三次贝塞尔曲线 | `C 10 10, 50 10, 50 50` |
| `Q x1 y1, x y` | 二次贝塞尔曲线 | `Q 50 10, 100 50` |
| `A rx ry x-rot large sweep x y` | 弧线 | `A 30 30 0 0 1 100 100` |
| `Z` | 闭合路径 | `Z` |

### 8.3 SVG 使用方式

```html
<!-- 方式一：内联 SVG（推荐，可操作 DOM） -->
<svg>...</svg>
```

## 九、本地存储方案

### 9.1 Cookie

Cookie 是存储在浏览器中的小段文本数据（通常不超过 4KB），每次 HTTP 请求都会自动携带到服务器。

```javascript
// 设置 Cookie
document.cookie = "username=张三; max-age=86400; path=/; secure; samesite=lax";

// 读取 Cookie（所有 Cookie 以分号分隔的字符串）
console.log(document.cookie); // "username=张三; theme=dark"

// 删除 Cookie（设置过期时间为过去）
document.cookie = "username=; max-age=0; path=/";
```

**Cookie 属性：**

| 属性 | 说明 |
|------|------|
| `max-age` | 有效期（秒），过期后自动删除 |
| `expires` | 过期日期（GMT 格式） |
| `path` | 生效路径，默认当前路径 |
| `domain` | 生效域名 |
| `secure` | 仅 HTTPS 连接传输 |
| `httponly` | 禁止 JavaScript 访问（仅服务端可设置） |
| `samesite` | 跨站请求控制：`Strict` / `Lax` / `None` |

### 9.2 Web Storage

Web Storage 提供比 Cookie 更大的存储空间（通常 5MB-10MB），且数据不会随请求发送到服务器。

#### localStorage

```javascript
// 存储数据（持久化，关闭浏览器后仍存在）
localStorage.setItem('username', '张三');
localStorage.setItem('theme', 'dark');

// 存储对象（需序列化）
const user = { name: '张三', age: 25 };
localStorage.setItem('user', JSON.stringify(user));

// 读取数据
const username = localStorage.getItem('username');
const userObj = JSON.parse(localStorage.getItem('user'));

// 删除单个
localStorage.removeItem('username');

// 清空所有
localStorage.clear();

// 获取键名（按索引）
const key = localStorage.key(0);

// 获取存储数量
console.log(localStorage.length);

// 监听存储变化（同源的其他页面触发）
window.addEventListener('storage', (e) => {
    console.log(e.key, e.oldValue, e.newValue, e.url);
});
```

#### sessionStorage

```javascript
// API 与 localStorage 完全相同
sessionStorage.setItem('token', 'abc123');
sessionStorage.getItem('token');
sessionStorage.removeItem('token');
sessionStorage.clear();
```

### 9.3 localStorage 与 sessionStorage 对比

| 维度 | localStorage | sessionStorage | Cookie |
|------|-------------|---------------|--------|
| 生命周期 | 永久（除非手动删除） | 关闭标签页后清除 | 可设置过期时间 |
| 存储大小 | 约 5MB-10MB | 约 5MB-10MB | 约 4KB |
| 作用域 | 同源所有标签页共享 | 仅当前标签页 | 同源共享（受 path/domain 影响） |
| 随请求发送 | 否 | 否 | 是（每次 HTTP 请求） |
| API 易用性 | 简单 | 简单 | 繁琐（需手动解析） |
| storage 事件 | 支持 | 支持 | 不支持 |

### 9.4 IndexedDB

IndexedDB 是浏览器端的事务型数据库，支持存储大量结构化数据，使用异步 API。

```javascript
// 打开数据库
const request = indexedDB.open('MyDatabase', 1);

request.onupgradeneeded = (event) => {
    const db = event.target.result;
    // 创建对象存储（类似表）
    const objectStore = db.createObjectStore('users', {
        keyPath: 'id',
        autoIncrement: true
    });
    // 创建索引
    objectStore.createIndex('name', 'name', { unique: false });
    objectStore.createIndex('email', 'email', { unique: true });
};

request.onsuccess = (event) => {
    const db = event.target.result;

    // 添加数据
    const transaction = db.transaction('users', 'readwrite');
    const store = transaction.objectStore('users');
    store.add({ name: '张三', email: 'zhangsan@example.com', age: 25 });

    transaction.oncomplete = () => {
        console.log('数据添加成功');
    };
};

request.onerror = (event) => {
    console.error('数据库打开失败', event.target.error);
};
```

### 11.1 拖放基础

### 11.2 拖放事件

```javascript
const draggable = document.getElementById('draggable');
const dropzone = document.getElementById('dropzone');

// ===== 被拖拽元素的事件 =====

draggable.addEventListener('dragstart', (e) => {
    // 设置拖拽数据
    e.dataTransfer.setData('text/plain', e.target.id);
    e.dataTransfer.effectAllowed = 'move'; // move | copy | link
    e.target.style.opacity = '0.5';
});

draggable.addEventListener('drag', (e) => {
    // 拖拽过程中持续触发
});

draggable.addEventListener('dragend', (e) => {
    // 拖拽结束（无论是否成功放置）
    e.target.style.opacity = '1';
});

// ===== 放置区域的事件 =====

dropzone.addEventListener('dragenter', (e) => {
    e.preventDefault(); // 必须阻止默认行为才能 drop
    e.target.style.borderColor = '#1890ff';
});

dropzone.addEventListener('dragover', (e) => {
    e.preventDefault(); // 必须阻止默认行为才能 drop
    e.dataTransfer.dropEffect = 'move';
});

dropzone.addEventListener('dragleave', (e) => {
    e.target.style.borderColor = '#ccc';
});

dropzone.addEventListener('drop', (e) => {
    e.preventDefault();
    e.target.style.borderColor = '#ccc';

    // 获取拖拽数据
    const id = e.dataTransfer.getData('text/plain');
    const draggedEl = document.getElementById(id);

    // 移动元素
    e.target.appendChild(draggedEl);
});
```

### 11.3 拖放事件完整流程

```
被拖拽元素：dragstart → drag → dragend
放置区域：   dragenter → dragover → dragleave (或 drop)
```

| 事件 | 触发对象 | 说明 |
|------|----------|------|
| `dragstart` | 被拖拽元素 | 开始拖拽时触发 |
| `drag` | 被拖拽元素 | 拖拽过程中持续触发 |
| `dragend` | 被拖拽元素 | 拖拽结束时触发 |
| `dragenter` | 放置区域 | 拖拽进入目标区域时触发 |
| `dragover` | 放置区域 | 在目标区域内移动时持续触发 |
| `dragleave` | 放置区域 | 拖拽离开目标区域时触发 |
| `drop` | 放置区域 | 在目标区域内释放时触发 |

### 12.1 WebSocket 基础

WebSocket 是 HTML5 提供的全双工通信协议，客户端和服务器之间可以建立持久连接，双向实时通信。

```javascript

ws.onmessage = (event) => {
    console.log('收到消息:', event.data);

ws.onerror = (error) => {
    console.error('WebSocket 错误:', error);
```

### 12.3 心跳检测与断线重连

```javascript
class WebSocketClient {
    constructor(url, options = {}) {
        this.url = url;
        this.reconnectInterval = options.reconnectInterval || 3000;
        this.heartbeatInterval = options.heartbeatInterval || 30000;
        this.maxReconnectAttempts = options.maxReconnectAttempts || 5;
        this.reconnectAttempts = 0;
        this.heartbeatTimer = null;
        this.connect();
    }

    connect() {
        this.ws = new WebSocket(this.url);

        this.ws.onopen = () => {
            console.log('连接成功');
            this.reconnectAttempts = 0;
            this.startHeartbeat();
        };

        this.ws.onmessage = (event) => {
            const data = JSON.parse(event.data);
            if (data.type === 'pong') {
                // 心跳响应
                return;
            }
            console.log('收到消息:', data);
        };

        this.ws.onclose = (event) => {
            this.stopHeartbeat();
            if (event.code !== 1000) {
                this.reconnect();
            }
        };

        this.ws.onerror = () => {
            this.ws.close();
        };
    }

    startHeartbeat() {
        this.stopHeartbeat();
        this.heartbeatTimer = setInterval(() => {
            if (this.ws.readyState === WebSocket.OPEN) {
                this.ws.send(JSON.stringify({ type: 'ping' }));
            }
        }, this.heartbeatInterval);
    }

    stopHeartbeat() {
        if (this.heartbeatTimer) {
            clearInterval(this.heartbeatTimer);
            this.heartbeatTimer = null;
        }
    }

    reconnect() {
        if (this.reconnectAttempts >= this.maxReconnectAttempts) {
            console.error('已达到最大重连次数');
            return;
        }
        this.reconnectAttempts++;
        console.log(`第 ${this.reconnectAttempts} 次重连...`);
        setTimeout(() => this.connect(), this.reconnectInterval);
    }
}
```

```javascript
emailInput.validity.badInput;        // 输入格式错误
emailInput.validity.customError;     // 自定义错误

// 自定义验证消息
emailInput.setCustomValidity('请输入正确的邮箱地址');
emailInput.setCustomValidity(''); // 清除自定义错误

// 检查整个表单
console.log(form.checkValidity()); // 返回 true/false

// 触发浏览器验证 UI
form.reportValidity();

// 禁用原生验证
form.setAttribute('novalidate', '');

// 自定义验证事件
emailInput.addEventListener('invalid', (e) => {
    e.preventDefault(); // 阻止默认气泡
    if (emailInput.validity.valueMissing) {
        console.log('邮箱不能为空');
    } else if (emailInput.validity.typeMismatch) {
        console.log('邮箱格式不正确');
    }
});

// 表单提交时验证
form.addEventListener('submit', (e) => {
    if (!form.checkValidity()) {
        e.preventDefault();
        console.log('表单验证失败');
    }
});
```

## 十五、Web Workers 多线程处理

### 15.1 Web Workers 基础

Web Workers 允许在后台线程中运行 JavaScript，不阻塞主线程 UI 渲染。

```javascript
// ===== 主线程（main.js） =====

// 创建 Worker
const worker = new Worker('worker.js');

// 向 Worker 发送消息
worker.postMessage({ type: 'calculate', data: [1, 2, 3, 4, 5] });

// 接收 Worker 消息
worker.onmessage = (event) => {
    console.log('Worker 返回结果:', event.data);
};

// Worker 错误处理
worker.onerror = (error) => {
    console.error('Worker 错误:', error.message, error.filename, error.lineno);
};

// 终止 Worker
// worker.terminate();
```

```javascript
// ===== Worker 线程（worker.js） =====

// 接收主线程消息
self.onmessage = (event) => {
    const { type, data } = event.data;

    if (type === 'calculate') {
        const result = data.reduce((sum, num) => sum + num, 0);
        // 返回结果给主线程
        self.postMessage({ type: 'result', value: result });
    }
};

// 也可使用 addEventListener
// self.addEventListener('message', handler);

// 在 Worker 中引入其他脚本
// importScripts('helper.js', 'utils.js');

// Worker 内部错误
self.onerror = (error) => {
    console.error('Worker 内部错误:', error);
};
```

### 15.2 Worker 类型

| 类型 | 说明 | 创建方式 |
|------|------|----------|
| **Dedicated Worker** | 专属于创建它的页面 | `new Worker('worker.js')` |
| **Shared Worker** | 同源多个页面共享 | `new SharedWorker('worker.js')` |
| **Service Worker** | 离线缓存、推送通知、后台同步 | `navigator.serviceWorker.register('sw.js')` |

### 15.3 Shared Worker 示例

```javascript
// ===== 主线程（多个页面可共享） =====
const worker = new SharedWorker('shared-worker.js');

// 通过 port 通信
worker.port.start();
worker.port.postMessage({ type: 'hello' });

worker.port.onmessage = (event) => {
    console.log('Shared Worker 返回:', event.data);
};

// ===== shared-worker.js =====
const connections = [];

self.onconnect = (event) => {
    const port = event.ports[0];
    connections.push(port);

    port.onmessage = (e) => {
        console.log('收到消息:', e.data);
        // 广播给所有连接
        connections.forEach(conn => {
            conn.postMessage({ type: 'broadcast', data: e.data });
        });
    };

    port.start();
};
```

### 15.4 Worker 限制

- 不能直接操作 DOM
- 不能访问 `window` 对象、`document` 对象
- 不能访问 `localStorage` / `sessionStorage`（但可访问 IndexedDB）
- 同源限制（Worker 脚本必须与主页面同源）
- 传递数据通过**结构化克隆**（值拷贝），大量数据考虑使用 Transferable 对象

```javascript
// 使用 Transferable 对象传输（零拷贝，性能更高）
const buffer = new ArrayBuffer(1024 * 1024); // 1MB
worker.postMessage({ buffer }, [buffer]); // buffer 所有权转移给 Worker
// 此时主线程中 buffer 不可用
```

#### Q1：请简述 HTML5 的文档类型声明 `<!DOCTYPE html>` 的作用。

| 垂直对齐 | 按标准规范 | 不同浏览器不一致 |
| 表格字体继承 | 不继承 | 继承 |

#### Q11：WebSocket 的握手过程是怎样的？如何实现心跳检测和断线重连？

**考察知识点：** WebSocket 协议、实时通信 | **能力等级：** 中级

**参考答案：**

**握手过程：**

WebSocket 连接基于 HTTP 协议升级而来：

```
客户端                                    服务器
  |                                         |
  |---- HTTP GET (Upgrade 请求) ----------->|
  |     Connection: Upgrade                 |
  |     Upgrade: websocket                  |
  |     Sec-WebSocket-Key: Base64随机串     |
  |     Sec-WebSocket-Version: 13           |
  |                                         |
  |<---- HTTP 101 Switching Protocols ------|
  |     Connection: Upgrade                 |
  |     Upgrade: websocket                  |
  |     Sec-WebSocket-Accept: SHA1结果      |
  |                                         |
  |<====== WebSocket 全双工通信 ===========>|
```

**关键点：**
- `Sec-WebSocket-Key` 是客户端随机生成的 Base64 字符串
- 服务端将 Key 与魔数 `258EAFA5-E914-47DA-95CA-C5AB0DC85B11` 拼接后进行 SHA-1 哈希，再 Base64 编码得到 `Sec-WebSocket-Accept`
- 响应码为 `101 Switching Protocols`，表示协议切换成功

**心跳检测与断线重连：**

```javascript
class WSClient {
    constructor(url) {
        this.url = url;
        this.reconnectInterval = 3000;
        this.heartbeatInterval = 30000;
        this.reconnectAttempts = 0;
        this.maxReconnectAttempts = 5;
        this.connect();
    }

    connect() {
        this.ws = new WebSocket(this.url);
        this.ws.onopen = () => {
            this.reconnectAttempts = 0;
            this.startHeartbeat();
        };
        this.ws.onmessage = (e) => {
            if (JSON.parse(e.data).type === 'pong') return;
            // 处理业务消息
        };
        this.ws.onclose = (e) => {
            this.stopHeartbeat();
            if (e.code !== 1000) this.reconnect();
        };
    }

        }
    }
```

```javascript
};

// 主线程接收

    console.log('计算结果:', e.data.value);
};

// Transferable 对象（零拷贝高性能传输）
```

```javascript
    constructor(routes) {
        this.routes = routes;
        this.init();
    }

    init() {

        window.addEventListener('popstate', () => {

            }

        // 初始路由
        this.handleRoute(location.pathname);
    }

    navigate(url) {
        history.pushState(null, '', url);
        this.handleRoute(url);

    handleRoute(path) {
        const route = this.routes.find(r => {
            // 支持动态路由 /user/:id
            const regex = new RegExp('^' + r.path.replace(/:\w+/g, '([^/]+)') + '$');

            return match ? { ...r, params: match.slice(1) } : null;

        if (route) {
            document.getElementById('app').innerHTML = route.component(route.params);
        } else {
            document.getElementById('app').innerHTML = '<h1>404 Not Found</h1>';
        }
    }
}
```

#### Q15：请说明浏览器的渲染流程（从输入 URL 到页面呈现），HTML 解析在其中扮演什么角色？

#### Q16：请实现一个图片懒加载方案，并说明 Intersection Observer API 的原理。

**考察知识点：** Intersection Observer、懒加载、性能优化 | **能力等级：** 高级

**参考答案：**

**Intersection Observer API 原理：**

`IntersectionObserver` 异步观察目标元素与视口（或指定祖先元素）的交叉状态，当可见性变化时触发回调，替代传统的 `scroll` 事件监听方案，性能更优。

**图片懒加载实现：**

```html
<img data-src="image.jpg" class="lazy" alt="图片">
<img data-src="image2.jpg" class="lazy" alt="图片">
```

```javascript
class LazyLoader {
    constructor(options = {}) {
        this.rootMargin = options.rootMargin || '0px 0px 200px 0px';
        this.threshold = options.threshold || 0;
        this.init();
    }

    init() {
        this.observer = new IntersectionObserver(
            (entries) => {
                entries.forEach(entry => {
                    if (entry.isIntersecting) {
                        const img = entry.target;
                        this.loadImage(img);
                        this.observer.unobserve(img); // 加载后停止观察
                    }
                });
            },
            {
                rootMargin: this.rootMargin, // 提前 200px 开始加载
                threshold: this.threshold
            }
        );

        // 观察所有懒加载图片
        document.querySelectorAll('img[data-src]').forEach(img => {
            this.observer.observe(img);
        });
    }

    loadImage(img) {
        const src = img.getAttribute('data-src');
        if (!src) return;

        // 创建新 Image 对象预加载
        const tempImg = new Image();
        tempImg.onload = () => {
            img.src = src;
            img.classList.add('loaded');
            img.removeAttribute('data-src');
        };
        tempImg.onerror = () => {
            img.classList.add('error');
            // 可设置占位图
            img.src = 'placeholder.jpg';
        };
        tempImg.src = src;
    }

    // 动态添加新元素
    observe(img) {
        this.observer.observe(img);
    }

    destroy() {
        this.observer.disconnect();
    }
}

// 使用
const lazyLoader = new LazyLoader({ rootMargin: '0px 0px 300px 0px' });
```

**IntersectionObserver 配置：**

| 选项 | 说明 |
|------|------|
| `root` | 观察的根元素，默认视口 |
| `rootMargin` | 根元素的外边距，可提前触发 |
| `threshold` | 交叉比例阈值（0-1），可设数组 `[0, 0.5, 1]` |

**考察知识点：** 离线存储、Service Worker、PWA | **能力等级：** 高级

**参考答案：**

**Application Cache 废弃原因：**

1. **更新机制不可靠：** 只有 manifest 文件内容变化才会触发更新，资源文件本身变化不会触发
2. **缓存策略单一：** 无法灵活控制缓存策略（全部缓存或全部不缓存）
3. **调试困难：** 缺乏调试工具，问题排查困难
4. **安全风险：** 容易导致敏感数据被缓存

**Service Worker 替代方案：**

```javascript
// ===== 注册 Service Worker =====
if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js')
        .then(reg => console.log('SW 注册成功:', reg.scope))
        .catch(err => console.error('SW 注册失败:', err));
}

// ===== sw.js =====
const CACHE_NAME = 'my-app-v1';
const urlsToCache = [
    '/',
    '/index.html',
    '/styles/main.css',
    '/scripts/app.js',
    '/images/logo.png'
];

// 安装阶段：预缓存关键资源
self.addEventListener('install', (event) => {
    event.waitUntil(
        caches.open(CACHE_NAME)
            .then(cache => cache.addAll(urlsToCache))
            .then(() => self.skipWaiting()) // 立即激活
    );
});

// 激活阶段：清理旧缓存
self.addEventListener('activate', (event) => {
    event.waitUntil(
        caches.keys().then(cacheNames => {
            return Promise.all(
                cacheNames.filter(name => name !== CACHE_NAME)
                    .map(name => caches.delete(name))
            );
        }).then(() => self.clients.claim())
    );
});

// 请求拦截：缓存策略
self.addEventListener('fetch', (event) => {
    event.respondWith(
        caches.match(event.request).then(cachedResponse => {
            // 缓存优先，同时更新缓存
            const fetchPromise = fetch(event.request).then(networkResponse => {
                if (networkResponse && networkResponse.status === 200) {
                    const responseClone = networkResponse.clone();
                    caches.open(CACHE_NAME).then(cache => {
                        cache.put(event.request, responseClone);
                    });
                }
                return networkResponse;
            });
            return cachedResponse || fetchPromise;
        })
    );
});
```

**缓存策略对比：**

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| Cache First | 缓存优先，缓存未命中才请求网络 | 静态资源 |
| Network First | 网络优先，失败才用缓存 | 频繁更新的 API |
| Cache Only | 仅缓存 | 纯离线资源 |
| Network Only | 仅网络 | 不需要缓存的请求 |
| Stale-While-Revalidate | 先用缓存，同时更新缓存 | 兼顾性能和新鲜度 |

#### Q20：请设计一个基于 HTML5 的文件断点续传方案，包含前端分片和进度展示。

**考察知识点：** File API、Blob、断点续传 | **能力等级：** 高级

**参考答案：**

```html
<input type="file" id="fileInput">
<progress id="progress" value="0" max="100"></progress>
<div id="status"></div>
```

```javascript
class FileUploader {
    constructor(options) {
        this.chunkSize = options.chunkSize || 1024 * 1024 * 5; // 5MB
        this.uploadUrl = options.uploadUrl;
        this.concurrent = options.concurrent || 3; // 并发数
    }

    async upload(file) {
        const chunks = this.createChunks(file);
        const fileHash = await this.calculateHash(file);
        const uploadedChunks = await this.getUploadedChunks(fileHash);

        const pendingChunks = chunks.filter(
            (_, index) => !uploadedChunks.includes(index)
        );

        // 并发上传
        const total = pendingChunks.length;
        let completed = 0;

        const uploadChunk = async (chunk, index) => {
            const formData = new FormData();
            formData.append('file', chunk.blob);
            formData.append('hash', fileHash);
            formData.append('index', index);
            formData.append('totalChunks', chunks.length);
            formData.append('fileName', file.name);

            await fetch(this.uploadUrl, {
                method: 'POST',
                body: formData
            });

            completed++;
            this.updateProgress(completed / total * 100);
        };

        // 并发控制
        const tasks = pendingChunks.map((chunk, i) => () => uploadChunk(chunk, chunk.index));
        await this.runConcurrently(tasks, this.concurrent);

        // 通知服务端合并
        await fetch('/merge', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ hash: fileHash, fileName: file.name, totalChunks: chunks.length })
        });

        this.updateStatus('上传完成');
    }

    createChunks(file) {
        const chunks = [];
        let start = 0;
        let index = 0;

        while (start < file.size) {
            const end = Math.min(start + this.chunkSize, file.size);
            chunks.push({
                index: index++,
                blob: file.slice(start, end),
                start,
                end
            });
            start = end;
        }
        return chunks;
    }

    async calculateHash(file) {
        // 使用 SparkMD5 或 Web Crypto API
        const spark = new SparkMD5.ArrayBuffer();
        const chunkSize = 1024 * 1024 * 2; // 2MB 采样
        const chunks = Math.ceil(file.size / chunkSize);
        const reader = new FileReader();

        for (let i = 0; i < chunks; i++) {
            const start = i * chunkSize;
            const end = Math.min(start + chunkSize, file.size);
            const blob = file.slice(start, end);

            const buffer = await new Promise((resolve) => {
                reader.onload = (e) => resolve(e.target.result);
                reader.readAsArrayBuffer(blob);
            });
            spark.append(buffer);
        }
        return spark.end();
    }

    async getUploadedChunks(fileHash) {
        const res = await fetch(`/check?hash=${fileHash}`);
        const data = await res.json();
        return data.uploadedChunks || []; // [0, 1, 2, ...]
    }

    async runConcurrently(tasks, limit) {
        const executing = new Set();
        for (const task of tasks) {
            const p = task().then(() => executing.delete(p));
            executing.add(p);
            if (executing.size >= limit) {
                await Promise.race(executing);
            }
        }
        await Promise.all(executing);
    }

    updateProgress(percent) {
        document.getElementById('progress').value = percent;
    }

    updateStatus(message) {
        document.getElementById('status').textContent = message;
    }
}

const fileInput = document.getElementById('fileInput');
fileInput.addEventListener('change', (e) => {
    const file = e.target.files[0];
    const uploader = new FileUploader({ uploadUrl: '/upload' });
    uploader.upload(file);
});
```
