1. 按钮组件系统

Sass 的混合功能可以轻松创建一致的按钮变体

实际效果：

Sass 源代码：

// 按钮变体混合 @mixin button-variant($background, $color) { background-color: $background; color: $color; border: 1px solid darken($background, 10%); &:hover { background-color: darken($background, 10%); } } // 按钮组件 .btn { padding: 12px 24px; border-radius: 4px; &--primary { @include button-variant(#3498db, white); } &--secondary { @include button-variant(#2ecc71, white); } }

编译后的 CSS：

.btn { padding: 12px 24px; border-radius: 4px; } .btn--primary { background-color: #3498db; color: white; border: 1px solid #2980b9; } .btn--primary:hover { background-color: #2980b9; } .btn--secondary { background-color: #2ecc71; color: white; border: 1px solid #27ae60; } .btn--secondary:hover { background-color: #27ae60; }

3. 响应式网格系统

Sass 循环和断点混合创建响应式网格

网格示例：

.col-12 .col-md-6 .col-lg-4
.col-12 .col-md-6 .col-lg-4
.col-12 .col-md-12 .col-lg-4
// Sass 网格系统实现 $breakpoints: ('sm': 576px, 'md': 768px, 'lg': 992px); @mixin respond-to($breakpoint) { @media (min-width: map-get($breakpoints, $breakpoint)) { @content; } } .row { display: flex; flex-wrap: wrap; } @for $i from 1 through 12 { .col-#{$i} { width: percentage($i / 12); } } @each $breakpoint, $value in $breakpoints { @include respond-to($breakpoint) { @for $i from 1 through 12 { .col-#{$breakpoint}-#{$i} { width: percentage($i / 12); } } } }

4. 工具类系统

Sass 循环生成间距和文本工具类

间距工具类：

.mb-2 (下边距 16px)
.mt-3 (上边距 24px)
.mx-4 (左右边距 32px)
.py-2 (上下内边距 16px)

文本工具类：

.text--primary - 主要颜色文本

.text--secondary - 次要颜色文本

.text--accent - 强调颜色文本

.text--center - 居中文本

.text--bold - 加粗文本

.text--uppercase - 大写文本

// Sass 生成工具类 $spacing-unit: 8px; @for $i from 0 through 5 { .mt-#{$i} { margin-top: $spacing-unit * $i; } .mb-#{$i} { margin-bottom: $spacing-unit * $i; } .pt-#{$i} { padding-top: $spacing-unit * $i; } .pb-#{$i} { padding-bottom: $spacing-unit * $i; } } .text { &--primary { color: #3498db; } &--secondary { color: #2ecc71; } &--accent { color: #e74c3c; } &--center { text-align: center; } &--bold { font-weight: bold; } &--uppercase { text-transform: uppercase; } }
