什么是 Sass？

Sass（Syntactically Awesome Style Sheets）是一个 CSS 预处理器，它扩展了 CSS 的功能，提供了变量、嵌套规则、混合（mixins）、函数等高级功能，使 CSS 更易于维护和编写。

变量系统

统一管理颜色、尺寸、字体等值

嵌套规则

清晰的层级结构，减少重复代码

混合功能

创建可复用的样式代码块

函数运算

动态计算样式值，支持数学运算

两种语法对比

SCSS 语法

完全兼容 CSS3 语法，使用 .scss 扩展名

// 变量定义
$primary-color: #3498db;
$font-stack: Helvetica, sans-serif;

// 嵌套规则
nav {
  ul {
    margin: 0;
    padding: 0;
    list-style: none;
  }

  a {
    color: $primary-color;
    &:hover {
      text-decoration: underline;
    }
  }
}
推荐使用 SCSS 语法，更容易上手

Sass 语法

基于缩进的语法，使用 .sass 扩展名

// 变量定义
$primary-color: #3498db
$font-stack: Helvetica, sans-serif

// 嵌套规则
nav
  ul
    margin: 0
    padding: 0
    list-style: none

  a
    color: $primary-color
    &:hover
      text-decoration: underline
旧语法，新项目不建议使用

核心特性示例

变量系统

// 定义变量
$primary-color: #3498db;
$spacing-unit: 8px;
$font-size-base: 16px;

// 使用变量
.header {
  background-color: $primary-color;
  padding: $spacing-unit * 2;
  font-size: $font-size-base;
}

混合功能

// 定义混合
@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

@mixin border-radius($radius) {
  border-radius: $radius;
}

// 使用混合
.card {
  @include flex-center;
  @include border-radius(10px);
}

嵌套规则

.container {
  width: 100%;

  .header {
    background: #333;

    .logo {
      width: 100px;
      height: 50px;
    }
  }

  .button {
    background: blue;

    &:hover {
      background: darkblue;
    }
  }
}

安装和使用

安装 Sass

使用 npm 或 yarn 全局安装 Sass：

npm install -g sass
yarn global add sass

基本编译命令

编译 Sass 文件为 CSS：

sass input.scss output.css
sass --watch input.scss:output.css
sass input.scss output.css --style compressed

项目配置

在 package.json 中添加脚本：

{
  "scripts": {
    "sass": "sass src/scss:dist/css",
    "sass:watch": "sass --watch src/scss:dist/css",
    "sass:build": "sass src/scss:dist/css --style compressed"
  },
  "devDependencies": {
    "sass": "^1.77.0"
  }
}

实际应用示例

按钮组件

@mixin button-variant($bg, $color) {
  background: $bg;
  color: $color;
  border: 1px solid darken($bg, 10%);

  &:hover {
    background: darken($bg, 10%);
  }
}

.button {
  padding: 12px 24px;
  border-radius: 4px;
  cursor: pointer;

  &--primary {
    @include button-variant(#3498db, white);
  }

  &--secondary {
    @include button-variant(#95a5a6, white);
  }
}

响应式设计

// 断点变量
$breakpoints: (
  'sm': 576px,
  'md': 768px,
  'lg': 992px
);

@mixin respond-to($breakpoint) {
  @media (min-width: map-get($breakpoints, $breakpoint)) {
    @content;
  }
}

.container {
  width: 100%;

  @include respond-to('md') {
    width: 750px;
  }

  @include respond-to('lg') {
    width: 970px;
  }
}

最佳实践

文件组织

按功能模块组织 Sass 文件，提高可维护性

命名规范

使用 BEM 或其他命名规范保持一致性

避免过度嵌套

嵌套深度不超过 3-4 层，保持代码清晰

使用模块系统

优先使用 @use 和 @forward 替代 @import

建议从 SCSS 语法开始学习，逐步掌握高级功能。合理使用变量和混合可以大大提高开发效率。
