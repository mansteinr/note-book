一、概述：两个 Hook 的定位

1.1 React Actions 状态管理架构

在 React 19 的 Actions 系统中，useActionState 和 useFormStatus 是两个核心的状态管理 Hook，它们分别承担不同的职责：

方面 useActionState useFormStatus
设计目标 管理表单的全局状态和异步流程 获取表单的当前状态信息
作用范围 表单级别（整个表单） 组件级别（表单内的子组件）
数据流向 自上而下（状态驱动） 自下而上（状态感知）

依赖关系 独立于组件层级 依赖于父级表单

二、useActionState 深度解析

2.1 基本用法

useActionState 是 React 19 中用于管理表单状态的核心 Hook，它返回一个三元组：[state, action, isPending]

import { useActionState } from 'react';

function FormComponent() {
  // 定义表单处理函数和初始状态
  const [state, action, isPending] = useActionState(
    async (previousState, formData) => {
      // 处理表单数据
      const name = formData.get('name');
      const email = formData.get('email');
      
      // 模拟 API 调用
      await new Promise(resolve => setTimeout(resolve, 1000));
      
      // 返回新状态
      return {
        success: true,
        message: `欢迎 ${name}，注册成功！`,
        submittedAt: new Date().toISOString()
      };
    },
    null // 初始状态
  );
  
  return (
    <form action={action}>
      <input type="text" name="name" required />
      <input type="email" name="email" required />
      <button type="submit" disabled={isPending}>
        {isPending ? '提交中...' : '提交'}
      </button>
    </form>
  );
}
💡 提示： useActionState 的 action 函数会自动处理 FormData，无需手动创建或处理事件对象。

三、useFormStatus 深度解析

3.1 基本用法

useFormStatus 用于在表单的子组件中获取表单的当前状态，它返回一个包含表单状态信息的对象。

import { useFormStatus } from 'react-dom';

function SubmitButton() {
  // 获取表单状态
  const { pending, data, method, action } = useFormStatus();
  
  return (
    <button
      type="submit"
      disabled={pending}
      style={{
        backgroundColor: pending ? '#6c757d' : '#007bff',
        color: 'white',
        padding: '10px 20px',
        border: 'none',
        borderRadius: '4px',
        cursor: pending ? 'not-allowed' : 'pointer'
      }}
    >
      {pending ? (
        <>
          <span className="spinner" />
          处理中...
        </>
      ) : (
        '提交表单'
      )}
    </button>
  );
}

function MyForm() {
  return (
    <form action={submitForm}>
      <input type="text" name="username" />
      <!-- SubmitButton 可以感知表单状态 -->
      <SubmitButton />
    </form>
  );
}
⚠️ 注意： useFormStatus 必须在 <form> 元素内部使用，否则会抛出错误。

四、核心区别对比

4.1 功能定位对比

特性 useActionState useFormStatus
主要用途 管理表单的全局状态和异步操作 获取表单的当前状态信息
返回值 [state, action, isPending] { pending, data, method, action }
状态管理 主动管理（创建、更新状态） 被动感知（读取现有状态）
作用范围 表单级别（控制整个表单） 组件级别（感知父级表单）
依赖关系 独立，不依赖父组件 必须位于 <form> 元素内

useActionState 模式

五、协同工作模式

5.1 黄金组合模式

在实际应用中，useActionState 和 useFormStatus 通常一起使用，形成完美的协同工作模式：

function CollaborativeForm() {
  // useActionState：管理全局状态
  const [state, action, isPending] = useActionState(
    async (prevState, formData) => {
      // 处理表单提交
      const result = await submitToAPI(formData);
      return { success: true, data: result };
    },
    null
  );
  
  return (
    <form action={action}>
      <input type="text" name="username" />
      <input type="email" name="email" />
      
      <!-- useFormStatus：优化子组件 -->
      <EnhancedSubmitButton />
      <FormStatusIndicator />
      
      <!-- useActionState：显示结果 -->
      {state && (
        <div className="result">
          {state.success ? '✅ 成功' : '❌ 失败'}
        </div>
      )}
    </form>
  );
}

function EnhancedSubmitButton() {
  const { pending } = useFormStatus();
  
  return (
    <button
      type="submit"
      disabled={pending}
      className={`btn ${pending ? 'loading' : ''}`}
    >
      {pending ? '处理中...' : '提交'}
    </button>
  );
}
🎯 最佳实践： 使用 useActionState 管理业务状态，使用 useFormStatus 优化用户体验，两者结合实现完美的表单解决方案。

六、实战应用场景

6.1 用户注册系统

结合使用两个 Hook 构建完整的用户注册流程：

function UserRegistration() {
  const [state, action, isPending] = useActionState(
    async (prevState, formData) => {
      // 表单验证
      const errors = {};
      const username = formData.get('username');
      const email = formData.get('email');
      
      if (!username || username.length < 3) {
        errors.username = '用户名至少3个字符';
      }
      
      if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
        errors.email = '邮箱格式不正确';
      }
      
      if (Object.keys(errors).length > 0) {
        return { errors, success: false };
      }
      
      // 模拟 API 调用
      await new Promise(resolve => setTimeout(resolve, 1500));
      
      return {
        success: true,
        message: `欢迎 ${username}，注册成功！`,
        errors: {}
      };
    },
    { success: false, message: null, errors: {} }
  );
  
  return (
    <div className="registration-form">
      <h2>用户注册</h2>
      <form action={action}>
        <div className="form-group">
          <label>用户名</label>
          <input
            type="text"
            name="username"
            className={`input ${state.errors?.username ? 'error' : ''}`}
          />
          {state.errors?.username && (
            <div className="error-message">{state.errors.username}</div>
          )}
        </div>
        
        <div className="form-group">
          <label>邮箱</label>
          <input
            type="email"
            name="email"
            className={`input ${state.errors?.email ? 'error' : ''}`}
          />
          {state.errors?.email && (
            <div className="error-message">{state.errors.email}</div>
          )}
        </div>
        
        <!-- 使用 useFormStatus 的智能按钮 -->
        <SmartSubmitButton />
      </form>
      
      {state.success && state.message && (
        <div className="success-message">
          ✅ {state.message}
        </div>
      )}
    </div>
  );
}

七、性能优化策略

7.1 避免不必要的重渲染

❌ 优化前

function UnoptimizedForm() {
  const [state, action, isPending] = useActionState(...);
  
  return (
    <form>
      <!-- 所有字段都会重渲染 -->
      <input type="text" name="field1" />
      <input type="text" name="field2" />
      <button>提交</button>
    </form>
  );
}

✅ 优化后

function OptimizedForm() {
  const [state, action, isPending] = useActionState(...);
  
  return (
    <form>
      <!-- 使用 React.memo -->
      <MemoizedFields />
      <SubmitButton isPending={isPending} />
    </form>
  );
}

const MemoizedFields = React.memo(function FormFields() {
  return (
    <>
      <input type="text" name="field1" />
      <input type="text" name="field2" />
    </>
  );
});

九、常见问题与解决方案

9.1 useActionState 常见问题

❌ 状态不更新

// 错误：直接修改状态
const [state, action, isPending] = useActionState(
  async (prevState, formData) => {
    prevState.count += 1; // 直接修改
    return prevState;
  },
  { count: 0 }
);

✅ 正确做法

// 正确：返回新状态
const [state, action, isPending] = useActionState(
  async (prevState, formData) => {
    return { count: prevState.count + 1 }; // 新对象
  },
  { count: 0 }
);

十、总结与最佳实践

10.1 核心总结

useActionState 的核心价值

  • 状态管理：统一管理表单状态
  • 异步流程控制：内置 pending 状态
  • 错误处理：集中处理验证错误
  • 数据持久化：支持状态恢复

useFormStatus 的核心价值

  • 状态感知：感知父级表单状态
  • 组件解耦：提高组件复用性
  • 用户体验优化：精细化 UI 反馈
  • 性能优化：避免不必要重渲染

10.2 最佳实践指南

🎯 实践1：合理分工

使用 useActionState 管理业务状态，使用 useFormStatus 优化用户体验。

🎯 实践2：错误处理策略

实现分层错误处理：表单验证 → 业务逻辑 → API 调用 → 未捕获错误。

🎯 实践3：性能优化组合

结合 React.memo、useMemo、useCallback 和虚拟列表等技术。

10.3 最终建议

💡 记住： useActionState 是状态的管理者，useFormStatus 是状态的感知者。合理运用这对黄金组合，将大幅提升您的 React 应用开发效率和用户体验。
