1阶段一：Java基础夯实（第1-8周）

1.1 阶段目标

掌握Java语言核心语法与面向对象编程思想，熟练使用集合框架、IO/NIO、Lambda与Stream API，掌握JDK 17新特性。完成本阶段后，能独立编写高质量Java控制台应用和简易网络程序。

知识点掌握程度重点/难点
基本数据类型与运算精通自动装箱/拆箱、类型提升、== vs equals
流程控制与数组精通数组内存模型、多维数组
类与对象精通构造器、this/super、初始化顺序
封装、继承、多态精通多态的实现机制、动态绑定
抽象类与接口精通JDK8+接口默认方法/静态方法
内部类与枚举熟练匿名内部类、枚举单例

// Spring Boot自动配置核心流程
// 1. @SpringBootApplication = @SpringBootConfiguration + @EnableAutoConfiguration + @ComponentScan
// 2. @EnableAutoConfiguration → @Import(AutoConfigurationImportSelector)
// 3. 加载META-INF/spring/...AutoConfiguration.imports
// 4. 根据@ConditionalOnClass/@ConditionalOnMissingBean等条件过滤
// 5. 满足条件的配置类生效，自动注册Bean
@Configuration
@ConditionalOnClass(RedisTemplate.class)
@EnableConfigurationProperties(RedisCustomProperties.class)
public class RedisCustomAutoConfiguration {
    @Bean @ConditionalOnMissingBean
    public RedisService redisService(RedisTemplate<String, Object> redisTemplate,
                                      RedisCustomProperties properties) {
        return new RedisService(redisTemplate, properties);
    }
}

🔍常见面试题解析

Q1: HashMap底层实现原理？为什么用红黑树？

答：JDK1.8采用数组+链表+红黑树。计算hash→定位下标→插入/遍历。链表长度≥8且数组≥64转红黑树（O(logn) vs O(n)）。红黑树节点≤6退化回链表。扩容：超过threshold(容量×0.75)时2倍扩容。

Q2: volatile的作用？为什么不能保证原子性？

答：作用：1.保证可见性 2.禁止指令重排。不能保证原子性：i++的读取→修改→写回三步非原子。解决：AtomicInteger(CAS)或synchronized/ReentrantLock。应用：DCL单例、状态标志位。

Q3: 线程池核心参数？如何合理配置？

答：7大参数：corePoolSize、maximumPoolSize、keepAliveTime、unit、workQueue、threadFactory、handler。CPU密集型：核数+1；IO密集型：核数×2。队列选有界防OOM。拒绝策略推荐CallerRunsPolicy。

Q4: G1和ZGC的区别？

答：G1：基于Region分代收集，停顿可控但非确定性。ZGC：着色指针+读屏障，停顿<10ms且与堆大小无关。选择：一般用G1；超低延迟或TB级堆选ZGC。

Q5: Spring Bean的生命周期？

答：实例化→属性赋值→Aware接口→BeanPostProcessor.before→@PostConstruct/afterPropertiesSet/init-method→BeanPostProcessor.after(AOP代理)→就绪→@PreDestroy/destroy

Q6: Spring Boot自动配置原理？

答：@EnableAutoConfiguration→AutoConfigurationImportSelector→加载spring.factories/imports文件→@Conditional条件过滤→满足条件的配置类注册Bean。核心：约定大于配置+条件装配。

Q7: CAP定理？如何取舍？

答：CAP最多同时满足两个。P不可避免，所以CP(ZooKeeper)或AP(Nacos临时实例/Eureka)。互联网系统多选AP+最终一致性(BASE)。

Q8: MySQL MVCC原理？

答：隐藏列DB_TRX_ID+DB_ROLL_PTR→Undo Log版本链→ReadView判断可见性。RC每次SELECT新ReadView；RR复用第一次的ReadView。读写不阻塞。

Q9: Maven依赖冲突如何解决？

答：mvn dependency:tree查看依赖树。原则：最短路径优先→声明顺序优先。解决：exclusions排除、dependencyManagement统一版本、BOM导入。

Q10: JDK 17有哪些重要新特性？

答：Records(不可变数据载体)、Sealed Classes(受限继承)、模式匹配instanceof、Switch表达式、Text Blocks(多行字符串)。Spring Boot 3.x要求最低JDK 17。

常见问题FAQ

Q: 零基础可以直接学Spring Boot吗？

答：不建议。Spring Boot建立在Java基础和Spring框架之上，跳过基础会导致理解困难。建议先完成阶段一和阶段二，再学习Spring Boot。

Q: JDK 17和JDK 8/11该选哪个？

答：选JDK 17。它是LTS版本，Spring Boot 3.x要求最低JDK 17，新特性（Records/Sealed/模式匹配）大幅提升开发效率，且是当前互联网大厂的主流选择。

Q: Maven和Gradle该学哪个？

答：优先学Maven。国内大厂以Maven为主，生态更成熟。掌握Maven后再了解Gradle即可。

Q: 学习时间不够怎么办？

答：调整节奏，每个阶段可延长1-2周。关键是保持每天至少1-2小时的编码练习，周末集中做项目。不要追求速度，理解深度更重要。
