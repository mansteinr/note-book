# 数据输入与布尔类型

本教程将介绍 Python 中的数据输入方式以及布尔类型的使用,这是程序与用户交互、进行逻辑判断的基础。

---

## 一、数据输入:`input()` 语句

### 1.1 `input()` 的基本用法

`input()` 是 Python 内置函数,用于从控制台读取用户输入。它会暂停程序执行,等待用户输入内容并按下回车键,然后返回用户输入的内容。

**重要提示:`input()` 返回的永远是字符串类型(`str`),即使用户输入的是数字。**

```python
# 基本用法:读取用户输入
name = input("请输入你的名字: ")
print("你好," + name + "!")
```

运行示例:

```
请输入你的名字: 小明
你好,小明!
```

### 1.2 `input()` 返回的是字符串

这是一个初学者最容易踩坑的地方,看下面的示例:

```python
# 错误示范:直接使用 input 的返回值进行数学运算
num = input("请输入一个数字: ")
# 此时 num 是字符串类型,即使输入 10,它也是 "10"
print("你输入的是:", num)
print("类型是:", type(num))  # <class 'str'>
```

运行示例:

```
请输入一个数字: 10
你输入的是: 10
类型是: <class 'str'>
```

如果直接对字符串进行数学运算,会引发错误:

```python
# 这样会报错 TypeError
# num = input("请输入一个数字: ")
# result = num + 5  # 字符串不能直接和整数相加
```

### 1.3 `input()` 结合类型转换

要处理用户输入的数字,需要将字符串转换为数值类型。常用的转换函数:

- `int()`:转换为整数
- `float()`:转换为浮点数
- `str()`:转换为字符串

```python
# 将输入的字符串转换为整数
age_str = input("请输入你的年龄: ")
age = int(age_str)  # 将字符串转换为整数
print("明年你", age + 1, "岁")
```

运行示例:

```
请输入你的年龄: 18
明年你 19 岁
```

也可以写成一行(更简洁):

```python
# 一行写法:转换与输入同时进行
age = int(input("请输入你的年龄: "))
print("你的年龄是:", age)
print("年龄的类型是:", type(age))  # <class 'int'>
```

### 1.4 综合示例:计算两数之和

```python
# 综合示例:读取两个数字并计算它们的和
print("=== 加法计算器 ===")
num1 = int(input("请输入第一个整数: "))
num2 = int(input("请输入第二个整数: "))

total = num1 + num2
print(f"{num1} + {num2} = {total}")
```

运行示例:

```
=== 加法计算器 ===
请输入第一个整数: 12
请输入第二个整数: 30
12 + 30 = 42
```

### 1.5 浮点数输入示例

```python
# 读取浮点数输入
height = float(input("请输入你的身高(米): "))
weight = float(input("请输入你的体重(千克): "))

# 计算 BMI 指数
bmi = weight / (height ** 2)
print(f"你的 BMI 指数是: {bmi:.2f}")
```

运行示例:

```
请输入你的身高(米): 1.75
请输入你的体重(千克): 68
你的 BMI 指数是: 22.20
```

## 二、布尔类型 `bool`

### 2.1 什么是布尔类型

布尔类型(`bool`)是 Python 中表示逻辑真假的数据类型,它只有两个值:

- `True`(真):首字母必须大写
- `False`(假):首字母必须大写

**注意:Python 是大小写敏感的,`true` 和 `false` 不是布尔值,会报错。**

```python
# 布尔类型的定义
is_student = True
is_admin = False

print("是否是学生:", is_student)
print("是否是管理员:", is_admin)
print("类型是:", type(is_student))  # <class 'bool'>
```

运行结果:

```
是否是学生: True
是否是管理员: False
类型是: <class 'bool'>
```

### 2.2 布尔值用于存储比较结果

布尔类型最常见的用途是存储比较运算的结果:

```python
# 布尔值可以存储比较运算的结果
age = 20
is_adult = age >= 18  # 比较 age 是否大于等于 18

print("年龄是:", age)
print("是否成年:", is_adult)
```

运行结果:

```
年龄是: 20
是否成年: True
```

## 三、比较运算符

比较运算符用于比较两个值,返回的结果一定是布尔值 `True` 或 `False`。

| 运算符 | 含义 | 示例 | 结果 |
| :---: | :---: | :---: | :---: |
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `5 <= 3` | `False` |

### 3.1 等于运算符 `==`

**注意:`=` 是赋值运算符,`==` 才是比较运算符,初学者极易混淆。**

```python
# 等于比较
a = 10
b = 10
c = 20

print(a == b)  # True,因为 a 和 b 相等
print(a == c)  # False,因为 a 和 c 不相等

# 字符串也可以比较
name1 = "Tom"
name2 = "Tom"
print(name1 == name2)  # True
```

运行结果:

```
True
False
True
```

### 3.2 不等于运算符 `!=`

```python
# 不等于比较
x = 5
y = 10
print(x != y)  # True,因为 x 不等于 y
print(x != 5)  # False,因为 x 等于 5
```

运行结果:

```
True
False
```

### 3.3 大小比较运算符

```python
# 大小比较
score = 85

# 大于
print(score > 60)   # True,85 大于 60
print(score > 100)  # False,85 不大于 100

# 小于
print(score < 100)  # True,85 小于 100
print(score < 60)   # False,85 不小于 60

# 大于等于
print(score >= 85)  # True,85 等于 85
print(score >= 90)  # False,85 小于 90

# 小于等于
print(score <= 85)  # True,85 等于 85
print(score <= 80)  # False,85 大于 80
```

运行结果:

```
True
False
True
False
True
False
True
False
```

## 四、综合示例

### 4.1 读取用户输入并判断

```python
# 综合示例:读取用户信息并进行判断
print("=== 用户信息录入系统 ===")

# 读取用户姓名
name = input("请输入你的姓名: ")

# 读取用户年龄并转换为整数
age = int(input("请输入你的年龄: "))

# 读取用户身高并转换为浮点数
height = float(input("请输入你的身高(米): "))

print("\n=== 信息汇总 ===")
print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"身高: {height} 米")

# 使用比较运算符进行判断
is_adult = age >= 18
is_tall = height >= 1.7

print(f"是否成年: {is_adult}")
print(f"是否高于 1.7 米: {is_tall}")
```

运行示例:

```
=== 用户信息录入系统 ===
请输入你的姓名: 小明
请输入你的年龄: 20
请输入你的身高(米): 1.75

=== 信息汇总 ===
姓名: 小明
年龄: 20
身高: 1.75 米
是否成年: True
是否高于 1.7 米: True
```

### 4.2 密码验证示例

```python
# 密码验证示例
correct_password = "123456"

# 读取用户输入的密码
user_input = input("请输入密码: ")

# 比较输入的密码是否正确

```

运行示例:

```
请输入密码: 123456
密码正确: True
```

### 4.3 成绩判断示例

```python
# 成绩判断示例
score = int(input("请输入你的成绩(0-100): "))

# 使用多个比较运算符
is_pass = score >= 60           # 是否及格
is_excellent = score >= 90      # 是否优秀

print(f"成绩: {score}")
print(f"是否及格: {is_pass}")
print(f"是否优秀: {is_excellent}")
print(f"是否满分: {is_perfect}")
```

运行示例:

```

是否及格: True
是否优秀: True
是否满分: False
```

## 五、小结

| 知识点 | 要点 |
| :--- | :--- |
| `input()` | 读取用户输入,返回值永远是字符串 |
| 类型转换 | `int()`、`float()` 将字符串转为数值 |
| `bool` 类型 | 只有 `True` 和 `False` 两个值,首字母大写 |
| 比较运算符 | `==` `!=` `>` `<` `>=` `<=`,返回布尔值 |
| `=` 与 `==` | `=` 赋值,`==` 比较 |

> **学习建议:** 多动手编写交互式程序,加深对 `input()` 返回字符串这一特性的理解,避免在类型转换上出错。
