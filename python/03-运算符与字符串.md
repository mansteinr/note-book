# 运算符与字符串

## 一、运算符分类

运算符是用于执行各种运算的特殊符号。Python 中的运算符可以分为以下几类：

- 算术运算符
- 赋值运算符
- 比较运算符
- 逻辑运算符
- 位运算符

### 1.1 算术运算符

算术运算符用于执行数学运算。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2.5` |
| `//` | 整除（地板除） | `5 // 2` | `2` |
| `%` | 取余（取模） | `5 % 2` | `1` |
| `**` | 幂运算 | `2 ** 3` | `8` |

```python
# 算术运算符示例
a = 10
b = 3

# 加法
print("加法：", a + b)          # 13

# 减法
print("减法：", a - b)          # 7

# 乘法
print("乘法：", a * b)          # 30

# 除法（结果总是浮点数）
print("除法：", a / b)          # 3.3333333333333335

# 整除（向下取整，直接去掉小数部分）
print("整除：", a // b)         # 3

# 取余（取模运算，返回除法的余数）
print("取余：", a % b)          # 1

# 幂运算（计算a的b次方）
print("幂运算：", a ** b)       # 1000
```

#### 1.1.1 除法与整除的区别

```python
# 普通除法：结果总是浮点数
print(10 / 2)     # 5.0（虽然能整除，但结果是浮点数）
print(10 / 3)     # 3.3333333333333335

# 整除：返回不大于结果的最大整数
print(10 // 3)    # 3
print(-10 // 3)   # -4（注意：负数整除向下取整）

# 取余运算
print(10 % 3)     # 1
print(-10 % 3)    # 2（Python的取余结果与除数同号）
```

#### 1.1.2 算术运算符的综合应用

```python
# 计算圆的面积和周长
radius = 5
pi = 3.14159
area = pi * radius ** 2        # 面积 = π × r²
circumference = 2 * pi * radius # 周长 = 2 × π × r
print("圆的面积：", area)            # 78.53975
print("圆的周长：", circumference)    # 31.4159

# 数字拆分：获取一个三位数的各位数字
num = 456
ones = num % 10                # 个位：6
tens = num // 10 % 10          # 十位：5
hundreds = num // 100          # 百位：4
print(f"数字{num}的百位：{hundreds}，十位：{tens}，个位：{ones}")
```

### 1.2 赋值运算符

赋值运算符用于给变量赋值。

| 运算符 | 描述 | 示例 | 等价于 |
|--------|------|------|--------|
| `=` | 简单赋值 | `a = 5` | `a = 5` |
| `+=` | 加法赋值 | `a += 3` | `a = a + 3` |
| `-=` | 减法赋值 | `a -= 3` | `a = a - 3` |
| `*=` | 乘法赋值 | `a *= 3` | `a = a * 3` |
| `/=` | 除法赋值 | `a /= 3` | `a = a / 3` |
| `//=` | 整除赋值 | `a //= 3` | `a = a // 3` |
| `%=` | 取余赋值 | `a %= 3` | `a = a % 3` |
| `**=` | 幂赋值 | `a **= 3` | `a = a ** 3` |

```python
# 赋值运算符示例
a = 10
print("初始值：", a)    # 10

# 加法赋值
a += 5
print("a += 5：", a)    # 15

# 减法赋值
a -= 3
print("a -= 3：", a)    # 12

# 乘法赋值
a *= 2
print("a *= 2：", a)    # 24

# 除法赋值（结果为浮点数）
a /= 4
print("a /= 4：", a)    # 6.0

# 整除赋值
a //= 2
print("a //= 2：", a)   # 3.0

# 取余赋值
a %= 2
print("a %= 2：", a)    # 1.0

# 幂赋值
a = 3
a **= 2
print("a **= 2：", a)   # 9
```

### 1.3 比较运算符

比较运算符用于比较两个值，返回布尔值 `True` 或 `False`。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `5 <= 3` | `False` |

```python
# 比较运算符示例
a = 10
b = 5

# 等于
print(a == b)    # False

# 不等于
print(a != b)    # True

# 大于
print(a > b)     # True

# 小于
print(a < b)     # False

# 大于等于
print(a >= 10)   # True

# 小于等于
print(a <= 10)   # True

# 比较运算符常用于条件判断
age = 18
print("是否成年：", age >= 18)    # True

score = 85
print("是否及格：", score >= 60)  # True
print("是否优秀：", score >= 90)  # False

# 字符串也可以比较（按字典序比较）
print("apple" < "banana")    # True
print("apple" == "apple")    # True
```

### 1.4 逻辑运算符

逻辑运算符用于组合多个条件，返回布尔值。

| 运算符 | 描述 | 说明 |
|--------|------|------|
| `and` | 逻辑与 | 两边都为True，结果才为True |
| `or` | 逻辑或 | 两边任一个为True，结果就为True |
| `not` | 逻辑非 | 取反，True变False，False变True |

#### 1.4.1 逻辑运算真值表

| A | B | A and B | A or B | not A |
|---|---|---------|--------|-------|
| True | True | True | True | False |
| True | False | False | True | False |
| False | True | False | True | True |
| False | False | False | False | True |

```python
# 逻辑运算符示例
age = 20
has_id = True

# and：两个条件都满足才为True
print("成年且有身份证：", age >= 18 and has_id)    # True

# or：任一条件满足就为True
has_vip = False
has_coupon = True
print("有VIP或有优惠券：", has_vip or has_coupon)  # True

# not：取反
is_raining = False
print("天没下雨：", not is_raining)    # True

# 组合使用
score = 85
is_attending = True
# 成绩及格且出勤率合格
print("是否通过：", score >= 60 and is_attending)    # True
```

#### 1.4.2 逻辑运算的短路特性

Python 的逻辑运算具有**短路特性**（Short-circuit evaluation）：

- `and`：如果第一个条件为 False，则不再计算第二个条件
- `or`：如果第一个条件为 True，则不再计算第二个条件

```python
# and的短路特性
# 当a为False时，不会计算b，直接返回False
a = False
b = True
print(a and b)    # False（a为False，直接返回，不计算b）

# or的短路特性
# 当a为True时，不会计算b，直接返回True
a = True
b = False
print(a or b)     # True（a为True，直接返回，不计算b）

# 利用短路特性避免错误
user_input = ""   # 假设用户输入为空字符串
# 如果user_input为空，不会执行len()函数，避免错误
if user_input and len(user_input) > 5:
    print("输入有效")
else:
    print("输入无效")    # 输出此结果
```

### 1.5 位运算符

位运算符直接对整数的二进制位进行操作。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `&` | 按位与 | `5 & 3` | `1` |
| `\|` | 按位或 | `5 \| 3` | `7` |
| `^` | 按位异或 | `5 ^ 3` | `6` |
| `~` | 按位取反 | `~5` | `-6` |
| `<<` | 左移 | `5 << 1` | `10` |
| `>>` | 右移 | `5 >> 1` | `2` |

```python
# 位运算符示例
a = 5    # 二进制：0101
b = 3    # 二进制：0011

# 按位与：对应位都为1，结果才为1
print("a & b =", a & b)     # 1   (二进制：0001)

# 按位或：对应位任一为1，结果就为1
print("a | b =", a | b)     # 7   (二进制：0111)

# 按位异或：对应位不同为1，相同为0
print("a ^ b =", a ^ b)     # 6   (二进制：0110)

# 按位取反：0变1，1变0（包括符号位）
print("~a =", ~a)           # -6

# 左移：所有位向左移动n位，相当于乘以2的n次方
print("a << 1 =", a << 1)   # 10  (5 * 2 = 10)

# 右移：所有位向右移动n位，相当于除以2的n次方（取整）
print("a >> 1 =", a >> 1)   # 2   (5 // 2 = 2)
```

#### 1.5.1 位运算的应用场景

```python
# 判断奇偶性（n & 1，结果为0是偶数，为1是奇数）
num = 7
print(f"{num}是奇数：", (num & 1) == 1)    # True

num = 8
print(f"{num}是偶数：", (num & 1) == 0)    # True

# 交换两个变量（不用临时变量）
x = 10
y = 20
x = x ^ y
y = x ^ y
x = x ^ y
print(f"交换后：x = {x}, y = {y}")    # x = 20, y = 10

# 快速乘除2的n次方
print(5 << 3)    # 40 (5 * 8)
print(40 >> 3)  # 5  (40 // 8)
```

## 二、字符串

### 2.1 字符串的三种定义方式

Python 中字符串可以用三种方式定义：

- **单引号** `'...'`
- **双引号** `"..."`
- **三引号** `'''...'''` 或 `"""..."""`（可跨多行）

```python
# 单引号定义字符串
str1 = 'Hello, Python!'
print(str1)

# 双引号定义字符串
str2 = "你好，世界"
print(str2)

# 三引号定义字符串（可跨多行）
str3 = """这是
一个
多行字符串"""
print(str3)

# 三引号也可以用单引号
str4 = '''这也是
多行字符串'''
print(str4)
```

### 2.2 字符串的嵌套使用

当字符串内容本身包含引号时，可以使用不同的引号来避免冲突：

```python
# 字符串内容包含单引号，用双引号定义
str1 = "He said, 'Hello!'"
print(str1)    # He said, 'Hello!'

# 字符串内容包含双引号，用单引号定义
str2 = 'She said, "Hi!"'
print(str2)    # She said, "Hi!"

# 使用转义字符（反斜杠\）处理引号
str3 = 'It\'s a nice day'
print(str3)    # It's a nice day

str4 = "He said, \"Hello!\""
print(str4)    # He said, "Hello!"

# 三引号中可以自由使用单双引号
str5 = """He said, 'Hello!' and she said, "Hi!" """
print(str5)
```

### 2.3 字符串拼接

使用 `+` 运算符可以将多个字符串拼接成一个字符串：

```python
# 字符串拼接
str1 = "Hello"
str2 = "World"
result = str1 + " " + str2
print(result)    # Hello World

# 拼接字符串和变量
name = "张三"
greeting = "你好，" + name + "！"
print(greeting)    # 你好，张三！

# 注意：字符串不能直接和数字拼接，需要先转换
age = 18
# info = "我今年" + age + "岁"    # 报错！
info = "我今年" + str(age) + "岁"  # 正确，将数字转为字符串
print(info)    # 我今年18岁

# 多个字符串拼接
part1 = "Python"
part2 = "是"
part3 = "一门"
part4 = "编程语言"
sentence = part1 + part2 + part3 + part4
print(sentence)    # Python是一门编程语言
```

## 三、字符串格式化

字符串格式化是将变量或表达式的值插入到字符串中的方法。Python 提供了三种字符串格式化方式。

### 3.1 方式一：%占位符格式化

这是最早的字符串格式化方式，使用 `%` 占位符：

| 占位符 | 说明 |
|--------|------|
| `%s` | 字符串 |
| `%d` | 整数 |
| `%f` | 浮点数 |
| `%%` | 输出%号本身 |

```python
# %s：字符串占位符
name = "张三"
message = "你好，%s！" % name
print(message)    # 你好，张三！

# %d：整数占位符
age = 18
message = "我今年%d岁" % age
print(message)    # 我今年18岁

# %f：浮点数占位符
height = 1.75
message = "身高%f米" % height
print(message)    # 身高1.750000米

# 多个占位符
name = "李四"
age = 25
height = 1.80
message = "姓名：%s，年龄：%d，身高：%f米" % (name, age, height)
print(message)
# 姓名：李四，年龄：25，身高：1.800000米

# 输出%号本身
print("完成度：100%%")    # 完成度：100%
```

### 3.2 字符串格式化的精度控制

在使用 `%f` 时，可以控制小数点后的位数，格式为 `%.nf`，其中 `n` 是保留的小数位数：

```python
# 默认浮点数输出（6位小数）
pi = 3.141592653589793
print("默认：      %f" % pi)        # 3.141593

# 保留2位小数
print("保留2位：  %.2f" % pi)       # 3.14

# 保留4位小数
print("保留4位：  %.4f" % pi)        # 3.1416

# 不保留小数（自动四舍五入）
print("不保留小数：%.0f" % pi)       # 3

# 整数也可以设置宽度（不够前面补空格或0）
num = 42
print("宽度5位：  %5d" % num)        #    42（前面3个空格）
print("补零：     %05d" % num)       # 00042

# 综合示例
name = "张三"
age = 18
score = 95.5
print("姓名：%s，年龄：%d，成绩：%.1f分" % (name, age, score))
# 姓名：张三，年龄：18，成绩：95.5分
```

### 3.3 方式二：format()方法

`format()` 方法是 Python 3 推荐的字符串格式化方式，使用 `{}` 作为占位符：

```python
# 基本用法：按顺序填入
name = "张三"
age = 18
message = "我叫{}，今年{}岁".format(name, age)
print(message)    # 我叫张三，今年18岁

# 通过索引指定顺序
message = "{1}今年{0}岁".format(age, name)
print(message)    # 张三今年18岁

# 通过变量名指定
message = "我叫{name}，今年{age}岁".format(name="李四", age=20)
print(message)    # 我叫李四，今年20岁

# 控制精度
pi = 3.1415926
print("π = {:.2f}".format(pi))    # π = 3.14
print("π = {:.4f}".format(pi))    # π = 3.1416

# 设置宽度
num = 42
print("宽度5位：{:5d}".format(num))      #    42
print("补零：{:05d}".format(num))        # 00042

# 不同类型混合
name = "王五"
age = 22
score = 88.5
message = "姓名：{0}，年龄：{1}，成绩：{2:.1f}".format(name, age, score)
print(message)    # 姓名：王五，年龄：22，成绩：88.5

# 对齐方式
text = "hello"
print("左对齐：{:<10}".format(text))    # hello     （右补空格）
print("右对齐：{:>10}".format(text))    #      hello（左补空格）
print("居中：  {:^10}".format(text))    #   hello   （两侧补空格）
```

### 3.4 方式三：f-string（推荐方式）

f-string（格式化字符串字面量）是 Python 3.6 引入的字符串格式化方式，语法简洁，性能更好，是目前**最推荐**的格式化方式。

使用方法：在字符串前加 `f` 或 `F`，然后在 `{}` 中直接写变量名或表达式。

```python
# 基本用法
name = "张三"
age = 18
message = f"我叫{name}，今年{age}岁"
print(message)    # 我叫张三，今年18岁

# 直接在{}中使用表达式
a = 10
b = 3
print(f"{a} + {b} = {a + b}")    # 10 + 3 = 13
print(f"{a} * {b} = {a * b}")    # 10 * 3 = 30

# 控制精度
pi = 3.141592653589793
print(f"π = {pi:.2f}")    # π = 3.14
print(f"π = {pi:.4f}")    # π = 3.1416

# 设置宽度和对齐
num = 42
print(f"宽度5位：{num:5d}")       #    42
print(f"补零：{num:05d}")         # 00042

text = "hello"
print(f"左对齐：{text:<10}")      # hello     
print(f"右对齐：{text:>10}")      #      hello
print(f"居中：{text:^10}")        #   hello   

# 调用函数
def get_greeting(name):
    return f"你好，{name}"

user_name = "李四"
print(f"问候：{get_greeting(user_name)}")

# 使用字典
user = {"name": "王五", "age": 25}
print(f"用户：{user['name']}，年龄：{user['age']}")

# 多行f-string
name = "赵六"
age = 30
info = f"""
姓名：{name}
年龄：{age}
"""
print(info)
```

### 3.5 三种格式化方式对比

```python
name = "张三"
age = 18
score = 95.5

# 方式1：%占位符（旧方式）
msg1 = "姓名：%s，年龄：%d，成绩：%.1f" % (name, age, score)
print("方式1：", msg1)

# 方式2：format()方法
msg2 = "姓名：{}，年龄：{}，成绩：{:.1f}".format(name, age, score)
print("方式2：", msg2)

# 方式3：f-string（推荐）
msg3 = f"姓名：{name}，年龄：{age}，成绩：{score:.1f}"
print("方式3：", msg3)

# 三种方式输出相同的结果：
# 姓名：张三，年龄：18，成绩：95.5
```

| 方式 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| `%` 占位符 | 兼容性好 | 语法繁琐，类型需匹配 | ⭐⭐ |
| `format()` | 功能强大 | 语法稍长 | ⭐⭐⭐ |
| f-string | 语法简洁，性能好 | 需要 Python 3.6+ | ⭐⭐⭐⭐⭐ |

### 3.6 对表达式进行格式化

f-string 的强大之处在于可以在 `{}` 中直接写表达式：

```python
# 直接进行数学运算
a = 10
b = 3
print(f"{a} ÷ {b} = {a / b:.2f}")    # 10 ÷ 3 = 3.33
print(f"{a} 的 {b} 次方 = {a ** b}")  # 10 的 3 次方 = 1000

# 调用函数
text = "hello world"
print(f"大写：{text.upper()}")        # 大写：HELLO WORLD
print(f"长度：{len(text)}")           # 长度：11

# 条件表达式
age = 18
print(f"{'成年' if age >= 18 else '未成年'}")    # 成年

# 列表操作
numbers = [1, 2, 3, 4, 5]
print(f"列表：{numbers}")
print(f"列表长度：{len(numbers)}")
print(f"最大值：{max(numbers)}")
print(f"最小值：{min(numbers)}")
print(f"总和：{sum(numbers)}")

# 复杂表达式
radius = 5
pi = 3.14159
print(f"半径为{radius}的圆，面积 = {pi * radius ** 2:.2f}")    # 面积 = 78.54

# 使用=调试输出（Python 3.8+）
x = 10
y = 20
print(f"{x = }, {y = }")    # x = 10, y = 20
print(f"{x + y = }")        # x + y = 30
```

## 四、综合练习示例

### 4.1 练习1：学生成绩信息卡

```python
# 学生成绩信息卡
student_name = "张三"
student_class = "高三(1)班"
math_score = 95
english_score = 88
chinese_score = 92

# 计算总分和平均分
total_score = math_score + english_score + chinese_score
average_score = total_score / 3

# 判断是否优秀学生
is_excellent = average_score >= 90

# 使用f-string输出信息卡
print("=" * 40)
print("       学生成绩信息卡")
print("=" * 40)
print(f"姓名：{student_name}")
```

### 4.3 练习3：温度转换器

```python
# 温度转换器：摄氏度与华氏度互转
celsius = 37.5  # 摄氏温度

# 摄氏度转华氏度：F = C × 9/5 + 32
fahrenheit = celsius * 9 / 5 + 32

# 华氏度转摄氏度：C = (F - 32) × 5/9
fahrenheit_round = 100  # 华氏温度
celsius_from_f = (fahrenheit_round - 32) * 5 / 9

print("【温度转换器】")
print(f"摄氏温度 {celsius}°C = 华氏温度 {fahrenheit:.2f}°F")
print(f"华氏温度 {fahrenheit_round}°F = 摄氏温度 {celsius_from_f:.2f}°C")

# 判断温度状态
temp = celsius
status = "寒冷" if temp < 10 else ("凉爽" if temp < 25 else ("温暖" if temp < 35 else "炎热"))
print(f"当前温度{celsius}°C，状态：{status}")
```

```python
# BMI身体质量指数计算器
name = "张三"
height = 1.75    # 身高（米）
weight = 70      # 体重（千克）

# BMI公式：体重 / 身高的平方
bmi = weight / (height ** 2)

# 判断BMI范围
if bmi < 18.5:
    status = "偏瘦"
elif bmi < 24:
    status = "正常"
elif bmi < 28:
    status = "偏胖"
else:
    status = "肥胖"

print("【BMI计算器】")
print(f"姓名：{name}")
print(f"身高：{height}米")
print(f"体重：{weight}千克")
print(f"BMI值：{bmi:.2f}")
print(f"身体状况：{status}")
```
