## 1. 函数的初体验

### 1.1 为什么需要函数

在编程过程中，我们经常会遇到以下场景：

- **同一段代码需要重复执行多次**：例如在多个地方计算两个数的和。
- **代码结构臃肿、难以维护**：所有逻辑都堆在一起，阅读和修改非常困难。

函数（Function）就是**将一段具有特定功能的代码封装起来**，方便重复使用，使程序更加模块化、清晰、易于维护。

### 1.2 不使用函数的问题

```python
# 场景：多次计算两个数的和

# 第一次计算
a1 = 10
b1 = 20
sum1 = a1 + b1
print(f"两数之和是: {sum1}")

# 第二次计算
a2 = 30
b2 = 40
sum2 = a2 + b2
print(f"两数之和是: {sum2}")

# 第三次计算
a3 = 50
b3 = 60
sum3 = a3 + b3
print(f"两数之和是: {sum3}")
```

上述代码中，加法和打印的逻辑被重复了三次。如果需要修改逻辑（例如输出格式），就需要修改三处，容易遗漏。

### 1.3 使用函数后的改进

```python
def add(a, b):
    """计算两个数的和并打印结果"""
    result = a + b
    print(f"两数之和是: {result}")


# 只需要调用函数即可，无需重复写逻辑
add(10, 20)
add(30, 40)
add(50, 60)
```

### 1.4 函数的优势

| 优势       | 说明                                       |
| ---------- | ------------------------------------------ |
| 代码复用   | 一次定义，多次调用                         |
| 结构清晰   | 将复杂问题拆分为多个小函数                 |
| 易于维护   | 修改逻辑只需改一处                         |
| 降低耦合   | 函数之间相互独立，便于测试和调试           |

## 2. 函数基础定义语法

### 2.1 函数定义语法

```python
def 函数名():
    函数体（要执行的代码）
```

说明：
- `def` 是 define 的缩写，表示定义函数。
- 函数名应使用**小写字母**，单词之间用下划线分隔（snake_case 命名法）。
- 函数名后紧跟圆括号 `()`，括号内可写参数（暂时不写）。
- 冒号 `:` 不可省略。
- 函数体必须**缩进 4 个空格**（PEP 8 规范）。

### 2.2 函数调用

```python
函数名()
```

定义函数后，函数不会自动执行，必须通过 `函数名()` 来调用。

### 2.3 基本示例

```python
def greet():
    """打印问候语"""
    print("Hello, Python!")
    print("欢迎学习函数")


# 调用函数
greet()
```

运行结果：

```text
Hello, Python!
欢迎学习函数
```

### 2.4 注意事项

```python
# 1. 函数必须先定义后调用
say_hi()  # 错误：NameError: name 'say_hi' is not defined


def say_hi():
    print("Hi")


# 2. 函数可以调用多次
def show_message():
    print("函数被调用了一次")


show_message()
show_message()
show_message()
```

## 4. 函数的传入参数

### 4.1 为什么需要参数

前面的函数只能执行固定逻辑，无法处理不同数据。参数让函数更灵活，能够接收外部传入的数据。

### 4.2 形参和实参

```python
def add(a, b):  # a 和 b 是形式参数（形参）
    """计算两个数的和"""
    result = a + b
    print(f"{a} + {b} = {result}")


add(10, 20)  # 10 和 20 是实际参数（实参）
add(3, 5)
```

- **形参**：定义函数时括号中的变量，相当于占位符。
- **实参**：调用函数时传入的具体值。

### 4.3 位置参数

位置参数按照**顺序**一一对应传递。

```python
def introduce(name, age, city):
    """自我介绍"""
    print(f"我叫{name}，今年{age}岁，来自{city}")


# 参数按位置一一对应
introduce("张三", 18, "北京")
introduce("李四", 20, "上海")
```

运行结果：

```text
我叫张三，今年18岁，来自北京
我叫李四，今年20岁，来自上海
```

注意：位置参数的**顺序不能颠倒**，否则会导致逻辑错误：

```python
introduce("北京", "张三", 18)  # 错误：参数顺序颠倒
# 输出：我叫北京，今年张三岁，来自18
```

### 4.4 多参数示例

```python
def calc_average(score1, score2, score3):
    """计算三门课的平均分"""
    average = (score1 + score2 + score3) / 3
    print(f"平均分是: {average:.2f}")


calc_average(85, 90, 78)
calc_average(92, 88, 95)
```

## 6. 函数的返回值

### 6.1 什么是返回值

函数执行完毕后，可以将一个结果返回给调用者，这个结果就是**返回值**。使用 `return` 关键字。

### 6.2 return 语法

```python
def 函数名(参数):
    函数体
    return 返回值
```

### 6.3 示例

```python
def add(a, b):
    """计算两个数的和并返回结果"""
    result = a + b
    return result


# 接收返回值
sum_result = add(10, 20)
print(f"两数之和: {sum_result}")

# 也可以直接打印返回值
print(f"两数之和: {add(5, 8)}")
```

### 6.4 return 后无值返回 None

```python
def say_hello():
    """没有 return 语句，默认返回 None"""
    print("Hello")


result = say_hello()
print(f"返回值是: {result}")  # 输出: None


def say_hi():
    """return 后没有值，也返回 None"""
    print("Hi")
    return


result = say_hi()
print(f"返回值是: {result}")  # 输出: None
```

### 6.5 return 的作用：结束函数

```python
def check_age(age):
    """return 会立即结束函数"""
    if age < 0:
        return "年龄不能为负数"
    # 如果上面 return 执行了，下面代码不会执行
    if age >= 18:
        return "成年人"
    return "未成年人"


print(check_age(-5))
print(check_age(20))
print(check_age(15))
```

### 6.6 多个 return 的注意事项

```python
def max_number(a, b):
    """返回较大的数"""
    if a > b:
        return a
    return b


print(f"较大的数是: {max_number(10, 20)}")
```

## 7. 函数返回值之 None 类型

### 7.1 None 的概念

`None` 是 Python 中的一个特殊常量，表示"什么都没有"或"无值"。函数没有 `return` 语句，或者 `return` 后没有值时，默认返回 `None`。

```python
def do_nothing():
    """什么都不做"""
    pass


result = do_nothing()
print(result)              # 输出: None
print(type(result))        # 输出: <class 'NoneType'>
print(result is None)      # 输出: True
```

### 7.2 None 在 if 判断中为 False

`None` 在条件判断中等价于 `False`，这是 Python 的重要特性。

```python
def find_user(user_id):
    """模拟查找用户，找不到返回 None"""
    users = {1: "张三", 2: "李四"}
    if user_id in users:
        return users[user_id]
    return None


result = find_user(3)
# None 在 if 中被视为 False
if result:
    print(f"找到用户: {result}")
else:
    print("用户不存在")
```

### 7.3 None 的应用场景

```python
# 应用场景 1：函数作为判断条件
def is_even(number):
    """是偶数返回字符串，否则返回 None"""
    if number % 2 == 0:
        return "偶数"
    return None


result = is_even(10)
if result:
    print(f"判断结果: {result}")
else:
    print("不是偶数")


# 应用场景 2：作为默认值
def greet(name=None):
    """name 默认为 None"""
    if name is None:
        print("你好，陌生人")
    else:
        print(f"你好，{name}")


greet()
greet("张三")
```

### 7.4 比较 None 的正确方式

```python
# 推荐：使用 is 判断 None
value = None
if value is None:
    print("value 是 None")

# 不推荐：使用 == 判断 None（虽然能工作，但不符合规范）
if value == None:  # PEP 8 建议使用 is
    print("value 是 None")
```

## 8. 函数的说明文档

### 8.1 什么是 docstring

函数说明文档（docstring）是用**三引号** `"""..."""` 括起来的字符串，用于说明函数的功能、参数、返回值等信息。

### 8.2 定义 docstring

```python
def add(a, b):
    """
    计算两个数的和

    参数:
        a: 第一个数
        b: 第二个数

    返回:
        两个数的和
    """
    return a + b


# 调用函数
print(add(10, 20))
```

### 8.3 使用 help() 查看文档

```python
def calculate_bmi(weight, height):
    """
    计算 BMI 指数

    参数:
        weight: 体重（千克）
        height: 身高（米）

    返回:
        BMI 指数
    """
    return weight / (height ** 2)


# 使用 help() 查看函数文档
help(calculate_bmi)
```

运行结果：

```text
Help on function calculate_bmi in module __main__:

calculate_bmi(weight, height)
    计算 BMI 指数

    参数:
        weight: 体重（千克）
        height: 身高（米）

    返回:
        BMI 指数
```

### 8.4 通过 __doc__ 属性查看


## 9. 函数的嵌套调用

### 9.1 什么是嵌套调用

函数 A 中调用了函数 B，称为函数的**嵌套调用**。

```python
def func_b():
    """函数 B"""
    print("函数 B 开始执行")
    print("函数 B 执行结束")


def func_a():
    """函数 A，内部调用函数 B"""
    print("函数 A 开始执行")
    func_b()  # 嵌套调用
    print("函数 A 执行结束")


func_a()
```

运行结果：

```text
函数 A 开始执行
函数 B 开始执行
函数 B 执行结束
函数 A 执行结束
```

### 9.2 实际应用示例

```python
def print_line(char="-", times=30):
    """打印分割线"""
    print(char * times)


def print_title(title):
    """打印带分割线的标题"""
    print_line()
    print(title)
    print_line()


print_title("Python 函数教程")
print_title("数据类型", "=", 20)
```

### 9.3 计算多个数据的统计值

```python
def calc_sum(numbers):
    """计算列表元素之和"""
    total = 0
    for num in numbers:
        total += num
    return total


def calc_average(numbers):
    """计算平均值，调用 calc_sum"""
    total = calc_sum(numbers)
    average = total / len(numbers)
    return average


def show_statistics(numbers):
    """显示统计信息"""
    total = calc_sum(numbers)
    average = calc_average(numbers)
    print(f"数据: {numbers}")
    print(f"总和: {total}")
    print(f"平均值: {average:.2f}")


show_statistics([10, 20, 30, 40, 50])
```

## 10. 变量的作用域

### 10.1 局部变量

在函数**内部**定义的变量，称为局部变量。其作用范围仅限于函数内部，函数外部无法访问。

```python
def test():
    """定义局部变量"""
    num = 100  # 局部变量
    print(f"函数内部访问 num: {num}")


test()
# print(num)  # 错误：NameError: name 'num' is not defined
```

### 10.2 全局变量

在函数**外部**定义的变量，称为全局变量。函数内部可以访问，但在函数内部直接修改会创建新的局部变量。

```python
# 全局变量
message = "我是全局变量"


def test():
    """函数内部访问全局变量"""
    print(f"函数内部访问: {message}")


test()
print(f"函数外部访问: {message}")
```

### 10.3 函数内部修改全局变量（错误示例）

```python
count = 100  # 全局变量


def test():
    count = 200  # 这是新建了一个局部变量，并未修改全局变量
    print(f"函数内部 count: {count}")


test()
print(f"函数外部 count: {count}")
```

运行结果：

```text
函数内部 count: 200
函数外部 count: 100
```

### 10.4 global 关键字修改全局变量

```python
count = 100  # 全局变量


def test():
    global count  # 声明使用全局变量
    count = 200  # 修改的是全局变量
    print(f"函数内部 count: {count}")


test()
print(f"函数外部 count: {count}")
```

运行结果：

```text
函数内部 count: 200
函数外部 count: 200
```

### 10.5 局部变量和全局变量的区别

| 特性       | 局部变量                       | 全局变量                       |
| ---------- | ------------------------------ | ------------------------------ |
| 定义位置   | 函数内部                       | 函数外部                       |
| 作用范围   | 仅函数内部                     | 整个程序                       |
| 生命周期   | 函数调用时创建，调用结束销毁   | 程序运行期间一直存在           |
| 命名冲突   | 与全局变量同名时，优先用局部   | 同名局部变量会"遮蔽"全局变量   |

### 10.6 综合示例

```python
# 全局变量
total_score = 0


def add_score(score):
    """添加分数到总分"""
    global total_score
    total_score += score
    print(f"当前总分: {total_score}")


def show_average(count):
    """显示平均分"""
    # count 是局部变量
    average = total_score / count
    print(f"平均分: {average:.2f}")


add_score(85)
add_score(90)
add_score(78)
show_average(3)
```

## 11. 函数综合案例

### 综合案例：简易学生信息管理系统

```python
# 全局变量：存储学生列表
students = []


def add_student(name, age, score):
    """添加学生"""
    student = {
        "name": name,
        "age": age,
        "score": score
    }
    students.append(student)
    print(f"成功添加学生: {name}")


def show_all_students():
    """显示所有学生"""
    if not students:
        print("暂无学生信息")
        return

    print("-" * 40)
    print(f"{'姓名':<10}{'年龄':<10}{'成绩':<10}")
    print("-" * 40)
    for student in students:
        print(f"{student['name']:<10}{student['age']:<10}{student['score']:<10}")
    print("-" * 40)


def calc_average_score():
    """计算平均成绩"""
    if not students:
        print("暂无学生信息")
        return

    total = 0
    for student in students:
        total += student["score"]
    average = total / len(students)
    print(f"全班平均成绩: {average:.2f}")
    return average


def find_student(name):
    """查找学生"""
    for student in students:
        if student["name"] == name:
            print(f"找到学生: {student['name']}, 年龄: {student['age']}, 成绩: {student['score']}")
            return student
    print(f"未找到学生: {name}")
    return None


def find_max_score():
    """查找最高分学生"""
    if not students:
        print("暂无学生信息")
        return None

    max_student = students[0]
    for student in students:
        if student["score"] > max_student["score"]:
            max_student = student
    print(f"最高分学生: {max_student['name']}, 成绩: {max_student['score']}")
    return max_student


# 测试代码
print("=" * 40)
print("学生信息管理系统")
print("=" * 40)

# 添加学生
add_student("张三", 18, 85)
add_student("李四", 19, 92)
add_student("王五", 18, 78)
add_student("赵六", 20, 95)
print()

# 显示所有学生
show_all_students()
print()

# 计算平均成绩
calc_average_score()
print()

# 查找学生
find_student("李四")
find_student("钱七")
print()

# 查找最高分
find_max_score()
```

```text
姓名      年龄      成绩
```

| 参数     | 形参（定义时）和实参（调用时），位置参数按顺序对应         |
| 返回值   | `return` 返回结果，无 return 或 return 无值时返回 None   |
| None     | 表示"无值"，在 if 判断中等价于 False                      |
| 文档     | 三引号字符串 docstring，用 `help()` 或 `__doc__` 查看      |
| 嵌套调用 | 函数中调用其他函数                                        |
| 作用域   | 局部变量（函数内）、全局变量（函数外），global 修改全局    |

> **学习建议**：函数是编程的核心概念，建议多动手编写小函数，逐步掌握参数传递和返回值的使用。下一章将学习 [数据容器](08-数据容器.md)。
