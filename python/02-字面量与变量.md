# 字面量与变量

## 一、字面量

### 1.1 字面量概念

**字面量**（Literal）是指在代码中直接写出来的、表示固定值的量。例如数字 `100`、字符串 `"hello"`、布尔值 `True` 等，它们都是字面量，因为它们的值在代码中直接写明，不会被改变。

简单理解：字面量就是代码中**字面上**看到的值。

### 1.2 常用字面量类型

Python 中常用的字面量类型包括：

| 字面量类型 | 说明 | 示例 |
|----------|------|------|
| 整数（int） | 不带小数点的数字 | `100`、`-50`、`0` |
| 浮点数（float） | 带小数点的数字 | `3.14`、`-0.5`、`2.0` |
| 字符串（str） | 用引号括起来的文本 | `"hello"`、`'Python'` |
| 布尔值（bool） | 表示真或假 | `True`、`False` |
| 复数（complex） | 复数表示 | `3+4j`、`2-1j` |
| 空值（NoneType） | 表示什么都没有 | `None` |

### 1.3 字面量使用示例

```python
# 整数字面量
print(100)        # 正整数
print(-50)        # 负整数
print(0)          # 零

# 浮点数字面量
print(3.14)      # 普通浮点数
print(-0.5)      # 负浮点数
print(2.0)       # 整数形式的浮点数

# 字符串字面量
print("Hello, Python!")   # 双引号字符串
print('你好，世界')        # 单引号字符串

# 布尔值字面量
print(True)      # 真
print(False)     # 假

# 空值字面量
print(None)      # 空值，表示什么都没有

# 复数字面量
print(3 + 4j)    # 复数，3为实部，4为虚部
```

运行结果：

```
100
-50
0
3.14
-0.5
2.0
Hello, Python!
你好，世界
True
False
None
(3+4j)
```

## 二、变量定义与赋值

### 2.1 什么是变量

**变量**是程序中用来存储数据的容器。可以把变量想象成一个带标签的盒子，盒子里装着数据，标签就是变量名，通过变量名可以访问和修改盒子里的数据。

与字面量不同，变量的值可以在程序运行过程中改变。

### 2.2 变量定义与赋值

在 Python 中，使用赋值运算符 `=` 来定义变量并赋值。语法格式：

```python
变量名 = 值
```

```python
# 定义变量并赋值
name = "张三"        # 字符串变量
age = 18            # 整数变量
height = 1.75       # 浮点数变量
is_student = True   # 布尔变量

# 使用变量（通过变量名访问存储的值）
print(name)
print(age)
print(height)
print(is_student)
```

运行结果：

```
张三
18
1.75
True
```

### 2.3 变量的修改

变量之所以叫"变量"，是因为它的值可以被修改：

```python
# 定义变量
score = 90
print("初始成绩：", score)

# 修改变量的值
score = 95
print("修改后的成绩：", score)

# 变量也可以存储其他类型的值（不推荐）
score = "优秀"
print("再次修改：", score)
```

运行结果：

```
初始成绩： 90
修改后的成绩： 95
再次修改： 优秀
```

### 2.4 变量命名规则

Python 中变量命名需要遵循以下规则：

1. **只能包含**字母、数字、下划线（`_`）
2. **不能以数字开头**
3. **区分大小写**（`Name` 和 `name` 是不同的变量）
4. **不能使用 Python 关键字**（如 `if`、`for`、`while`、`def` 等）
5. **不能包含空格**

```python
# 合法的变量名
name = "张三"
age = 18
_height = 1.75
student_name = "李四"
score2 = 95
MAX_SIZE = 100

# 非法的变量名（会报错）
# 2score = 95      # 不能以数字开头
# student name = "李四"  # 不能包含空格
# for = "循环"     # 不能使用关键字
```

### 2.5 PEP 8命名规范建议

根据 PEP 8 规范，Python 变量命名应遵循以下建议：

1. **变量名和函数名**使用小写字母，单词之间用下划线分隔（**snake_case** 蛇形命名法）
2. **常量**使用全大写字母，单词之间用下划线分隔（**UPPER_CASE**）
3. **类名**使用驼峰命名法（**CamelCase**）
4. 命名应有意义，避免使用 `a`、`b`、`x` 等无意义的名字（除非是简单的计数器）

```python
# 符合PEP 8规范的命名
student_name = "张三"
student_age = 18
max_score = 100
is_valid = True

# 常量使用全大写
MAX_CONNECTIONS = 100
PI = 3.141592653589793
DEFAULT_TIMEOUT = 30

# 类名使用驼峰命名法（后续章节会学习）
# class StudentInfo:
#     pass
```

## 三、数据类型

### 3.1 Python的基本数据类型

Python 中常见的数据类型如下：

| 类型 | 名称 | 说明 | 示例 |
|------|------|------|------|
| `int` | 整数 | 不带小数点的数字 | `100`、`-50`、`0` |
| `float` | 浮点数 | 带小数点的数字 | `3.14`、`-0.5` |
| `str` | 字符串 | 用引号括起来的文本 | `"hello"`、`'你好'` |
| `bool` | 布尔值 | 真或假 | `True`、`False` |
| `complex` | 复数 | 数学中的复数 | `3+4j` |

### 3.2 使用type()查看数据类型

Python 提供了内置函数 `type()` 来查看数据或变量的类型：

```python
# 查看字面量的类型
print(type(100))        # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>
print(type(3 + 4j))     # <class 'complex'>
print(type(None))       # <class 'NoneType'>

# 查看变量的类型
name = "张三"
age = 18
height = 1.75
is_student = True

print(type(name))       # <class 'str'>
print(type(age))        # <class 'int'>
print(type(height))     # <class 'float'>
print(type(is_student)) # <class 'bool'>
```

运行结果：

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'complex'>
<class 'NoneType'>
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

### 3.3 各数据类型详解

#### 3.3.1 整数（int）

整数是没有小数点的数字，Python 3 中的整数没有大小限制（仅受内存限制）：

```python
# 整数示例
positive_num = 100       # 正整数
negative_num = -50      # 负整数
zero = 0                # 零

# Python支持其他进制的整数
binary = 0b1010         # 二进制，等于十进制的10
octal = 0o12            # 八进制，等于十进制的10
hexadecimal = 0xA       # 十六进制，等于十进制的10

print(binary, octal, hexadecimal)
```

#### 3.3.2 浮点数（float）

浮点数是带有小数点的数字，也可以使用科学计数法表示：

```python
# 浮点数示例
pi = 3.14159
e = 2.71828
negative_float = -0.5

# 科学计数法
big_num = 1.5e3         # 1.5 × 10^3 = 1500.0
small_num = 1.5e-3      # 1.5 × 10^-3 = 0.0015

print(pi)
print(big_num)
print(small_num)
```

#### 3.3.3 字符串（str）

字符串是用引号括起来的文本，可以使用单引号、双引号或三引号：

```python
# 字符串示例
str1 = 'Hello'
str2 = "Python"
str3 = """多行
字符串"""
str4 = '也可以用单引号'

print(str1)
print(str2)
print(str3)
```

#### 3.3.4 布尔值（bool）

布尔值只有两个：`True`（真）和 `False`（假），首字母必须大写：

```python
# 布尔值示例
is_student = True
is_teacher = False

print(is_student)
print(is_teacher)

# 布尔值常用于条件判断
age = 18
is_adult = age >= 18
print("是否成年：", is_adult)
```

#### 3.3.5 复数（complex）

复数由实部和虚部组成，虚部用 `j` 表示（数学中用 `i`）：

```python
# 复数示例
c1 = 3 + 4j        # 实部为3，虚部为4
c2 = 2 - 1j        # 实部为2，虚部为-1

print(c1)
print(type(c1))

# 获取实部和虚部
print("实部：", c1.real)
print("虚部：", c1.imag)
```

## 四、数据类型转换

### 4.1 类型转换函数

在程序中，有时需要将一种数据类型转换为另一种类型。Python 提供了以下内置函数进行类型转换：

| 函数 | 说明 | 示例 |
|------|------|------|
| `int(x)` | 将 x 转换为整数 | `int(3.14)` → `3` |
| `float(x)` | 将 x 转换为浮点数 | `float(5)` → `5.0` |
| `str(x)` | 将 x 转换为字符串 | `str(100)` → `"100"` |
| `bool(x)` | 将 x 转换为布尔值 | `bool(0)` → `False` |
| `complex(x)` | 将 x 转换为复数 | `complex(3)` → `3+0j` |

### 4.2 类型转换示例

#### 4.2.1 转换为整数（int）

```python
# 浮点数转整数（直接去掉小数部分，不四舍五入）
float_num = 3.14
int_num = int(float_num)
print(float_num, "->", int_num)     # 3.14 -> 3

# 负浮点数转整数
float_num2 = -2.9
int_num2 = int(float_num2)
print(float_num2, "->", int_num2)  # -2.9 -> -2

# 字符串转整数（字符串必须是合法的整数表示）
str_num = "123"
int_num3 = int(str_num)
print(str_num, "->", int_num3)     # 123 -> 123

# 布尔值转整数
print(int(True))    # 1
print(int(False))   # 0
```

#### 4.2.2 转换为浮点数（float）

```python
# 整数转浮点数
int_num = 100
float_num = float(int_num)
print(int_num, "->", float_num)    # 100 -> 100.0

# 字符串转浮点数（字符串必须是合法的数字表示）
str_num = "3.14"
float_num2 = float(str_num)
print(str_num, "->", float_num2)  # 3.14 -> 3.14

# 布尔值转浮点数
print(float(True))   # 1.0
print(float(False))  # 0.0
```

#### 4.2.3 转换为字符串（str）

```python
# 数字转字符串
num = 100
str_num = str(num)
print(num, "->", str_num)          # 100 -> 100
print(type(num), "->", type(str_num))

float_num = 3.14
str_float = str(float_num)
print(float_num, "->", str_float)   # 3.14 -> 3.14

# 布尔值转字符串
print(str(True))    # True
print(str(False))   # False
```

#### 4.2.4 转换为布尔值（bool）

```python
# 数字转布尔值：0为False，非0为True
print(bool(0))       # False
print(bool(1))       # True
print(bool(-1))      # True
print(bool(3.14))    # True
print(bool(0.0))     # False

# 字符串转布尔值：空字符串为False，非空字符串为True
print(bool(""))      # False
print(bool("hello")) # True
print(bool(" "))      # True（包含空格的字符串不是空字符串）

# None转布尔值
print(bool(None))     # False
```

### 4.3 类型转换注意事项

1. **浮点数转整数**：直接截断小数部分，不进行四舍五入
2. **字符串转数字**：字符串内容必须是合法的数字表示，否则会报错
3. **任何类型都可以转换为字符串**，但反向转换需要内容合法

```python
# 错误示例：无法转换的字符串
# int("3.14")     # 报错：字符串不是合法的整数表示
# int("hello")    # 报错：字符串不是数字

# 正确做法：先将字符串转为浮点数，再转为整数
str_num = "3.14"
num = int(float(str_num))   # 先转float，再转int
print(num)                  # 3
```

### 4.4 隐式类型转换

在某些运算中，Python 会自动进行类型转换（隐式转换）：

```python
# 整数和浮点数运算，结果自动转为浮点数
result1 = 10 + 3.14
print(result1, type(result1))    # 13.14 <class 'float'>

# 整数除法（/）结果总是浮点数
result2 = 10 / 2
print(result2, type(result2))    # 5.0 <class 'float'>

# 布尔值参与运算时，True当作1，False当作0
result3 = 10 + True
print(result3)                   # 11
```

## 五、标识符命名规范

### 5.1 什么是标识符

**标识符**是程序中用来命名变量、函数、类、模块等的名字。在 Python 中，标识符包括变量名、函数名、类名等。

### 5.2 标识符命名规则

Python 标识符命名必须遵守以下规则：

1. **只能包含**字母（a-z, A-Z）、数字（0-9）和下划线（`_`）
2. **不能以数字开头**
3. **区分大小写**：`Name` 和 `name` 是不同的标识符
4. **不能使用 Python 关键字**作为标识符
5. **长度无限制**，但应简洁有意义
6. **不能包含空格**和特殊字符（如 `@`、`$`、`%` 等）

### 5.3 Python关键字

关键字是 Python 语言保留的、具有特殊含义的单词，不能用作标识符。查看所有关键字：

```python
# 查看Python所有关键字
import keyword
print(keyword.kwlist)
```

Python 3.12 的关键字包括：

```
['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await',
 'break', 'class', 'continue', 'def', 'del', 'elif', 'else', 'except',
 'finally', 'for', 'from', 'global', 'if', 'import', 'in', 'is',
 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try',
 'while', 'with', 'yield']
```

### 5.4 PEP 8命名规范

PEP 8 是 Python 官方的编码风格指南，其中关于命名的建议如下：

| 类型 | 命名风格 | 示例 |
|------|---------|------|
| 变量名 | 小写 + 下划线（snake_case） | `student_name`、`user_age` |
| 函数名 | 小写 + 下划线（snake_case） | `calculate_area`、`get_user_info` |
| 类名 | 驼峰命名法（CamelCase） | `StudentInfo`、`MyClass` |
| 常量 | 全大写 + 下划线（UPPER_CASE） | `MAX_SIZE`、`PI` |
| 模块名 | 简短小写 | `math`、`os` |
| 私有变量 | 以下划线开头 | `_private_var` |
| 魔法方法 | 双下划线包围 | `__init__`、`__str__` |

```python
# 变量名：使用snake_case
student_name = "张三"
user_age = 18
is_valid = True
total_count = 100

# 常量：使用UPPER_CASE
MAX_CONNECTIONS = 100
PI = 3.141592653589793
DEFAULT_TIMEOUT = 30
DATABASE_URL = "localhost:3306"

# 函数名：使用snake_case
# def calculate_area(radius):
#     return 3.14 * radius ** 2

# 类名：使用CamelCase
# class StudentInfo:
#     pass
```

### 5.5 命名规范最佳实践

```python
# 好的命名：清晰、有意义
student_name = "张三"
file_path = "/home/user/file.txt"
user_count = 100
is_logged_in = True

# 坏的命名：无意义或缩写过度
# a = "张三"           # 不知道a代表什么
# fp = "/home/user/file.txt"  # 缩写不清晰
# x1 = 100            # 无意义
# flag = True         # 不知道是什么flag

# 布尔变量建议用is_、has_、can_等开头
is_valid = True
has_permission = False
can_edit = True

# 避免使用内置函数名
# list = [1, 2, 3]   # 不要用list作为变量名，会覆盖内置函数
# str = "hello"       # 不要用str作为变量名
```

## 六、变量的多重赋值和链式赋值

### 6.1 多重赋值

Python 支持在一行代码中同时给多个变量赋值，这种方式称为**多重赋值**：

```python
# 同时给多个变量赋不同的值
name, age, height = "张三", 18, 1.75
print(name, age, height)    # 张三 18 1.75

# 多重赋值常用于交换两个变量的值（不需要临时变量）
a = 10
b = 20
print("交换前：a =", a, ", b =", b)    # 交换前：a = 10 , b = 20
a, b = b, a
print("交换后：a =", a, ", b =", b)    # 交换后：a = 20 , b = 10

# 多重赋值也适用于不同类型
user_name, user_age, is_active = "李四", 25, True
print(user_name)    # 李四
print(user_age)     # 25
print(is_active)    # True
```

### 6.2 链式赋值

链式赋值是指将同一个值同时赋给多个变量：

```python
# 链式赋值：多个变量赋相同的值
a = b = c = 100
print(a, b, c)    # 100 100 100

# 链式赋值也可以用于字符串
x = y = z = "hello"
print(x, y, z)   # hello hello hello

# 注意：链式赋值时，所有变量指向同一个对象
# 对于不可变类型（如整数、字符串），这没有问题
# 对于可变类型（如列表），需要特别注意
a = b = [1, 2, 3]
a.append(4)
print(a)    # [1, 2, 3, 4]
print(b)    # [1, 2, 3, 4]  # b也变了！
```

### 6.3 多目标赋值与多重赋值的区别

```python
# 链式赋值：所有变量引用同一个对象
x = y = z = 10
print("链式赋值：", x, y, z)

# 多重赋值：每个变量可以有不同的值
x, y, z = 10, 20, 30
print("多重赋值：", x, y, z)

# 多重赋值解包（unpacking）
# 可以将列表、元组等中的元素分别赋值给多个变量
coordinates = (100, 200)
x_pos, y_pos = coordinates
print("坐标：x =", x_pos, ", y =", y_pos)

# 使用*号收集多余的值
first, *rest = [1, 2, 3, 4, 5]
print("第一个：", first)     # 1
print("剩余：", rest)        # [2, 3, 4, 5]
```

## 七、综合示例

```python
# 综合示例：学生信息管理

# 学生基本信息（多重赋值）
student_name, student_age, student_height = "张三", 18, 1.75

# 学生成绩
math_score = 95
english_score = 88
chinese_score = 92

# 常量定义
MAX_SCORE = 100    # 满分
PASS_SCORE = 60    # 及格分

# 计算总分和平均分
total_score = math_score + english_score + chinese_score
average_score = total_score / 3

# 输出学生信息
print("=" * 30)
print("学生信息")
print("=" * 30)
print("姓名：", student_name)
print("年龄：", student_age)
print("身高：", student_height)
print("数学成绩：", math_score)
print("英语成绩：", english_score)
print("语文成绩：", chinese_score)
print("总分：", total_score)
print("平均分：", average_score)
print("平均分（保留2位小数）：", round(average_score, 2))

# 查看数据类型
print()
print("数据类型：")
print("姓名类型：", type(student_name))
print("年龄类型：", type(student_age))
print("身高类型：", type(student_height))
print("平均分类型：", type(average_score))
```
