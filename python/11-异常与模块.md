## 一、了解异常

### 1.1 什么是异常

异常（Exception）是程序在运行过程中发生的错误或意外情况。当程序遇到错误时，如果没有处理，就会中断执行并显示错误信息。

```python
# 异常示例：除以零
print(10 / 0)  # 会抛出 ZeroDivisionError
```

运行上面的代码会看到类似输出：
```
ZeroDivisionError: division by zero
```

### 1.2 常见异常类型

| 异常类型 | 说明 | 触发示例 |
|---------|------|---------|
| `ZeroDivisionError` | 除以零错误 | `1 / 0` |
| `ValueError` | 值错误（类型正确但值不合法） | `int("abc")` |
| `TypeError` | 类型错误（类型不匹配） | `"a" + 1` |
| `FileNotFoundError` | 文件未找到错误 | `open("不存在.txt")` |
| `IndexError` | 索引越界错误 | `[1,2,3][10]` |
| `KeyError` | 字典键不存在错误 | `{"a": 1}["b"]` |
| `NameError` | 变量未定义错误 | 访问未定义的变量 |
| `AttributeError` | 属性错误 | 访问不存在的属性 |

```python
# 常见异常演示

# 1. ZeroDivisionError: 除以零
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"除零错误: {e}")

# 2. ValueError: 值错误
try:
    number = int("hello")
except ValueError as e:
    print(f"值错误: {e}")

# 3. TypeError: 类型错误
try:
    result = "age" + 18
except TypeError as e:
    print(f"类型错误: {e}")

# 4. FileNotFoundError: 文件未找到
try:
    with open("not_exist.txt", "r") as f:
        content = f.read()
except FileNotFoundError as e:
    print(f"文件未找到: {e}")

# 5. IndexError: 索引越界
try:
    my_list = [1, 2, 3]
    print(my_list[10])
except IndexError as e:
    print(f"索引越界: {e}")

# 6. KeyError: 字典键不存在
try:
    my_dict = {"name": "张三"}
    print(my_dict["age"])
except KeyError as e:
    print(f"键错误: {e}")
```

## 二、异常的捕获

### 2.1 基本语法

使用 `try...except` 语句捕获异常：

```python
# 基本异常捕获语法
try:
    # 可能出错的代码
    number = int(input("请输入一个数字: "))
    result = 100 / number
    print(f"100 除以 {number} = {result}")
except:
    # 出错后执行的代码
    print("输入有误，请输入一个非零数字")
```

> **注意**：不指定异常类型的 `except:` 会捕获所有异常，但不推荐这样使用，因为可能会隐藏真正的错误。

### 2.2 捕获指定异常类型

建议只捕获特定的异常类型，便于定位问题：

```python
# 捕获指定异常类型
try:
    number = int("abc")
except ValueError as e:
    # as e 将异常对象赋值给变量 e
    print(f"发生值错误: {e}")
```

输出：
```
发生值错误: invalid literal for int() with base 10: 'abc'
```

### 2.3 捕获多个异常

可以使用元组的形式同时捕获多种异常：

```python
# 捕获多个异常
try:
    # 可能产生多种异常的代码
    my_list = [1, 2, 3]
    index = int(input("请输入索引 (0-2): "))
    print(f"元素是: {my_list[index]}")
except (ValueError, IndexError) as e:
    # 无论是 ValueError 还是 IndexError 都会在这里处理
    print(f"发生错误: {e}")
```

也可以分别处理不同异常：

```python
# 分别捕获不同异常
try:
    my_list = [1, 2, 3]
    index = int(input("请输入索引 (0-2): "))
    print(f"元素是: {my_list[index]}")
except ValueError:
    print("输入的不是有效数字！")
except IndexError:
    print("索引超出范围！")
except Exception as e:
    # Exception 是所有异常的父类，作为兜底处理
    print(f"未知错误: {e}")
```

### 2.4 else 块

`else` 块在 `try` 中没有发生任何异常时执行：

```python
# else 块的使用
try:
    number = int(input("请输入一个数字: "))
    result = 10 / number
except ValueError:
    print("输入的不是有效数字！")
except ZeroDivisionError:
    print("不能除以零！")
else:
    # 只有 try 块没有异常时才会执行
    print(f"计算成功: 10 / {number} = {result}")
```

### 2.5 finally 块

`finally` 块**无论是否发生异常都会执行**，常用于资源释放（如关闭文件、数据库连接等）：

```python
# finally 块的使用
try:
    f = open("test.txt", "r", encoding="utf-8")
    content = f.read()
    print(content)
except FileNotFoundError:
    print("文件不存在！")
else:
    print("文件读取成功！")
finally:
    # 无论是否发生异常，都会执行
    print("执行 finally 块")
    # 确保 f 变量存在后再关闭
    if 'f' in dir():
        f.close()
```

### 2.6 完整的异常处理结构

```python
# 完整的 try-except-else-finally 结构
def safe_divide(a, b):
    """安全除法函数"""
    try:
        result = a / b
    except ZeroDivisionError as e:
        print(f"错误: {e}")
        return None
    except TypeError as e:
        print(f"类型错误: {e}")
        return None
    else:
        print("除法运算成功")
        return result
    finally:
        print("除法运算结束（无论如何都会执行）")


# 测试
print("--- 测试 1: 正常情况 ---")
print(safe_divide(10, 2))

print("\n--- 测试 2: 除以零 ---")
print(safe_divide(10, 0))

print("\n--- 测试 3: 类型错误 ---")
print(safe_divide(10, "a"))
```

## 三、异常的传递性

### 3.1 异常会从被调用函数传递到调用处

当函数内部发生异常且未被处理时，异常会向外层传递，直到被处理或导致程序终止：

```python
# 异常的传递性
def func1():
    print("func1 开始")
    # 这里会发生异常
    result = 10 / 0
    print("func1 结束")  # 这行不会执行


def func2():
    print("func2 开始")
    func1()  # 调用 func1，异常会传递到这里
    print("func2 结束")  # 这行不会执行


def func3():
    print("func3 开始")
    try:
        func2()  # 在这里捕获传递过来的异常
    except ZeroDivisionError as e:
        print(f"在 func3 中捕获到异常: {e}")
    print("func3 结束")


# 调用 func3
func3()
```

输出：
```
func3 开始
func2 开始
func1 开始
在 func3 中捕获到异常: division by zero
func3 结束
```

### 3.2 实际应用：在合适的位置处理异常

```python
# 在调用处统一处理异常
def read_config(file_path):
    """读取配置文件"""
    with open(file_path, "r", encoding="utf-8") as f:
        return f.read()


def get_database_url():
    """获取数据库连接地址"""
    try:
        config = read_config("config.txt")
        return config.strip()
    except FileNotFoundError:
        print("配置文件不存在，使用默认地址")
        return "localhost:3306"


# 调用
url = get_database_url()
print(f"数据库地址: {url}")
```

## 四、模块的概念和导入

### 4.1 什么是模块

模块（Module）就是一个 `.py` 文件，里面定义了函数、类、变量等，可以被其他程序导入使用。模块的主要作用：
- **代码复用**：避免重复造轮子
- **组织代码**：将相关功能组织在一起
- **命名空间隔离**：避免命名冲突

### 4.2 import 模块名

```python
# 方式一：import 模块名
import math

# 使用时需要加上模块名前缀
print(math.pi)          # 输出: 3.141592653589793
print(math.sqrt(16))    # 输出: 4.0
```

```python
# 导入多个模块
import os
import sys
import random

print(os.getcwd())          # 获取当前工作目录
print(sys.version)          # 获取 Python 版本
print(random.randint(1, 100))  # 生成 1-100 的随机整数
```

### 4.3 from 模块名 import 功能名

```python
# 方式二：from 模块名 import 功能名
from math import pi, sqrt

# 直接使用，不需要模块名前缀
print(pi)         # 输出: 3.141592653589793
print(sqrt(16))   # 输出: 4.0
```

### 4.4 from 模块名 import *（不推荐）

```python
# 方式三：from 模块名 import *（不推荐）
# 会导入模块中所有公共成员，容易造成命名冲突
from math import *

print(pi)
print(sqrt(25))
```

> **不推荐原因**：
> 1. 容易造成命名冲突（不同模块可能有同名函数）
> 2. 无法一眼看出某个函数来自哪个模块
> 3. 会导入不需要的内容，浪费资源

### 4.5 import 模块名 as 别名

```python
# 方式四：使用别名（模块名太长时很方便）
import numpy as np  # 常见用法

# 也可以给标准库起别名
import math as m

print(m.pi)         # 输出: 3.141592653589793
print(m.sqrt(16))   # 输出: 4.0
```

### 4.6 from 模块名 import 功能名 as 别名

```python
# 方式五：给导入的功能起别名
from math import sqrt as square_root

print(square_root(16))  # 输出: 4.0
```

### 4.7 导入方式对比

| 导入方式 | 使用方式 | 优点 | 缺点 |
|---------|---------|------|------|
| `import 模块名` | `模块名.函数()` | 清晰明确 | 每次都要写模块名 |
| `from 模块名 import 功能名` | `函数()` | 简洁 | 可能命名冲突 |
| `from 模块名 import *` | `函数()` | 最简洁 | **不推荐**，容易冲突 |
| `import 模块名 as 别名` | `别名.函数()` | 简短清晰 | - |

### 4.8 __all__ 变量控制导入范围

在模块中定义 `__all__` 列表，可以控制 `from 模块名 import *` 时导入哪些内容：

```python
# 假设有一个模块 my_module.py，内容如下：
# __all__ = ["func1", "func2"]  # 只允许导入 func1 和 func2
#
# def func1():
#     print("这是 func1")
#
# def func2():
#     print("这是 func2")
#
# def func3():
#     print("这是 func3")  # 不能被 import * 导入

# 使用时：
# from my_module import *
# func1()  # 可以调用
# func2()  # 可以调用
# func3()  # 报错！NameError
```

## 五、自定义模块并导入

### 5.1 创建自定义模块

任何 `.py` 文件都可以作为模块被导入。假设我们创建一个工具模块 `my_utils.py`：

```python
# 文件名: my_utils.py
# 这是一个自定义模块

def add(a, b):
    """加法"""
    return a + b


def subtract(a, b):
    """减法"""
    return a - b


def multiply(a, b):
    """乘法"""
    return a * b


def divide(a, b):
    """除法"""
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b


PI = 3.141592653589793
```

### 5.2 导入自定义模块

在同目录下创建另一个 `.py` 文件：

```python
# 文件名: main.py
# 导入同目录下的自定义模块

import my_utils

# 使用模块中的函数
result = my_utils.add(10, 5)
print(f"10 + 5 = {result}")

result = my_utils.subtract(10, 5)
print(f"10 - 5 = {result}")

result = my_utils.multiply(10, 5)
print(f"10 * 5 = {result}")

result = my_utils.divide(10, 5)
print(f"10 / 5 = {result}")

print(f"PI = {my_utils.PI}")
```

### 5.3 使用 from import 导入

```python
# 从自定义模块导入特定功能
from my_utils import add, subtract

print(add(3, 5))       # 输出: 8
print(subtract(10, 4)) # 输出: 6
```

### 5.4 模块的 __name__ 属性

每个模块都有 `__name__` 属性，直接运行时为 `"__main__"`，被导入时为模块名：

```python
# 文件名: my_module.py

def greet(name):
    """打招呼函数"""
    print(f"你好，{name}！")


# 这段代码只有在直接运行本文件时才会执行
# 被导入时不会执行
if __name__ == "__main__":
    greet("张三")
    print("这是直接运行时执行的代码")
```

> **作用**：`if __name__ == "__main__":` 用于区分模块是被直接运行还是被导入，常用于编写测试代码。

## 六、自定义 Python 包

### 6.1 什么是包

包（Package）是一种管理 Python 模块命名空间的方式，本质上是**包含 `__init__.py` 文件的文件夹**。

```
my_package/              # 包名（文件夹）
    __init__.py          # 包的初始化文件（可以为空，但必须存在）
    module1.py           # 模块1
    module2.py           # 模块2
    sub_package/         # 子包
        __init__.py
        module3.py
```

### 6.2 创建包结构

```python
# 1. 创建文件夹 my_package
# 2. 在文件夹内创建 __init__.py（内容可以为空，或写初始化代码）

# 文件: my_package/__init__.py
# 可以在这里定义 __all__ 控制包的导入范围
__all__ = ["math_tools", "string_tools"]
print("my_package 包已加载")
```

```python
# 文件: my_package/math_tools.py
def add(a, b):
    """加法"""
    return a + b


def multiply(a, b):
    """乘法"""
    return a * b
```

```python
# 文件: my_package/string_tools.py
def to_upper(s):
    """转大写"""
    return s.upper()


def to_lower(s):
    """转小写"""
    return s.lower()
```

### 6.3 导入包中的模块

```python
# 导入包中的模块
import my_package.math_tools

result = my_package.math_tools.add(3, 5)
print(result)  # 输出: 8
```

```python
# 从包中导入特定模块

```

```python

```


## 八、综合案例

### 8.1 案例：带异常处理的安全计算器

**需求**：实现一个安全的计算器，能处理各种异常情况。

```python
# 综合案例：安全计算器
class SafeCalculator:
    """带异常处理的安全计算器"""

    def add(self, a, b):
        """加法"""
        try:
            return float(a) + float(b)
        except (ValueError, TypeError) as e:
            print(f"输入错误: {e}")
            return None

    def subtract(self, a, b):
        """减法"""
        try:
            return float(a) - float(b)
        except (ValueError, TypeError) as e:
            print(f"输入错误: {e}")
            return None

    def multiply(self, a, b):
        """乘法"""
        try:
            return float(a) * float(b)
        except (ValueError, TypeError) as e:
            print(f"输入错误: {e}")
            return None

    def divide(self, a, b):
        """除法"""
        try:
            return float(a) / float(b)
        except ZeroDivisionError:
            print("错误: 除数不能为零！")
            return None
        except (ValueError, TypeError) as e:
            print(f"输入错误: {e}")
            return None
        finally:
            print("（计算完成）")


# 使用计算器
calc = SafeCalculator()

print("--- 加法测试 ---")
print(calc.add(10, 5))        # 输出: 15.0
print(calc.add("10", "5"))    # 输出: 15.0
print(calc.add("abc", 5))     # 输出错误信息

print("\n--- 除法测试 ---")
print(calc.divide(10, 2))     # 输出: 5.0
print(calc.divide(10, 0))     # 输出错误信息
print(calc.divide("abc", 2))  # 输出错误信息
```

### 8.2 案例：模块化的学生管理系统

**需求**：将学生管理系统拆分为多个模块，演示模块化编程。

```python
# 文件: student.py（学生模块）

class Student:
    """学生类"""

    def __init__(self, student_id, name, age):
        self.student_id = student_id
        self.name = name
        self.age = age

    def __str__(self):
        return f"学号: {self.student_id}, 姓名: {self.name}, 年龄: {self.age}"


def create_student(student_id, name, age):
    """创建学生（带异常处理）"""
    try:
        if not name:
            raise ValueError("姓名不能为空")
        if age < 0 or age > 150:
            raise ValueError("年龄不合法")
        return Student(student_id, name, age)
    except TypeError as e:
        print(f"类型错误: {e}")
        return None
```

```python
# 文件: student_manager.py（管理模块）
# from student import Student, create_student


class StudentManager:
    """学生管理类"""

    def __init__(self):
        self.students = []

    def add_student(self, student_id, name, age):
        """添加学生"""
        # 检查学号是否已存在
        for s in self.students:
            if s.student_id == student_id:
                print(f"学号 {student_id} 已存在！")
                return False

        student = create_student(student_id, name, age)
        if student:
            self.students.append(student)
            print(f"添加成功: {student}")
            return True
        return False

    def find_student(self, student_id):
        """查找学生"""
        for s in self.students:
            if s.student_id == student_id:
                return s
        print(f"未找到学号为 {student_id} 的学生")
        return None

    def show_all(self):
        """显示所有学生"""
        if not self.students:
            print("暂无学生信息")
            return
        print("=== 学生列表 ===")
        for s in self.students:
            print(s)

    def save_to_file(self, file_path):
        """保存到文件"""
        try:
            with open(file_path, "w", encoding="utf-8") as f:
                for s in self.students:
                    f.write(f"{s.student_id},{s.name},{s.age}\n")
            print(f"保存成功，共 {len(self.students)} 条记录")
        except IOError as e:
            print(f"保存失败: {e}")

    def load_from_file(self, file_path):
        """从文件加载"""
        try:
            with open(file_path, "r", encoding="utf-8") as f:
                for line in f:
                    parts = line.strip().split(",")
                    if len(parts) == 3:
                        student_id, name, age = parts[0], parts[1], int(parts[2])
                        self.add_student(student_id, name, age)
            print("加载完成")
        except FileNotFoundError:
            print("文件不存在，将创建新数据")
        except ValueError as e:
            print(f"数据格式错误: {e}")
```

## 九、本章小结

### 9.1 异常处理要点

| 语法 | 说明 |
|------|------|
| `try...except` | 捕获异常 |
| `try...except Exception as e` | 捕获并获取异常信息 |
| `try...except (A, B) as e` | 捕获多种异常 |
| `else` | 无异常时执行 |
| `finally` | 无论是否异常都执行 |

### 9.2 模块导入方式对比

```python
import math                    # 推荐：清晰
from math import sqrt          # 推荐：简洁
from math import sqrt as sq    # 别名：灵活
from math import *             # 不推荐：易冲突
```

### 9.3 最佳实践

1. **捕获具体异常**：不要用 `except:` 捕获所有异常
2. **合理使用 finally**：用于资源释放
3. **模块化编程**：将功能拆分到不同模块
4. **使用 `if __name__ == "__main__":`**：区分模块运行和导入
5. **优先使用标准库**：避免重复造轮子
