# 判断语句

判断语句是程序进行逻辑判断、控制执行流程的核心机制。本教程将系统介绍 Python 中 `if` 语句的各种用法,从基础到进阶,配合完整案例讲解。

---

## 一、`if` 语句基本格式

### 1.1 语法格式

`if` 语句用于在满足条件时执行特定代码块。

```python
if 条件:
    条件成立时执行的代码
```

**注意事项:**
- `if` 后跟一个条件表达式,条件后必须有**冒号 `:`**
- 代码块必须**缩进**(推荐 4 个空格,PEP 8 规范)
- 条件为 `True` 时执行缩进代码块,为 `False` 时跳过

```python
# 基础示例
age = 20

if age >= 18:
    print("你已经成年了")
    print("可以享受成年人的权利")

print("程序结束")  # 这行不属于 if 语句
```

运行结果:

```
你已经成年了
可以享受成年人的权利
程序结束
```

当条件不满足时:

```python
age = 15

if age >= 18:
    print("你已经成年了")  # 这行不会执行

print("程序结束")  # 这行总是会执行
```

运行结果:

```
程序结束
```

### 1.2 案例:成年人判断

## 二、`if-else` 组合判断

### 2.1 语法格式

`if-else` 语句用于在两种互斥情况下做出选择:条件成立执行一块代码,不成立执行另一块代码。

```python
if 条件:
    条件成立时执行的代码
else:
    条件不成立时执行的代码
```

```python
# 基础示例
age = 20

if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

运行结果:

```
成年人
```

### 2.2 案例:买票判断

根据身高判断是否需要购买车票:
- 身高超过 120 厘米需要买票
- 身高不超过 120 厘米免票

```python
    print(f"你的身高是 {height} 厘米,可以免票乘车。")

```

## 三、`if-elif-else` 多条件判断

### 3.1 语法格式

当需要判断多种情况时,可以使用 `if-elif-else` 结构。程序会从上到下依次判断条件,只要有一个条件成立,执行对应代码块后**就不再判断后面的条件**。

```python
if 条件1:
    条件1成立时执行的代码
elif 条件2:
    条件2成立时执行的代码
elif 条件3:
    条件3成立时执行的代码
else:
    以上条件都不成立时执行的代码
```

**说明:**
- `elif` 是 `else if` 的缩写
- 可以有任意多个 `elif`
- `else` 可以省略
- 一旦某个条件成立,后续条件不再判断

```python
# 基础示例:成绩等级判断
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

运行结果:

```
良好
```

## 四、判断语句的嵌套使用

### 4.1 嵌套 `if` 语法

`if` 语句内部还可以再包含 `if` 语句,这就是嵌套判断。**注意缩进层次,每一层嵌套都要增加一级缩进。**

```python
if 条件1:
    if 条件2:
        条件1和条件2都成立时执行的代码
    else:
        条件1成立但条件2不成立时执行的代码
else:
    条件1不成立时执行的代码
```

### 4.2 嵌套判断示例

```python
# 嵌套判断示例:判断是否是成年男性
age = 20
gender = "男"

if age >= 18:
    print("你已成年")
    if gender == "男":
        print("你是成年男性")
    elif gender == "女":
        print("你是成年女性")
else:
    print("你未成年")
```

运行结果:

```
你已成年
你是成年男性
```

### 4.3 案例:乘车综合判断

结合身高和是否携带行李判断乘车费用:

```python
# 案例:乘车综合判断
print("=== 乘车费用计算系统 ===")

height = int(input("请输入你的身高(厘米): "))
has_luggage = input("是否携带大件行李?(是/否): ")

# 第一层判断:是否需要买票
if height > 120:
    print("你需要购买成人票。")
    # 第二层判断:是否需要加收行李费
    if has_luggage == "是":
        print("携带大件行李需加收 2 元行李费。")
        print("总费用:成人票 5 元 + 行李费 2 元 = 7 元")
    else:
        print("总费用:成人票 5 元")
else:
    print("你可以免票乘车。")
    # 第二层判断:即使免票也可能需要行李费
    if has_luggage == "是":
        print("但携带大件行李需支付 2 元行李费。")
        print("总费用:行李费 2 元")
    else:
        print("总费用:免费")

print("祝旅途愉快!")
```

## 五、综合案例

### 5.1 案例:简易计算器

```python
# 综合案例:简易计算器
print("=== 简易计算器 ===")

# 读取两个数字
num1 = float(input("请输入第一个数字: "))
operator = input("请输入运算符(+、-、*、/): ")
num2 = float(input("请输入第二个数字: "))

# 根据运算符进行不同运算
if operator == "+":
    result = num1 + num2
    print(f"{num1} + {num2} = {result}")
elif operator == "-":
    result = num1 - num2
    print(f"{num1} - {num2} = {result}")
elif operator == "*":
    result = num1 * num2
    print(f"{num1} * {num2} = {result}")
elif operator == "/":
    # 嵌套判断:除数不能为 0
    if num2 == 0:
        print("错误:除数不能为 0!")
    else:
        result = num1 / num2
        print(f"{num1} / {num2} = {result}")
else:
    print(f"不支持的运算符: {operator}")

print("计算完成。")
```

运行示例一(加法):

```
=== 简易计算器 ===
请输入第一个数字: 12
请输入运算符(+、-、*、/): +
请输入第二个数字: 30
12.0 + 30.0 = 42.0
计算完成。
```

运行示例二(除数为 0):

```
=== 简易计算器 ===
请输入第一个数字: 10
请输入运算符(+、-、*、/): /
请输入第二个数字: 0
```

## 六、小结

| 语句类型 | 适用场景 | 语法要点 |
| :--- | :--- | :--- |
| `if` | 单一条件判断 | 条件后加冒号,代码块缩进 |
| `if-else` | 二选一判断 | `else` 后加冒号,处理另一情况 |
| `if-elif-else` | 多条件互斥判断 | `elif` 可多次,匹配一个后跳过后面的 |
| 嵌套 `if` | 多层条件判断 | 注意缩进层次,逻辑要清晰 |

> **常见错误提醒:**
> 1. 忘记在 `if`、`elif`、`else` 后加冒号 `:`
> 2. 缩进不一致(混用空格和 Tab)
> 3. 把 `==` 写成 `=`(`=` 是赋值,`==` 是比较)
> 4. 嵌套层次混乱,导致逻辑错误
