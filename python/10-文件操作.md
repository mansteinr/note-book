## 一、文件编码概念

计算机存储的任何数据，本质上都是二进制（0 和 1）。为了让计算机能够表示人类可读的文字，就需要一种"翻译规则"——**编码**。编码就是把字符与二进制数字对应起来的规则。

### 1.1 常见编码介绍

| 编码方式 | 说明 | 适用场景 |
|---------|------|---------|
| ASCII | 美国信息交换标准代码，仅支持 128 个字符（英文、数字、符号） | 早期英文系统 |
| GBK / GB2312 | 中国国家标准编码，支持简体中文 | 中文 Windows 系统 |
| Big5 | 繁体中文编码 | 港台地区 |
| UTF-8 | 万国码，支持全球几乎所有文字，可变长度编码 | **推荐使用** |

### 1.2 Python 默认使用 UTF-8

Python 3 默认使用 UTF-8 编码读写文件，可以直接处理中文字符：

```python
# Python 默认使用 UTF-8 编码
# 可以直接输出中文字符串
print("你好，世界！")  # 输出: 你好，世界！
```

> **注意**：在 Windows 系统下，记事本默认编码可能是 GBK，而 Python 默认使用 UTF-8。如果打开文件时出现乱码或报错，通常就是编码不一致导致的。建议统一使用 UTF-8 编码。

### 1.3 查看与指定编码

```python
import sys

# 查看 Python 默认编码
print(sys.getdefaultencoding())  # 输出: utf-8

# 打开文件时可以指定编码
# f = open("test.txt", "r", encoding="utf-8")
```

## 二、文件的打开与关闭

### 2.1 open() 函数基本用法

`open()` 函数用于打开文件，语法格式如下：

```python
open(file, mode, encoding)
```

- `file`：文件路径（字符串）
- `mode`：访问模式（可选，默认为 `r`）
- `encoding`：编码方式（推荐显式指定为 `"utf-8"`）

### 2.2 访问模式

| 模式 | 说明 | 文件不存在时 |
|------|------|-------------|
| `r` | 只读（默认） | 报错 |
| `w` | 写入（覆盖原有内容） | 创建新文件 |
| `a` | 追加（在文件末尾添加） | 创建新文件 |
| `rb` / `wb` / `ab` | 以二进制方式读写 | - |

```python
# 打开文件的基本示例
f = open("test.txt", "r", encoding="utf-8")
# 使用文件...
f.close()  # 使用完毕后必须关闭文件
```

> **重要提示**：使用 `open()` 打开文件后，必须调用 `close()` 关闭文件，否则会导致资源泄漏。

## 三、文件的读取操作

### 3.1 read() —— 读取全部内容

`read()` 方法一次性读取文件全部内容，返回字符串。

```python
# 假设 test.txt 内容为：
# 你好，Python！
# 这是第二行。

# 使用 read() 读取全部内容
f = open("test.txt", "r", encoding="utf-8")
content = f.read()
print(content)
f.close()
```

输出：
```
你好，Python！
这是第二行。
```

可以传入参数指定读取的字符数：

```python
f = open("test.txt", "r", encoding="utf-8")
content = f.read(5)  # 只读取前 5 个字符
print(content)  # 输出: 你好，Py
f.close()
```

### 3.2 readlines() —— 读取所有行返回列表

`readlines()` 一次性读取文件全部内容，按行分割，返回列表。

```python
# readlines() 示例
f = open("test.txt", "r", encoding="utf-8")
lines = f.readlines()
print(type(lines))  # 输出: <class 'list'>
print(lines)        # 输出: ['你好，Python！\n', '这是第二行。\n']
f.close()

# 遍历每一行
for line in lines:
    print(line.strip())  # strip() 用于去除每行末尾的换行符
```

### 3.3 readline() —— 读取一行

`readline()` 每次只读取一行内容。

```python
# readline() 示例
f = open("test.txt", "r", encoding="utf-8")

line1 = f.readline()  # 读取第一行
print(line1, end="")  # 输出: 你好，Python！

line2 = f.readline()  # 读取第二行
print(line2, end="")  # 输出: 这是第二行。

f.close()
```

### 3.4 for line in file —— 循环读取每一行（推荐）

这是最简洁、最高效的逐行读取方式，适合处理大文件。

```python
# for 循环读取每一行（推荐方式）
f = open("test.txt", "r", encoding="utf-8")
for line in f:
    print(line.strip())  # 去除换行符后输出
f.close()
```

输出：
```
你好，Python！
这是第二行。
```

### 3.5 with open() as f —— 上下文管理器（强烈推荐）

使用 `with` 语句可以自动管理文件的关闭，即使在读写过程中发生异常，文件也会被正确关闭。

```python
# 使用 with 语句（推荐方式）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 离开 with 块后，文件会自动关闭，无需调用 f.close()
```

```python
# with 语句结合 for 循环读取大文件
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

> **强烈推荐**：所有文件操作都使用 `with` 语句，避免忘记关闭文件导致资源泄漏。

### 3.6 课后练习：文件读取

**练习题目**：假设有一个 `score.txt` 文件，每行记录一个学生的姓名和分数（用空格分隔），格式如下：

```
张三 85
李四 92
王五 78
```

请读取文件，计算所有学生的平均分数。

```python
# 练习：计算学生平均分数
total_score = 0
count = 0

with open("score.txt", "r", encoding="utf-8") as f:
    for line in f:
        # 去除空白字符并按空格分割
        parts = line.strip().split()
        if len(parts) == 2:
            name = parts[0]
            score = int(parts[1])
            total_score += score
            count += 1
            print(f"姓名: {name}, 分数: {score}")

if count > 0:
    average = total_score / count
    print(f"总人数: {count}, 平均分: {average:.2f}")
else:
    print("文件中没有有效数据")
```

## 四、文件的写出操作

### 4.1 w 模式：覆盖写入

使用 `w` 模式打开文件时：
- 如果文件存在，**会清空原有内容**后写入新内容
- 如果文件不存在，**会自动创建新文件**

```python
# w 模式：覆盖写入
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("这是第一行内容。\n")  # \n 表示换行
    f.write("这是第二行内容。\n")
    f.write("这是第三行内容。")

print("写入完成！")
```

运行后 `output.txt` 内容：
```
这是第一行内容。
这是第二行内容。
这是第三行内容。
```

### 4.2 writelines() 写入多行

`writelines()` 接收一个列表，将列表中每个字符串写入文件（不会自动添加换行符）。

```python
# writelines() 示例
lines = [
    "第一行\n",
    "第二行\n",
    "第三行\n"
]

with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)

print("多行写入完成！")
```

### 4.3 注意事项

```python
# 注意：w 模式会覆盖原有内容！
# 第一次写入
with open("test_write.txt", "w", encoding="utf-8") as f:
    f.write("第一次写入的内容")

# 第二次写入（会覆盖第一次的内容）
with open("test_write.txt", "w", encoding="utf-8") as f:
    f.write("第二次写入的内容")

# 读取查看
with open("test_write.txt", "r", encoding="utf-8") as f:
    print(f.read())  # 输出: 第二次写入的内容
```

## 五、文件的追加写入操作

### 5.1 a 模式：追加到文件末尾

使用 `a` 模式打开文件时：
- 如果文件存在，在文件**末尾追加**新内容，不会清空原有内容
- 如果文件不存在，**会自动创建新文件**

```python
# a 模式：追加写入
# 先创建文件并写入一行
with open("log.txt", "w", encoding="utf-8") as f:
    f.write("这是初始内容。\n")

# 使用 a 模式追加内容
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("这是追加的第一行。\n")
    f.write("这是追加的第二行。\n")

# 读取查看
with open("log.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

输出：
```
这是初始内容。
这是追加的第一行。
这是追加的第二行。
```

### 5.2 实际应用：日志记录

```python
# 模拟日志记录功能
import datetime


def write_log(message):
    """记录日志到文件"""
    now = datetime.datetime.now()
    time_str = now.strftime("%Y-%m-%d %H:%M:%S")
    with open("app.log", "a", encoding="utf-8") as f:
        f.write(f"[{time_str}] {message}\n")


# 记录多条日志
write_log("程序启动")
write_log("用户登录成功")
write_log("执行操作: 数据保存")
write_log("程序正常退出")

# 查看日志
with open("app.log", "r", encoding="utf-8") as f:
    print(f.read())
```

## 六、文件操作综合案例

### 6.1 案例：文件内容处理

**需求**：读取一个文件，将文件中的所有英文小写字母转换为大写字母，然后写入到另一个文件中。

```python
# 综合案例：文件内容转换
# 1. 先创建一个测试用的输入文件
with open("input.txt", "w", encoding="utf-8") as f:
    f.write("hello world\n")
    f.write("python programming\n")
    f.write("file operation example\n")

# 2. 读取 input.txt，处理后写入 output.txt
with open("input.txt", "r", encoding="utf-8") as src_file:
    with open("output.txt", "w", encoding="utf-8") as dst_file:
        for line in src_file:
            # 将小写字母转换为大写
            upper_line = line.upper()
            dst_file.write(upper_line)

# 3. 验证结果
with open("output.txt", "r", encoding="utf-8") as f:
    print("转换后的内容：")
    print(f.read())
```

输出：
```
转换后的内容：
HELLO WORLD
PYTHON PROGRAMMING
FILE OPERATION EXAMPLE
```

### 6.2 案例：统计文件信息

**需求**：统计文件中的行数、单词数、字符数。

```python
# 综合案例：统计文件信息
def count_file_info(file_path):
    """统计文件的行数、单词数、字符数"""
    line_count = 0
    word_count = 0
    char_count = 0

    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            line_count += 1
            # 去除换行符后统计字符
            char_count += len(line.strip())
            # 按空格分割统计单词
            words = line.strip().split()
            word_count += len(words)

    return line_count, word_count, char_count


# 创建测试文件
with open("sample.txt", "w", encoding="utf-8") as f:
    f.write("Python is a great programming language\n")
    f.write("It is easy to learn\n")
    f.write("File operations are very useful\n")

# 调用统计函数
lines, words, chars = count_file_info("sample.txt")
print(f"行数: {lines}")
print(f"单词数: {words}")
print(f"字符数: {chars}")
```

输出：
```
行数: 3
单词数: 16
字符数: 89
```

### 6.3 案例：简易通讯录

**需求**：实现一个简易通讯录，将联系人信息保存到文件，支持查看所有联系人。

```python
# 综合案例：简易通讯录
class ContactBook:
    """简易通讯录类"""

    def __init__(self, file_path="contacts.txt"):
        self.file_path = file_path

    def add_contact(self, name, phone):
        """添加联系人"""
        with open(self.file_path, "a", encoding="utf-8") as f:
            f.write(f"{name},{phone}\n")
        print(f"已添加联系人: {name} - {phone}")

    def show_all(self):
        """显示所有联系人"""
        try:
            with open(self.file_path, "r", encoding="utf-8") as f:
                print("=== 通讯录列表 ===")
                for line in f:
                    parts = line.strip().split(",")
                    if len(parts) == 2:
                        name, phone = parts
                        print(f"姓名: {name}, 电话: {phone}")
        except FileNotFoundError:
            print("通讯录为空，请先添加联系人")


# 使用通讯录
book = ContactBook()
book.add_contact("张三", "13800138000")
book.add_contact("李四", "13900139000")
book.add_contact("王五", "13700137000")
print()
book.show_all()
```

## 七、本章小结

### 7.1 知识要点回顾

| 知识点 | 说明 |
|-------|------|
| `open()` | 打开文件，需指定路径、模式、编码 |
| `read()` | 读取全部内容 |
| `readline()` | 读取一行 |
| `readlines()` | 读取所有行返回列表 |
| `for line in f` | 循环读取每一行（推荐） |
| `write()` | 写入字符串 |
| `writelines()` | 写入字符串列表 |
| `with` 语句 | 自动关闭文件（强烈推荐） |

### 7.2 最佳实践

1. **始终使用 `with` 语句**：自动管理文件资源，避免资源泄漏
2. **显式指定 `encoding="utf-8"`**：避免编码问题
3. **大文件使用 `for line in f`**：逐行读取，节省内存
4. **写入时注意 `\n` 换行符**：手动控制换行
5. **注意 `w` 和 `a` 模式的区别**：`w` 覆盖，`a` 追加

### 7.3 常见错误

```python
# 错误示例 1：忘记关闭文件
f = open("test.txt", "r", encoding="utf-8")
print(f.read())
# 忘记 f.close() —— 不推荐！

# 正确写法：使用 with 语句
with open("test.txt", "r", encoding="utf-8") as f:
    print(f.read())

# 错误示例 2：以 r 模式打开不存在的文件
# f = open("not_exist.txt", "r")  # 会抛出 FileNotFoundError

# 正确做法：先用 w 模式创建文件，再读取
```
