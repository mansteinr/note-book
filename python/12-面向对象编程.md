## 一、初识对象

### 1.1 面向对象编程思想

面向对象编程（Object-Oriented Programming，简称 OOP）是一种程序设计思想，它将程序中的数据和操作数据的方法封装到"对象"中。

**面向过程 vs 面向对象**：

- **面向过程**：关注"怎么做"，按步骤实现功能
- **面向对象**：关注"谁来做"，将功能封装到对象中

```python
# 面向过程：把大象装进冰箱
print("打开冰箱门")
print("把大象放进去")
print("关上冰箱门")

# 面向对象：谁负责做什么
# 冰箱对象: 开门、关门
# 大象对象: 走进去
```

### 1.2 类与对象的概念

- **类（Class）**：是对一类事物的抽象描述，是"模板"或"蓝图"
- **对象（Object）**：是类的具体实例，是"产品"

生活中的例子：
- 类：汽车设计图纸
- 对象：根据图纸制造出的一辆辆汽车

```
类: Student（学生）
   ├── 属性（特征）: 姓名、年龄、学号
   └── 方法（行为）: 学习、吃饭、睡觉

对象: 具体的某个学生（张三、李四）
```

## 二、类的成员方法

### 2.1 class 关键字定义类

使用 `class` 关键字定义类：

```python
# 定义一个简单的类
class Student:
    # 类的成员变量（类属性）
    school = "第一中学"

    # 类的成员方法
    def study(self):
        print("学生正在学习")

    def eat(self):
        print("学生正在吃饭")


# 创建对象（实例化）
s1 = Student()
s2 = Student()

# 调用方法
s1.study()  # 输出: 学生正在学习
s2.eat()    # 输出: 学生正在吃饭
```

### 2.2 类名的命名规范

类名使用**大驼峰命名法（CamelCase / PascalCase）**：每个单词首字母大写，不使用下划线。

```python
# 正确：大驼峰命名法
class StudentInfo:        # ✓
    pass

class UserProfile:        # ✓
    pass

class HTTPServer:        # ✓ 缩写也大写
    pass

# 错误：不符合规范
class student_info:      # ✗ 这是小写下划线
    pass

class userinfo:          # ✗ 没有大写
    pass
```

> **对比**：方法名和变量名使用**小写下划线命名法（snake_case）**，如 `student_name`、`get_user_info`。

### 2.3 定义成员方法

方法的第一个参数必须是 `self`，代表当前对象本身。调用方法时不需要手动传 `self`。

```python
class Calculator:
    """计算器类"""

    def add(self, a, b):
        """加法方法"""
        # self 不需要手动传入
        return a + b

    def subtract(self, a, b):
        """减法方法"""
        return a - b


# 创建对象
calc = Calculator()

# 调用方法时不需要传 self
result = calc.add(10, 5)
print(result)  # 输出: 15

result = calc.subtract(10, 5)
print(result)  # 输出: 5
```

### 2.4 self 关键字的作用

`self` 指向**当前对象本身**，通过 `self` 可以访问对象的属性和方法：

```python
class Person:
    """人类"""

    def set_info(self, name, age):
        """设置个人信息"""
        # 通过 self 将数据绑定到当前对象
        self.name = name
        self.age = age

    def show_info(self):
        """显示个人信息"""
        # 通过 self 访问当前对象的属性
        print(f"姓名: {self.name}, 年龄: {self.age}")

    def greet(self):
        """打招呼"""
        # 通过 self 调用当前对象的其他方法
        print(f"大家好！我是 {self.name}")
        self.show_info()


# 创建两个不同的对象
p1 = Person()
p1.set_info("张三", 20)
p1.greet()

print("---")

p2 = Person()
p2.set_info("李四", 25)
p2.greet()
```

输出：
```
大家好！我是 张三
姓名: 张三, 年龄: 20
---
大家好！我是 李四
姓名: 李四, 年龄: 25
```

> **理解 self**：`self` 类似于 Java 中的 `this`。当 `p1.greet()` 被调用时，`self` 就指向 `p1`；当 `p2.greet()` 被调用时，`self` 就指向 `p2`。

## 三、类和对象

### 3.1 类是模板，对象是实例

```python
class Dog:
    """狗类（模板）"""

    # 类属性：所有对象共享
    species = "犬科动物"

    def __init__(self, name, age):
        """构造方法"""
        # 实例属性：每个对象独有
        self.name = name
        self.age = age

    def bark(self):
        """狗叫"""
        print(f"{self.name} 汪汪叫！")

    def show_info(self):
        """显示信息"""
        print(f"名字: {self.name}, 年龄: {self.age}岁, 物种: {Dog.species}")


# 创建对象（实例化）
dog1 = Dog("旺财", 3)
dog2 = Dog("小黑", 5)

# 每个对象的实例属性独立
dog1.show_info()  # 输出: 名字: 旺财, 年龄: 3岁, 物种: 犬科动物
dog2.show_info()  # 输出: 名字: 小黑, 年龄: 5岁, 物种: 犬科动物

# 类属性是共享的
print(Dog.species)  # 输出: 犬科动物

# 调用方法
dog1.bark()  # 输出: 旺财 汪汪叫！
dog2.bark()  # 输出: 小黑 汪汪叫！
```

### 3.2 类属性 vs 实例属性

```python
class Counter:
    """计数器类"""

    # 类属性：属于类，所有实例共享
    count = 0

    def __init__(self, name):
        self.name = name  # 实例属性：属于对象
        Counter.count += 1  # 访问类属性需要用类名

    @classmethod
    def show_count(cls):
        """类方法：访问类属性"""
        print(f"已创建 {cls.count} 个计数器")


# 创建多个对象
c1 = Counter("计数器1")
c2 = Counter("计数器2")
c3 = Counter("计数器3")

# 类属性被所有对象共享
Counter.show_count()  # 输出: 已创建 3 个计数器
print(Counter.count)  # 输出: 3
```

## 四、构造方法 __init__

### 4.1 构造方法的作用

`__init__` 是一个特殊方法（魔术方法），在**创建对象时自动调用**，用于初始化对象属性。

```python
class Student:
    """学生类"""

    def __init__(self, name, age, student_id):
        """构造方法：创建对象时自动调用"""
        print(f"正在创建学生对象: {name}")
        self.name = name          # 初始化姓名
        self.age = age            # 初始化年龄
        self.student_id = student_id  # 初始化学号

    def show_info(self):
        """显示学生信息"""
        print(f"学号: {self.student_id}, 姓名: {self.name}, 年龄: {self.age}")


# 创建对象时，参数会传给 __init__
s = Student("张三", 20, "2024001")
# 输出: 正在创建学生对象: 张三

s.show_info()
# 输出: 学号: 2024001, 姓名: 张三, 年龄: 20
```

### 4.2 带默认参数的构造方法

```python
class Phone:
    """手机类"""

    def __init__(self, brand="华为", price=2999):
        """构造方法带默认参数"""
        self.brand = brand
        self.price = price

    def show_info(self):
        print(f"品牌: {self.brand}, 价格: {self.price}元")


# 使用默认参数
p1 = Phone()
p1.show_info()  # 输出: 品牌: 华为, 价格: 2999元

# 传入参数
p2 = Phone("苹果", 9999)
p2.show_info()  # 输出: 品牌: 苹果, 价格: 9999元
```

## 五、魔术方法

魔术方法（Magic Methods）是以双下划线开头和结尾的特殊方法，也称为"dunder methods"。

### 5.1 __init__ —— 构造方法

```python
class Book:
    """图书类"""

    def __init__(self, title, author, price):
        """构造方法：创建对象时自动调用"""
        self.title = title
        self.author = author
        self.price = price
```

### 5.2 __str__ —— 字符串描述

`__str__` 方法在 `print(对象)` 或 `str(对象)` 时自动调用，返回对象的字符串描述。

```python
class Book:
    """图书类"""

    def __init__(self, title, author, price):
        self.title = title
        self.author = author
        self.price = price

    def __str__(self):
        """返回对象的可读字符串描述"""
        return f"《{self.title}》- 作者: {self.author}, 价格: {self.price}元"


book = Book("Python编程", "Guido", 99)

# print 对象时自动调用 __str__
print(book)  # 输出: 《Python编程》- 作者: Guido, 价格: 99元

# str() 转换时也调用 __str__
info = str(book)
print(info)  # 输出: 《Python编程》- 作者: Guido, 价格: 99元
```

### 5.3 __lt__ —— 小于比较

`__lt__` 在使用 `<` 运算符时触发。

```python
class Book:
    """图书类"""

    def __init__(self, title, author, price):
        self.title = title
        self.author = author
        self.price = price

    def __str__(self):
        return f"《{self.title}》价格: {self.price}元"

    def __lt__(self, other):
        """小于比较：< 运算符重载"""
        return self.price < other.price


book1 = Book("Python编程", "Author A", 99)
book2 = Book("Java编程", "Author B", 89)

# 使用 < 比较两个对象
print(book1 < book2)   # 输出: False (99 < 89 为假)
print(book2 < book1)   # 输出: True (89 < 99 为真)
```

### 5.4 __le__ —— 小于等于比较

`__le__` 在使用 `<=` 运算符时触发。

```python
class Student:
    """学生类"""

    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __str__(self):
        return f"{self.name}: {self.score}分"

    def __lt__(self, other):
        """< 小于"""
        return self.score < other.score

    def __le__(self, other):
        """<= 小于等于"""
        return self.score <= other.score


s1 = Student("张三", 85)
s2 = Student("李四", 90)
s3 = Student("王五", 85)

print(s1 < s2)    # 输出: True (85 < 90)
print(s1 <= s3)   # 输出: True (85 <= 85)
print(s2 <= s1)   # 输出: False (90 <= 85 为假)
```

### 5.5 __eq__ —— 等于比较

`__eq__` 在使用 `==` 运算符时触发。

```python
class Student:
    """学生类"""

    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __str__(self):
        return f"{self.name}: {self.score}分"

    def __eq__(self, other):
        """== 等于比较"""
        return self.score == other.score


s1 = Student("张三", 85)
s2 = Student("李四", 85)
s3 = Student("王五", 90)

print(s1 == s2)   # 输出: True (85 == 85)
print(s1 == s3)   # 输出: False (85 == 90 为假)
```

### 5.6 __repr__ —— 开发者友好的字符串表示

`__repr__` 返回一个"官方"字符串表示，主要用于调试和开发。理想情况下，`__repr__` 返回的字符串应该能用来重建对象。

```python
class Point:
    """点类"""

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """用户友好的字符串（print 时调用）"""
        return f"点({self.x}, {self.y})"

    def __repr__(self):
        """开发者友好的字符串（直接显示对象时调用）"""
        return f"Point({self.x}, {self.y})"


p = Point(3, 4)

# print() 调用 __str__
print(p)        # 输出: 点(3, 4)

# 在交互式环境或列表中显示时调用 __repr__
print(repr(p))  # 输出: Point(3, 4)

# 列表中显示对象时使用 __repr__
points = [Point(1, 2), Point(3, 4)]
print(points)   # 输出: [Point(1, 2), Point(3, 4)]
```

### 5.7 魔术方法总结表

| 魔术方法 | 触发时机 | 用途 |
|---------|---------|------|
| `__init__` | 创建对象时 | 初始化属性 |
| `__str__` | `print(obj)` / `str(obj)` | 用户友好的字符串 |
| `__repr__` | `repr(obj)` / 直接显示 | 开发者友好的字符串 |
| `__lt__` | `obj1 < obj2` | 小于比较 |
| `__le__` | `obj1 <= obj2` | 小于等于比较 |
| `__eq__` | `obj1 == obj2` | 等于比较 |
| `__gt__` | `obj1 > obj2` | 大于比较 |
| `__ge__` | `obj1 >= obj2` | 大于等于比较 |
| `__ne__` | `obj1 != obj2` | 不等于比较 |
| `__len__` | `len(obj)` | 获取长度 |
| `__del__` | 对象被销毁时 | 释放资源 |

## 六、封装

### 6.1 封装的概念

封装（Encapsulation）是将对象的数据（属性）和操作数据的方法（行为）捆绑在一起，并隐藏内部实现细节，对外提供公共的访问接口。

**封装的好处**：
1. 隐藏实现细节，简化使用
2. 保护数据安全，防止外部非法修改
3. 提高代码可维护性

### 6.2 私有属性和方法

在 Python 中，以**双下划线 `__`** 开头的属性和方法是私有的，不能在类外部直接访问。

```python
class BankAccount:
    """银行账户类"""

    def __init__(self, owner, balance):
        self.owner = owner          # 公有属性
        self.__balance = balance    # 私有属性（双下划线开头）

    def deposit(self, amount):
        """存款"""
        if amount > 0:
            self.__balance += amount
            print(f"存款 {amount} 元，余额: {self.__balance} 元")
        else:
            print("存款金额必须大于 0")

    def withdraw(self, amount):
        """取款"""
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"取款 {amount} 元，余额: {self.__balance} 元")
        else:
            print("取款金额无效或余额不足")

    def get_balance(self):
        """获取余额"""
        return self.__balance


# 创建账户
account = BankAccount("张三", 1000)

# 访问公有属性
print(account.owner)  # 输出: 张三

# 通过方法操作私有属性
account.deposit(500)    # 存款 500 元
account.withdraw(200)   # 取款 200 元
print(f"当前余额: {account.get_balance()} 元")

# 直接访问私有属性会报错
# print(account.__balance)  # AttributeError!
```

### 6.3 提供 getter 和 setter 方法

通过公有方法提供对私有属性的受控访问：

```python
class Student:
    """学生类"""

    def __init__(self, name, age):
        self.__name = name   # 私有属性
        self.__age = age     # 私有属性

    # getter 方法：获取私有属性
    def get_name(self):
        return self.__name

    def get_age(self):
        return self.__age

    # setter 方法：设置私有属性（可加入数据校验）
    def set_name(self, name):
        if not name:
            print("姓名不能为空！")
            return
        self.__name = name

    def set_age(self, age):
        if age < 0 or age > 150:
            print("年龄不合法！")
            return
        self.__age = age

    def show_info(self):
        print(f"姓名: {self.__name}, 年龄: {self.__age}")


# 使用
s = Student("张三", 20)
s.show_info()  # 输出: 姓名: 张三, 年龄: 20

# 通过 getter 获取
print(s.get_name())  # 输出: 张三
print(s.get_age())   # 输出: 20

# 通过 setter 修改（带校验）
s.set_age(25)
s.show_info()  # 输出: 姓名: 张三, 年龄: 25

s.set_age(-5)  # 输出: 年龄不合法！
s.show_info()  # 年龄没有改变
```

### 6.4 使用 property 装饰器（补充）

Python 推荐使用 `@property` 装饰器实现 getter/setter，使用更优雅：

```python
class Student:
    """学生类（使用 property 装饰器）"""

    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    @property
    def name(self):
        """getter：获取姓名"""
        return self.__name

    @name.setter
    def name(self, value):
        """setter：设置姓名"""
        if not value:
            print("姓名不能为空！")
            return
        self.__name = value

    @property
    def age(self):
        """getter：获取年龄"""
        return self.__age

    @age.setter
    def age(self, value):
        """setter：设置年龄"""
        if value < 0 or value > 150:
            print("年龄不合法！")
            return
        self.__age = value


# 使用时像访问普通属性一样
s = Student("张三", 20)
print(s.name)   # 调用 getter，输出: 张三
print(s.age)    # 输出: 20

s.age = 25      # 调用 setter
print(s.age)    # 输出: 25

s.age = -5      # 输出: 年龄不合法！
```

### 6.5 name mangling（名称改写）

Python 的私有属性实际上是通过"名称改写"实现的，并不是真正的私有：

```python
class MyClass:
    """演示 name mangling"""

    def __init__(self):
        self.public_var = "公有"
        self.__private_var = "私有"


obj = MyClass()

# 访问公有属性
print(obj.public_var)  # 输出: 公有

# 不能直接访问私有属性
# print(obj.__private_var)  # AttributeError!

# 但可以通过 _类名__属性名 访问（name mangling）
print(obj._MyClass__private_var)  # 输出: 私有

# 查看对象的所有属性
print(obj.__dict__)
# 输出: {'public_var': '公有', '_MyClass__private_var': '私有'}
```

> **说明**：Python 没有真正的私有，`__` 只是改了名字。这是一种约定，表示"这是内部实现，不建议外部访问"。

## 七、继承的基础语法

### 7.1 什么是继承

继承（Inheritance）允许子类获得父类的属性和方法，实现代码复用。

```
父类（基类）: Animal
   ├── 属性: name, age
   └── 方法: eat(), sleep()

子类（派生类）: Dog
   ├── 继承父类的所有属性和方法
   └── 新增: bark() 方法
```

### 7.2 单继承

```python
# 父类
class Animal:
    """动物类"""

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def eat(self):
        print(f"{self.name} 正在吃东西")

    def sleep(self):
        print(f"{self.name} 正在睡觉")


# 子类继承父类
class Dog(Animal):
    """狗类，继承自 Animal"""

    def bark(self):
        """子类新增方法"""
        print(f"{self.name} 汪汪叫！")


class Cat(Animal):
    """猫类，继承自 Animal"""

    def meow(self):
        """子类新增方法"""
        print(f"{self.name} 喵喵叫！")


# 创建子类对象
dog = Dog("旺财", 3)
dog.eat()    # 继承自父类的方法
dog.sleep()  # 继承自父类的方法
dog.bark()   # 子类自己的方法

print("---")

cat = Cat("咪咪", 2)
cat.eat()
cat.sleep()
cat.meow()
```

### 7.3 多继承

Python 支持多继承，一个子类可以继承多个父类：

```python
class Flyable:
    """会飞的"""

    def fly(self):
        print(f"{self.name} 正在飞！")


class Swimmable:
    """会游泳的"""

    def swim(self):
        print(f"{self.name} 正在游泳！")


# 多继承：同时继承 Flyable 和 Swimmable
class Duck(Flyable, Swimmable):
    """鸭子类：会飞也会游泳"""

    def __init__(self, name):
        self.name = name


# 创建鸭子对象
duck = Duck("唐老鸭")
duck.fly()   # 来自 Flyable
duck.swim()  # 来自 Swimmable
```

**同名方法的 MRO 顺序**：

```python
class A:
    def method(self):
        print("A 的方法")


class B:
    def method(self):
        print("B 的方法")


class C(A, B):
    """多继承，A 和 B 都有 method 方法"""
    pass


c = C()
c.method()  # 输出: A 的方法（A 在前，优先级高）

# 查看方法解析顺序（MRO）
print(C.__mro__)
# 输出: (<class 'C'>, <class 'A'>, <class 'B'>, <class 'object'>)
```

> **注意**：多继承中同名方法的查找顺序遵循 **C3 线性化算法**，可通过 `类名.__mro__` 查看。

## 八、复写父类成员和调用父类成员

### 8.1 复写（Override）父类方法

子类中定义与父类**同名**的方法或属性，会覆盖父类的：

```python
class Animal:
    """动物类"""

    def speak(self):
        print("动物发出声音")

    def info(self):
        print("这是动物类")


class Dog(Animal):
    """狗类"""

    # 复写父类方法
    def speak(self):
        print("狗汪汪叫！")

    # 复写父类方法
    def info(self):
        print("这是狗类")


# 创建对象
dog = Dog()
dog.speak()  # 输出: 狗汪汪叫！（调用的是子类复写后的方法）
dog.info()   # 输出: 这是狗类

# 通过父类名调用被复写的方法
Animal.speak(dog)  # 输出: 动物发出声音
```

### 8.2 调用父类同名方法

有两种方式调用父类被复写的方法：

**方式一：`父类名.方法名(self)`**

```python
class Animal:
    """动物类"""

    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出声音")


class Dog(Animal):
    """狗类"""

    def __init__(self, name, breed):
        # 调用父类的构造方法
        Animal.__init__(self, name)
        self.breed = breed

    def speak(self):
        # 先调用父类的方法
        Animal.speak(self)
        # 再添加子类的行为
        print(f"{self.name} 汪汪叫！品种: {self.breed}")


dog = Dog("旺财", "金毛")
dog.speak()
```

输出：
```
旺财 发出声音
旺财 汪汪叫！品种: 金毛
```

**方式二：`super().方法名()`（推荐）**

```python
class Animal:
    """动物类"""

    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出声音")


class Dog(Animal):
    """狗类"""

    def __init__(self, name, breed):
        # 使用 super() 调用父类构造方法（不需要传 self）
        super().__init__(name)
        self.breed = breed

    def speak(self):
        # 使用 super() 调用父类方法
        super().speak()
        print(f"{self.name} 汪汪叫！品种: {self.breed}")


dog = Dog("旺财", "金毛")
dog.speak()
```

> **推荐使用 `super()`**：
> - 不需要显式传递 `self`
> - 在多继承中更安全（遵循 MRO 顺序）
> - 代码更简洁

## 十一、Union 联合类型注解

### 11.1 Union 的基本使用

当一个变量可能有多种类型时，使用 `Union`：

```python
from typing import Union

# Union[int, str] 表示可以是 int 或 str 类型
def process_data(data: Union[int, str]) -> str:
    """处理数据，参数可以是 int 或 str"""
    if isinstance(data, int):
        return f"数字: {data}"
    else:
        return f"字符串: {data}"


print(process_data(100))      # 输出: 数字: 100
print(process_data("hello"))  # 输出: 字符串: hello
```

### 11.2 Union 在变量注解中的使用

```python
from typing import Union

# 变量可能是 int 或 str

print(user_id)  # 输出: ABC100

# 列表中元素可能是 int 或 float
numbers: list[Union[int, float]] = [1, 2.5, 3, 4.0]

```

## 十二、多态

### 12.1 多态的概念

多态（Polymorphism）是指**同一个方法调用，不同的对象会产生不同的行为**。

```python
class Animal:
    """动物基类"""

    def speak(self):
        print("动物发出声音")


class Dog(Animal):
    """狗类"""

    def speak(self):
        print("汪汪汪！")


class Cat(Animal):
    """猫类"""

    def speak(self):
        print("喵喵喵！")


class Duck(Animal):
    """鸭子类"""

    def speak(self):
        print("嘎嘎嘎！")


# 多态的体现：同一个方法，不同对象不同行为
def animal_speak(animal: Animal):
    """让动物叫（参数是 Animal 类型）"""
    animal.speak()  # 调用具体子类的 speak 方法


# 创建不同对象
dog = Dog()
cat = Cat()
duck = Duck()

# 传入不同对象，产生不同行为
animal_speak(dog)   # 输出: 汪汪汪！
animal_speak(cat)   # 输出: 喵喵喵！
animal_speak(duck)  # 输出: 嘎嘎嘎！
```

### 12.2 抽象类和抽象方法

抽象类（Abstract Class）不能被实例化，用于定义子类必须实现的方法。使用 `abc` 模块定义抽象类：

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    """图形抽象基类"""

    @abstractmethod
    def area(self) -> float:
        """计算面积（抽象方法，子类必须实现）"""
        pass

    @abstractmethod
    def perimeter(self) -> float:
        """计算周长（抽象方法，子类必须实现）"""
        pass

    def description(self):
        """普通方法：子类可以直接使用"""
        print(f"这是一个图形，面积: {self.area():.2f}, 周长: {self.perimeter():.2f}")


# 抽象类不能实例化
# shape = Shape()  # TypeError: 无法实例化抽象类


class Rectangle(Shape):
    """矩形"""

    def __init__(self, width: float, height: float):
        self.width = width
        self.height = height

    def area(self) -> float:
        return self.width * self.height

    def perimeter(self) -> float:
        return 2 * (self.width + self.height)


class Circle(Shape):
    """圆形"""

    def __init__(self, radius: float):
        self.radius = radius

    def area(self) -> float:
        import math
        return math.pi * self.radius ** 2

    def perimeter(self) -> float:
        import math
        return 2 * math.pi * self.radius


# 创建具体图形对象
rect = Rectangle(5, 3)
rect.description()  # 输出: 这是一个图形，面积: 15.00, 周长: 16.00

circle = Circle(4)
circle.description()  # 输出: 这是一个图形，面积: 50.27, 周长: 25.13
```

## 十三、面向对象综合案例

### 13.1 案例：动物王国（完整继承体系）

**需求**：设计一个完整的动物类继承体系，演示继承、多态、封装等特性。

```python
from abc import ABC, abstractmethod
import math


class Animal(ABC):
    """动物抽象基类"""

    def __init__(self, name: str, age: int):
        # 使用封装保护属性
        self.__name = name
        self.__age = age

    # getter 方法
    @property
    def name(self) -> str:
        return self.__name

    @property
    def age(self) -> int:
        return self.__age

    # setter 方法
    @name.setter
    def name(self, value: str) -> None:
        if not value:
            print("名字不能为空！")
            return
        self.__name = value

    @age.setter
    def age(self, value: int) -> None:
        if value < 0:
            print("年龄不能为负数！")
            return
        self.__age = value

    @abstractmethod
    def speak(self) -> None:
        """抽象方法：动物的叫声"""
        pass

    @abstractmethod
    def move(self) -> None:
        """抽象方法：动物的移动方式"""
        pass

    def show_info(self) -> None:
        """显示信息（普通方法）"""
        print(f"名字: {self.__name}, 年龄: {self.__age}岁", end="，")

    def __str__(self) -> str:
        return f"{self.__name}({self.__age}岁)"

    def __eq__(self, other) -> bool:
        """判断两个动物是否相同（名字和年龄相同）"""
        if isinstance(other, Animal):
            return self.__name == other.__name and self.__age == other.__age
        return False


class Mammal(Animal):
    """哺乳动物（继承 Animal）"""

    def __init__(self, name: str, age: int, fur_color: str):
        super().__init__(name, age)  # 调用父类构造方法
        self.fur_color = fur_color

    def move(self) -> None:
        """实现抽象方法"""
        print(f"{self.name} 在陆地上奔跑")

    def show_info(self) -> None:
        super().show_info()  # 调用父类方法
        print(f"毛发颜色: {self.fur_color}", end="，")
        self.speak()  # 调用具体子类的 speak


class Bird(Animal):
    """鸟类（继承 Animal）"""

    def __init__(self, name: str, age: int, wingspan: float):
        super().__init__(name, age)
        self.wingspan = wingspan  # 翼展

    def move(self) -> None:
        """实现抽象方法"""
        print(f"{self.name} 在天上飞翔")

    def show_info(self) -> None:
        super().show_info()
        print(f"翼展: {self.wingspan}米", end="，")
        self.speak()


class Dog(Mammal):
    """狗类（继承 Mammal）"""

    def __init__(self, name: str, age: int, fur_color: str, breed: str):
        super().__init__(name, age, fur_color)
        self.breed = breed  # 品种

    def speak(self) -> None:
        """实现抽象方法"""
        print(f"汪汪汪！（{self.breed}）")

    def fetch(self) -> None:
        """狗特有的方法"""
        print(f"{self.name} 在捡球！")


class Cat(Mammal):
    """猫类（继承 Mammal）"""

    def __init__(self, name: str, age: int, fur_color: str, is_indoor: bool):
        super().__init__(name, age, fur_color)
        self.is_indoor = is_indoor  # 是否室内猫

    def speak(self) -> None:
        """实现抽象方法"""
        print("喵喵喵！")

    def climb(self) -> None:
        """猫特有的方法"""
        print(f"{self.name} 在爬树！")


class Parrot(Bird):
    """鹦鹉类（继承 Bird）"""

    def __init__(self, name: str, age: int, wingspan: float, vocabulary: int):
        super().__init__(name, age, wingspan)
        self.vocabulary = vocabulary  # 词汇量

    def speak(self) -> None:
        """实现抽象方法"""
        print(f"你好你好！（词汇量: {self.vocabulary}）")


# ====== 使用示例 ======

# 创建不同动物

parrot = Parrot("波利", 5, 0.5, 100)

# 多态：遍历动物列表，调用相同方法
```

### 13.2 案例：学生管理系统（完整 OOP 设计）

**需求**：设计一个完整的学生管理系统，演示面向对象的综合应用。

```python
from typing import List, Optional


class Student:
    """学生类"""

    def __init__(self, student_id: str, name: str, age: int, scores: List[float]):
        self.student_id = student_id
        self.name = name
        self.age = age
        self.scores = scores  # 成绩列表

    def get_average_score(self) -> float:
        """计算平均分"""
        if not self.scores:
            return 0.0
        return sum(self.scores) / len(self.scores)

    def get_grade(self) -> str:
        """获取等级"""
        avg = self.get_average_score()
        if avg >= 90:
            return "A"
        elif avg >= 80:
            return "B"
        elif avg >= 70:
            return "C"
        elif avg >= 60:
            return "D"
        else:
            return "F"

    def __str__(self) -> str:
        return (f"学号: {self.student_id}, 姓名: {self.name}, "
                f"年龄: {self.age}, 平均分: {self.get_average_score():.1f}, "
                f"等级: {self.get_grade()}")

    def __repr__(self) -> str:
        return f"Student('{self.student_id}', '{self.name}', {self.age}, {self.scores})"

    def __lt__(self, other: 'Student') -> bool:
        """按平均分排序"""
        return self.get_average_score() < other.get_average_score()

    def __eq__(self, other) -> bool:
        if isinstance(other, Student):
            return self.student_id == other.student_id
        return False


class StudentManager:
    """学生管理类"""

    def __init__(self):
        self._students: List[Student] = []  # 使用下划线表示"受保护"

    def add_student(self, student: Student) -> bool:
        """添加学生"""
        # 检查学号是否重复
        for s in self._students:
            if s == student:
                print(f"学号 {student.student_id} 已存在！")
                return False
        self._students.append(student)
        print(f"添加成功: {student.name}")
        return True

    def remove_student(self, student_id: str) -> bool:
        """删除学生"""
        for i, s in enumerate(self._students):
            if s.student_id == student_id:
                removed = self._students.pop(i)
                print(f"已删除: {removed.name}")
                return True
        print(f"未找到学号 {student_id} 的学生")
        return False

    def find_student(self, student_id: str) -> Optional[Student]:
        """查找学生"""
        for s in self._students:
            if s.student_id == student_id:
                return s
        return None

    def show_all(self) -> None:
        """显示所有学生"""
        if not self._students:
            print("暂无学生信息")
            return
        print("\n=== 学生列表 ===")
        for s in self._students:
            print(s)

    def show_ranking(self) -> None:
        """按平均分排名"""
        if not self._students:
            print("暂无学生信息")
            return
        # 使用 sorted 排序（利用 __lt__ 方法）
        ranked = sorted(self._students, reverse=True)
        print("\n=== 成绩排名 ===")
        for i, s in enumerate(ranked, 1):
            print(f"第 {i} 名: {s.name} - {s.get_average_score():.1f}分 ({s.get_grade()}级)")

    def get_class_average(self) -> float:
        """获取班级平均分"""
        if not self._students:
            return 0.0
        total = sum(s.get_average_score() for s in self._students)
        return total / len(self._students)


class FileManager:
    """文件管理类（演示类的设计）"""

    @staticmethod
    def save_to_file(students: List[Student], file_path: str) -> bool:
        """保存到文件"""
        try:
            with open(file_path, "w", encoding="utf-8") as f:
                for s in students:
                    scores_str = ",".join(str(score) for score in s.scores)
                    f.write(f"{s.student_id},{s.name},{s.age},{scores_str}\n")
            print(f"保存成功，共 {len(students)} 条记录")
            return True
        except IOError as e:
            print(f"保存失败: {e}")
            return False

    @staticmethod
    def load_from_file(file_path: str) -> List[Student]:
        """从文件加载"""
        students = []
        try:
            with open(file_path, "r", encoding="utf-8") as f:
                for line in f:
                    parts = line.strip().split(",")
                    if len(parts) >= 4:
                        student_id = parts[0]
                        name = parts[1]
                        age = int(parts[2])
                        scores = [float(x) for x in parts[3:]]
                        students.append(Student(student_id, name, age, scores))
            print(f"加载成功，共 {len(students)} 条记录")
        except FileNotFoundError:
            print("文件不存在")
        except (ValueError, IndexError) as e:
            print(f"数据格式错误: {e}")
        return students
```

## 十四、本章小结

### 14.1 OOP 四大特性

| 特性 | 说明 | 关键字/语法 |
|------|------|------------|
| **封装** | 隐藏内部细节，对外提供接口 | `__` 私有属性、`@property` |
| **继承** | 子类获得父类的属性和方法 | `class 子类(父类):` |
| **多态** | 同一方法，不同对象不同行为 | 抽象类 `ABC`、`@abstractmethod` |
| **抽象** | 定义抽象类和抽象方法 | `from abc import ABC` |

### 14.2 常用魔术方法

| 方法 | 触发时机 |
|------|---------|
| `__init__` | 对象创建时 |
| `__str__` | `print(obj)` 时 |
| `__repr__` | `repr(obj)` 时 |
| `__lt__` | `<` 比较时 |
| `__le__` | `<=` 比较时 |
| `__eq__` | `==` 比较时 |

### 14.3 命名规范总结

| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | 大驼峰 PascalCase | `StudentInfo` |
| 方法名 | 小写下划线 snake_case | `get_student_info` |
| 变量名 | 小写下划线 snake_case | `student_name` |
| 常量 | 全大写下划线 | `MAX_SIZE` |
| 私有成员 | 双下划线开头 | `__balance` |
| 受保护成员 | 单下划线开头 | `_internal_var` |

### 14.4 最佳实践

1. **类名使用大驼峰**：`StudentInfo` 而非 `student_info`
2. **方法名使用小写下划线**：`get_name()` 而非 `getName()`
3. **优先使用 `super()`**：调用父类方法比 `父类名.方法(self)` 更优雅
4. **使用类型注解**：提高代码可读性和 IDE 提示
5. **合理使用封装**：敏感数据设为私有，提供 getter/setter
6. **使用 `@property`**：比传统 getter/setter 更优雅
7. **遵循单一职责原则**：一个类只做一件事
8. **优先使用组合而非继承**：避免过深的继承层次
